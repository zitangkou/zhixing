# 知行公考

纯公考备考应用 — 基于 **Taro 4 + Vue 3 + TypeScript + NutUI + Pinia** 的跨端应用（微信小程序 + H5）。

Slogan：**以「上岸」为唯一目标**

## 功能

- 今日驾驶舱：考试倒计时、今日清单、复习提醒、昨日足迹
- 公考主线：时政要点与金句素材、资料分析、申论/人民日报、知识框架、真题套卷
- 练习闭环：多种刷题模式、时政套题进度与错题订正、错题本（文章/手动）、艾宾浩斯复习、复习中心
- 积分、签到、排行榜、知行足迹

## 快速开始

```bash
cd ~/Projects/zhixing-gongkao
npm install
npm run dev:h5      # H5 开发 http://localhost:10087（默认连真实 API）
npm run dev:weapp   # 微信小程序，用开发者工具打开 dist 目录
```

后端另开终端：

```bash
cd server
source .venv/bin/activate
uvicorn app.main:app --reload --port 8001
```

## 部署（云服务器，一键）

```bash
# 服务器首次（一次性）
apt update && apt install -y git
cd /opt
git clone git@github.com:zitangkou/zhixing-gongkao.git   # 需先在 GitHub 添加服务器 SSH 公钥
cd zhixing-gongkao
bash deploy/setup-docker.sh    # 安装 Docker / Compose + 镜像加速（只跑一次）

# 一键部署：自动生成 .env → 构建 → 启动 → 健康检查
bash deploy.sh

# 配置域名网关（可选，正式运营推荐）
nano .env                      # 改 DOMAIN / CORS_ORIGINS / ALLOW_REGISTER
cp deploy/nginx.conf /etc/nginx/sites-available/zhixing-gongkao
# 编辑 server_name 与 proxy_pass 端口后：
ln -sf /etc/nginx/sites-available/zhixing-gongkao /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
```

- 访问：`http://<IP>:8081/`（H5）、`http://<IP>:8081/manage/`（管理后台）；有域名走网关后为 `http://<域名>/`
- 更新：`git pull && bash deploy.sh`；备份：`bash deploy/backup.sh`（每日定时：`bash deploy/install-backup.sh`）
- 与其它项目共存：compose 项目名 / 容器名 / 端口（8081）/ 数据卷均与 coffee-order 等隔离；服务器已有 Docker 时 `setup-docker.sh` 会自动跳过全局配置，不影响现有容器
- 完整手册（端口 / 路由 / HTTPS / 恢复）→ [DEPLOY.md](./DEPLOY.md)

## 速算训练与公式显示（2026-10-16，本地实现）

资料分析首页新增「速算训练 · 随机出题」，H5 与微信小程序均可使用。题库按计算概念组织，包含分数比较、增长量、增长率、基期量、比重、平均数、倍数、混合增长率、间隔/年均增长、贡献率/拉动等；比较题覆盖两数关系、多分数选极值及排序，计算题覆盖直接计算和四项计算辨析。训练可选题型或混合模式及每组 5/10/20 题。增长量练习使用真实统计数据改编题，解析根据数据特征推荐除乘转化、假设估算、错位加减或乘数拆分等方法，不把某一种速算方法固定为题型；增长量/增长率计算辨析只抽取在展示精度下能区分常见错项的真实数据，避免用人为凑出的算术误差填充选项。管理端「资料分析 → 速算训练」可配置题型、知识节点、数值范围和难度，预览校验后发布；题目由后端生成，逐题记录答案，支持服务端错题重练、个人训练历史及后台正确率/耗时/错选统计。训练结果不计入材料题积分与排行。

知识框架公式块、正文及例题中的 `$…$`、`$$…$$`、`\(…\)`、`\[…\]`、latex/math/tex 围栏可渲染。小程序通过 `@rojer/katex-mini` 转为 rich-text 节点，KaTeX 字体随包内置；H5 继续用 KaTeX HTML。复杂或非法公式回退到可读式/原文，实际手机排版仍需微信开发者工具与真机验收。

数学与场景校验：`node scripts/check-quick-calc.mjs`；小程序构建后校验：`node scripts/check-weapp-math.mjs`。当前为本地实现，尚未部署或发布。

## 申论练习（本地实现）

人民日报·申论四类练习支持归纳概括、提出对策、贯彻执行、申发论述。后台页面按“题目管理 / 自动出题 / 教研反馈”三个 Tab 分区，默认进入题目管理，分别维护练习、跟踪每日生成批次并复盘审核质量。系统复用每日人民日报共享采集池与联合分析缓存，只选择有公共议题、治理或政策执行证据锚点的候选并按正文指纹去重；每批最多处理3篇，同刊期再次运行可续跑剩余候选。材料摘录、逐点证据、答案对要点的逐点覆盖、题目字数上限、评分维度和解析长度均有硬校验；常规题优先归并4—6个要点，最多8个，超出常规数量需要说明独立性。二次复核中材料外事实或名称、答案漏点、证据过度推断、任务不匹配等实质问题，即使模型标成一般也会阻断草稿；复核引文须能在本题材料或答案中定位；设问按题型历年真题任务结构基准复核，且逐点说明材料证据如何支持要点、答案如何保留要点的对象与动作。质量分仅作辅助，不能抵消硬性问题。后台展示逐篇进度、质量退回与运行失败；教研审核结论、问题维度、审核意见及是否修改内容写入质量报告并保留历史，后台按题型汇总审核结论与高频问题维度，审核历史保存当时的题目版本并可按题型筛选分页导出完整审核样本 JSON，反馈统计按生成规则版本展示审核结论和修改率；可用`python3 server/scripts/analyze_shenlun_review_dataset.py <样本.json>`输出本地复盘报告；旧规则草稿会标为需复核，草稿不自动发布。小程序提交后解锁参考要点、证据、答案与解析，并支持订正复盘；系统不自动给学员答案打分。自动出题需要服务端启用 LLM，运行时段为北京时间09:00—11:00，默认开启，可用 `RMRB_SHENLUN_AUTO_ENABLED=false` 关闭。上游分析失败可从练习页直达联合采集并按刊期重跑。


### 2026-10-17 · 速算训练按题型组织（本地实现，待部署）

速算训练统一为分数比较、增长量、增长率、基期量四种题型。分数比较在同一组内覆盖分数性质、差分比较、同位比较和分母拆分场景，作答前只展示数据，作答后解析给出优先建议与推导。管理端按题型配置、预览和发布；新增分数比较规则初始为草稿，需显式发布。旧比较方法规则、版本及训练快照保留，历史统计和薄弱项推荐归入分数比较，建议方法分布单独统计。无需新增权限、菜单或环境变量。

### 2026-10-17 · 速算练习题目形式扩展（本地实现，待部署）

分数比较加入四分数选最大/最小和完整排序；增长量、增长率、基期量加入四项计算辨析，支持选择正确项或错误项。服务端在预览及创建正式练习时校验选项唯一性，管理端展示题目形式分布。多分数题标记为教学模拟，不作为真题原题或真题频率统计。

### 2026-10-17 · 混合训练加入综合材料辨析（本地实现，待部署）

混合训练每 10 题最多加入 1 道综合材料辨析题；20 题组加入 2 道。题目从同一统计来源、同一单位的 2023—2024 年公开数据中取四项，四个选项分别检验增长量、增长率、基期量、现期量，题目随机要求选择唯一正确项或唯一错误项。生成时核验每项公式和舍入结果，答后逐项标注成立与否并给出对应知识节点。该长题只在增长量、增长率、基期量训练均已发布时加入；不增加后台配置方法或独立入口。

### 2026-10-18 · 速算训练概念扩展（本地实现，待部署）

管理端与学员端新增比重、平均数、倍数、混合增长率、间隔/年均增长、贡献率/拉动题型。题目使用国家统计局粮食分省产量/单产、粮食分项、GDP现价分产业数据及海关贸易统计，按官方数据样本轮换生成 5/10/20 题；题型与解题方法分离，建议方法在答题后显示。每题保留来源链接，服务端校验数据关系、公式结果及选项唯一性。公开统计数据改编不代表真题原题，GDP现价混合增速也不代表官方不变价实际增速。倍数公式已更正为“倍数 = 1 + 增长率”。本阶段尚未部署。
