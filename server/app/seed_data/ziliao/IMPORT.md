# 资料分析真题导入规范

面向知行「试卷题库」批量导入，材料组会自动进入 H5「资料分析 → 专项练习」。

## 1. 推荐流程

1. Admin → **试卷题库** → 新建试卷（标题写清：如「2023国考行测·资料分析」）
2. 点 **导入题目**，粘贴 Markdown（推荐）或上传 `.md` / `.json`
3. 预览无误后确认导入
4. 确认 `section` 为 **资料分析**，同一材料下多题共用 `> **材料**` 块
5. 每题写 `> **知识点：**`（与题型关键词对齐，便于按题型练）

系统内置的「资料分析专项样例」仅作联调；**只要库里有其他资料分析真题，默认练习池会自动排除样例卷**。

## 2. Markdown 模板（复制即用）

```markdown
# 2023 国考行测（资料分析节选）

## 资料分析

### 1
> **材料**
> 2022 年，某省规上工业增加值同比增长 6.8%。其中，高技术制造业增加值增长 12.5%，占规上工业增加值的比重为 18.6%，比上年提高 0.9 个百分点。
> 同期该省工业投资同比增长 9.2%，其中高技术制造业投资增长 15.3%。

2022 年该省高技术制造业增加值约占规上工业增加值的：
A. 17.7%
B. 18.6%
C. 19.5%
D. 无法计算
> **答案：B**
> **解析：材料直接给出比重 18.6%。**
> **知识点：比重**
> **难度：2**

### 2
> **材料**
> 2022 年，某省规上工业增加值同比增长 6.8%。其中，高技术制造业增加值增长 12.5%，占规上工业增加值的比重为 18.6%，比上年提高 0.9 个百分点。
> 同期该省工业投资同比增长 9.2%，其中高技术制造业投资增长 15.3%。

与上年相比，2022 年该省高技术制造业增加值占规上工业增加值的比重：
A. 上升了
B. 下降了
C. 基本持平
D. 无法判断
> **答案：A**
> **解析：部分增速 12.5% > 整体 6.8%，或材料已写明提高 0.9 个百分点。**
> **知识点：两期比重差,比重**
> **难度：3**

### 3
（同一材料可只在第一题写材料块；后续题若不写材料，导入器按「当前材料」继承——建议每题仍重复材料块以保证分组稳定）
```

说明：

- `## 资料分析`：模块名必须含「资料分析」或就写成 `资料分析`
- `> **材料**` 后多行 `>` 为共享材料；**同一材料文本相同**的题会聚成一组
- `> **知识点：**` 建议用：增长率、增长量、基期、比重、两期比重差、倍数、平均数、贡献率、年均 等，与题型库 `keywords` 对齐
- 答案写字母 `B` 或选项全文均可

## 3. 知识点标签约定（与题型弱匹配）

| 标签示例 | 对应题型倾向 |
|----------|--------------|
| 增长率、增幅、同比 | T001 增长率计算 |
| 比较、增速更高 | T002 增长率比较 |
| 增长量、增加了 | T004 增长量计算 |
| 基期、上年 | T005 基期量计算 |
| 比重、占比、占 | T007 比重计算 |
| 百分点、上升、下降 | T010 两期比重差 |
| 倍数、是几倍 | T011 倍数计算 |
| 平均、人均 | T012 平均数计算 |
| 贡献率、拉动 | T014 贡献率/拉动 |

可写多个，逗号分隔：`> **知识点：比重,两期比重差**`

## 4. 质检清单（导入前过一遍）

- [ ] 材料完整，数字单位统一（万/亿）
- [ ] 同一材料组通常 3～5 题（国考风格）
- [ ] 选项可估算，避免怪数字导致无法速算
- [ ] 解析含「普通算法 + 速算路径」更好
- [ ] `difficulty`：国考一般 3～4，入门练 2
- [ ] 不要导入样例级「一眼看出」的题占满练习池

## 6. 持续扩库节奏（建议）

- 每周至少导入 **1 套** 真题资料分析（约 4 组材料 × 4 题）
- 导入后在 H5「按题型练」抽查过滤是否命中
- 错题本里反复错的考点 → 回填公式/技巧案例或补同类真题
