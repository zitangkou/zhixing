# 《十五五规划建议》公考出题规范（高质量）

参考：公务员考试政治理论·常识判断真题风格 + 2026 年规划建议竞赛题库。

## 核心原则

1. **严格依原文**：`source_sentence` 必须是原文中可找到的句子或要点，不得编造政策表述。
2. **拒绝低质挖空**：禁止把原文某个词替换成 `______` 的简单挖空题（如「两个确立」挖空），这类题记忆价值低。
3. **题干有考点**：每题应考查一个明确知识点（定位、术语、举措、并列项、易混概念等）。
4. **干扰项要「像真的」**：错误选项应来自相近表述、顺序颠倒、主体偷换、程度夸大，不能明显荒谬。
5. **解析讲清楚**：说明为何选此项；多选题需点明陷阱项（如「D项……尚未完成/明显错误」）。

## 题干写法（统一用「《建议》」指代本文）

| 题型 | 推荐句式 |
|------|----------|
| 单选 | 《建议》指出/提出/强调/要求，……（ ）。 |
| 单选 | 《建议》将「十五五」时期定位为…… |
| 单选 | ……是中国式现代化的（ ）。 |
| 单选 | 《建议》提出的「五大金融/六项原则」**不包括**： |
| 多选 | 《建议》指出，……包括： / 下列……正确的有： |
| 判断 | （判断）《建议》提出，…… |

填空用中文括号 `（ ）`，不要用下划线 `______`。

## 单选题（single）

- 4 个选项，1 个正确答案（字符串，等于某选项原文）。
- options **不含** A/B/C/D 前缀。
- 覆盖以下**题型 mix**（不要只做一种）：
  - **定位表述**：「是中国式现代化的物质技术基础/战略依托/鲜明底色……」
  - **指导术语**：主题、根本动力、根本目的、根本保障
  - **原文原话**：如「极不寻常、极不平凡」「夯实基础、全面发力」
  - **不包括型**：五大金融、原则、举措列表中混入一项错误
  - **易混干扰**：近义短语并列作选项（如「承前启后」vs「夯实基础、全面发力」）
  - **常识结合**：两个确立、四个意识等（须与原文语境一致）

## 多选题（multiple，公考标准）

- 4 个选项；**2～4 个**正确答案（数组）。
- 题干含「下列……正确」或「包括」。
- 常见模式：
  - **全对型**：四项均为原文并列要点（答案 ABCD）
  - **陷阱型**：三项对 + 一项偷换/夸大/未完成（如「国家完全统一大业完成」）
  - **部分型**：两项对（如「两个确立」的根本原因 BC）
- 解析格式：`A/B/C/D项：……` 或 `D项为陷阱，……`

## 判断题（judge）

- options 固定 `["正确", "错误"]`。
- 一半考原文正确表述（答案「正确」）；一半考**精准篡改**后错误（答案「错误」）。
- 篡改方式：根本↔基本、两个确立↔两个统一、已完成↔尚未完成、主体偷换。
- 错误判断题须在解析中给出正确表述。

## 出题流程（模型内部）

1. 先从原文提取带 `quote` 的要点清单（定位/并列/举措/不包括素材）。
2. 再按要点清单命制题目，确保 `source_sentence` 来自对应 quote。
3. 题目之间考点不重复，选项长度大致相当。
