## 步骤 1：三刀法解剖 → MD 文档

**输入：** 人民日报评论文章全文
**输出：** 标准格式的三刀解剖 MD 文档
**耗时：** 约30分钟

### 操作要点

1. 精读文章，标记总论点、分论点（2-4个）、规范词、金句、论据案例
2. 套用三刀解剖 MD 模板（见附录A），填充各模块
3. 保存为 `文章标题.md`

---

## 步骤 2：基于解剖 MD → 微信公众号 HTML

**输入：** 步骤1输出的三刀解剖 MD 文档
**输出：** 可直接粘贴到公众号后台的 HTML 文档
**耗时：** 约20分钟

### 操作要点

1. 从 MD 中提取：原文摘录、全文骨架、规范词（6-8个）、分论点（2-3个）、万能句式（3-4个）、素材速记卡
2. 套用公众号 HTML 模板（见附录B），替换对应内容
3. 保存为 `.html` 文件

**内容特点：** 系统化深读、全文拆解、适合收藏精读

---

## 步骤 3：基于解剖 MD → 小红书 8 张卡片内容模板

**输入：** 步骤1输出的三刀解剖 MD 文档
**输出：** 小红书 8 张卡片的内容文案（纯文字）
**耗时：** 约20分钟

### 卡片结构与内容来源

| 卡片 | 内容来源 | 精简原则 |

| 图1 封面 | 文章标题+核心主题 | 主标题≤20字 |
| 图2 概览 | 原文头部信息 | 3-5行，突出核心卖点 |
| 图3 金句 | 语录模块 | 选1-2句最强金句 |
| 图4 骨架 | 总骨架模块 | 文字流程图 |

| 图7 万能句式 | 句式模板 | 选1个最易套用 |
| 图8 速记卡+行动 | 总结+金句+案例 | 极简可背诵 |

**内容特点：** 视觉化干货、碎片化积累、引导收藏

## 步骤 5：基于小红书卡片 → 抖音版卡片 + AI 提示词（新增）

**输入：** 步骤3输出的小红书8张卡片内容
**输出：** 抖音版8张卡片文案 + 8组即梦/豆包提示词
**耗时：** 约15分钟

### 小红书 → 抖音 调整规则

| 维度 | 小红书（步骤3） | 抖音（步骤5） |
|------|----------------|---------------|
| **用户心态** | 搜索+收藏，主动学习 | 被动刷到，碎片化触达 |
| **封面背景** | 深蓝底 | **纯黑底** |
| **点缀色** | 金色 #C9A85C | **亮橙红 #FF4D2E + 亮黄 #FFC300** |
| **标题字号** | 60-80像素 | **80-100像素，超大** |
| **规范词数量** | 6个 | **3个（精选最核心）** |
| **分论点展示** | 完整拆解 | **只留核心公式** |
| **万能句式** | 原文+模板+仿写 | **模板+仿写，原文省略** |
| **最后一张图** | 素材速记卡+行动清单 | **关注引导卡** |
| **底部引导** | 评论仿写打卡 | **关注+进主页** |
| **内容风格** | 干净、优雅、留白多 | **大字、强对比、快节奏** |

## 三平台内容流转关系

```
同一篇解剖内容（MD）
    │
    ├──→ 公众号（长文HTML·完整版）
    │      └── 引导关注公众号
    │
    ├──→ 小红书（8张图·完整版）
    │      ├── 引导评论仿写打卡
    │      └── 主页简介放公众号
    │
    └──→ 抖音（8张图·精简版）
           ├── 图5引导“进主页看小红书”
           ├── 图8引导“关注看更多拆解”
           └── 主页简介放小红书号
```

**跨平台导流路径：**

```
抖音刷到 → 关注抖音 → 主页简介 → 小红书 → 主页简介 → 公众号

```
