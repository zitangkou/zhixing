# 人民日报文章 → 多平台内容运营 完整处理流程 SOP

本流程将一篇人民日报评论文章，经过四个步骤，转化为可用于微信公众号、小红书以及AI生图的多形态运营素材。

---

```
输入：人民日报评论文章（全文文本）
        │
        ▼

        │
        ▼
输出：三刀解剖 MD 文档（标准模板）
        │
        ├──────────────┐
        ▼              ▼
步骤2：生成公众号 HTML   步骤3：生成小红书 8 张卡片内容模板
        │              │
        ▼              ▼
输出：公众号排版 HTML    输出：小红书卡片文案（8张）
        │              │
        │              ▼
        │              步骤4：生成 AI 生图提示词（即梦/豆包）
        │              │
        │              ▼
        │              输出：8 组文生图提示词
        │
        ▼
最终：多平台内容素材包
```

## 步骤 1：三刀法解剖 → MD 文档

**输入：** 人民日报评论文章全文  
**输出：** 标准格式的三刀解剖 MD 文档  
**耗时：** 约 30 分钟

### 操作要点

1. **精读文章**，标记出：
   - 总论点、分论点（通常 2-4 个）
   - 规范词、金句
   - 论据案例、论证方法

2. **套用三刀解剖 MD 模板**（模板见附录 A），填充以下模块：
   - 原文摘录
   - 总骨架
   - 分论点拆解（每个包含标题、论据、小结、论证方法、套用模板）
   - 规范词表
   - 语录
   - 高频动词
   - 句式模板（含原文、模板、仿写）

3. **保存文件**，命名规范：`文章标题.md`，例如 `从一刻钟悟发展之道.md`

### 模板参考

见附录 A：三刀解剖 MD 模板（可直接复制使用）

---

## 步骤 2：基于解剖 MD → 微信公众号 HTML

**输入：** 步骤 1 输出的三刀解剖 MD 文档  
**输出：** 可直接粘贴到公众号后台的 HTML 文档  
**耗时：** 约 20 分钟

### 操作要点

1. **从 MD 文档中提取**：
   - 原文摘录
   - 全文骨架
   - 规范词精选（6-8 个）
   - 分论点拆解（选 2-3 个）
   - 万能句式（3-4 个）
   - 素材速记卡内容

2. **套用公众号 HTML 模板**（模板见附录 B），将内容填入对应区域：
   - 封面头图：文章标题 + 系列名
   - 开篇引导框
   - 原文摘录框
   - 骨架展示
   - 规范词表格
   - 分论点卡片
   - 句式卡片
   - 素材速记卡
   - 行动清单
   - 页脚链接

3. **保存为 `.html` 文件**，或直接粘贴到公众号编辑器 HTML 模式。

### 模板参考

见附录 B：微信公众号 HTML 模板（含完整样式，可直接替换文字）

## 步骤 3：基于解剖 MD → 小红书 8 张卡片内容模板

**输入：** 步骤 1 输出的三刀解剖 MD 文档  
**输出：** 小红书 8 张卡片的内容文案（纯文字，待配图）  
**耗时：** 约 20 分钟

### 卡片结构与内容来源

| 卡片 | 内容来源（MD 模块） | 精简原则 |
|------|---------------------|----------|
| 图1 封面 | 文章标题 + 核心主题 | 主标题 ≤20 字，副标题含系列名 |
| 图2 概览 | 原文头部信息 + 适用主题 | 3-5 行，突出核心卖点 |
| 图3 金句 | 语录模块 | 选 1-2 句最有力金句 |
| 图4 骨架 | 总骨架模块 | 用文字流程图展示 |
| 图5 规范词 | 规范词表 | 选 6 个最核心，含白话释义 |
| 图6 论证骨架 | 分论点拆解 | 选最精彩的 1 个分论点深入拆解 |
| 图7 万能句式 | 句式模板 | 选 1 个最易套用的，含原文/模板/仿写 |
| 图8 速记卡+行动 | 总结 + 金句 + 案例 | 极简，可直接背诵 |

### 操作要点

1. **逐张生成卡片文案**，参考小红书卡片模板（见附录 C），只生成文字，不包括设计。
2. **确保每张卡片信息独立**，用户保存任意一张都有收获。
3. **统一语气与格式**，保持系列感。

### 模板参考

见附录 C：小红书 8 张卡片内容模板（纯文字版，可直接填入数据）

## 步骤 4：基于 8 张卡片内容 → 文生图提示词

**输入：** 步骤 3 输出的 8 张卡片内容模板  
**输出：** 8 组可直接用于即梦/豆包等平台的文生图提示词  
**耗时：** 约 10 分钟

### 操作要点

1. **针对豆包/即梦优化**：
   - 去除所有十六进制色号（#1F3864 等），改为中文颜色描述（深藏蓝、暗金、暖米白等）
   - 去除所有 Emoji 符号（🔑、📌 等），改为纯文字描述或直接省略图标
   - 每条提示词控制在 150 字以内，指令尽量简洁

2. **逐张生成提示词**，每张对应一个提示词。

3. **保存为 `.md` 或 `.txt` 文件**，方便复制到生图平台。

### 模板参考

见附录 D：豆包/即梦文生图提示词模板（已去除所有格式指令，纯自然语言描述）

## 附录 D：豆包/即梦文生图提示词模板

### 通用规则

- 使用中文自然语言描述
- 颜色用中文名称（深藏蓝、暗金、暖米白、暖橙、深灰、浅灰）
- 不使用 Emoji 和特殊符号
- 每张提示词控制在 150 字以内
- 文字内容用引号标出，明确区分指令和显示内容

### 模板示例（以图1封面为例）

```
一张小红书封面图，竖版3比4。

背景是纯深藏蓝色，没有任何纹理。

画面正中间是两行白色粗体大字：
第一行写“人民日报这样读”
第二行写“申论下笔有神”

在白色大字上方，有一行较小的暗金色文字：
“三刀解剖法 申论时评拆解”

在白色大字下方，有一行较小的白色文字：
“今日拆解：从一刻钟悟发展之道”

画面最底部有一行暗金色小字：
“申论素材 考公必备”

整体风格：极简，扁平，没有阴影，文字准确清晰。
```

其余 7 张提示词参照此格式，将对应卡片内容填入即可。

## 使用注意事项

1. **文字准确性第一**：AI 生图后必须逐字核对，错字立即用 Canva 修正。
2. **模板复用**：首次制作好公众号 HTML 模板和 Canva 品牌模板，后续仅替换文字，效率最高。
3. **批次处理**：建议周一到周五每天解剖一篇，周六集中生成公众号 HTML 和小红书卡片，周日集中生成提示词和图片，晚上定时发布。
4. **一鱼多吃**：同一篇解剖内容，同时产出公众号、小红书、视频号素材，最大化价值。
