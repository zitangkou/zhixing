# 脚本清单（工作流/，含用途/用法/依赖）

> 生产用 10 个核心脚本；其余为历史/备用/作废。

## 核心生产脚本
| 脚本 | 用途 | 用法 | 依赖 |
|------|------|------|------|
| `抓取.py` | **人民日报评论抓取（v2.17 新增，automation 步骤1）**：自动识别评论版号、抓取评论版全部文章，正确处理「纵横」摘编栏目标题（标题区只有栏目名时回退正文第一个 p 取真实标题） | `python 工作流/抓取.py --date <YYYY-MM-DD> [--out 目录]` | venv bs4+lxml |
| `原文HTML生成.py` | **原文 HTML 生成（2026-09-09 新增，automation 步骤1.5）**：原文 md→统一版式 HTML（报头「时评精拆」/品牌红；**全部正文段落入正文**；灰块为原文**中心论点段**（优先「关键在于」等，非首段钩子）；标题下「主题：」来自同目录解剖 `主题归类` 命中后台预设或短名）。**标题降级**：标题行 ≥25 字→取「栏目:」字段（典型栏目词排除）。**归位模式 `--into-articles`**（配合 `--date`）：选中文章 md+HTML 到 `物料/<日期>/<文章标题>/原文/` | `python3 工作流/原文HTML生成.py --date <YYYY-MM-DD>`、`--date <d> --into-articles` 或单篇路径 | python3（非venv，标准库） |
| `规则自检.py` | 每日自检（门1-5，含可读性 WARN；**v2.18 增强**：解剖含「## 考题定位」自动走新校验（考题定位/迁移指南/精简铁律 5 项），旧格式 WARN 回退；`--anatomy-only` 只测解剖；`-v18` 目录按 9 卡校验；**v2.5（09-09）**：新增文章 `原文/` md+html 成对 + `解剖/` 三刀解剖.html 成对校验，FAIL 级） | `python3 工作流/规则自检.py "物料/<日期>"`，exit 0=通过 | python3（非venv） |
| `可读性检测.py` | 图片可读性 v2.1（文字级低对比+饱和度） | `python 工作流/可读性检测.py <图片或目录>`，❌黑白灰/低对比文字需处理 | venv opencv |
| `小红书卡片渲染.py` | **小红书卡片渲染（v2.15 生产，v2.17 双封面，v2.18 平行增强）**：公众号 HTML→1242×1660 卡片（路径B 重排）。标准 HTML=7 张/篇；**v2.18 HTML（含考题定位章节）=8 张/篇**：考题定位+骨架→「立意·骨架」、迁移指南+速记→「迁移·速记」两两合并 + **高度自适应阶梯省略**（渲染-测量-降级，内容超限按语义删行/截断，显式「……」标记，绝不静默截断）。**老版模板兼容（2026-09-09）**：v2.14/2.15 body 平级多 div（无总容器）自动偏移解析，08-28 实测 7 张/篇 | `python 工作流/小红书卡片渲染.py <公众号HTML路径> --out <输出目录>` | venv bs4+playwright+Chrome |
| `HTML转内容文本.py` | **HTML→纯文本结构文件**：默认输出 `.txt`（完整版全部章节）；`--brief` 简化版（≤1000字含空白；规范词2个/分论点1个/句式1个/去emoji/缩进压缩）。**老版模板兼容（2026-09-09）**：v2.14/2.15 body 平级多 div（无总容器）自动偏移解析（头部卡/原文摘录/章节索引），08-28 实测通过；08-26 v2.13 更早模板仍不兼容 | `python 工作流/HTML转内容文本.py <公众号HTML路径> [--brief]` | venv bs4 |
| `知乎HTML生成.py` | **知乎 HTML（v2.17 新增）**：以公众号 HTML(A套)为底，去顶部弱链接、文末加「来源引用卡」（人民日报版次日期+查看原文链接）+「上一篇/下一篇」导航（标题+占位链接 href="#"），输出 `知乎/<标题>_知乎.html` | `python 工作流/知乎HTML生成.py --date <YYYY-MM-DD>`（全量读状态.json selected_articles） | venv bs4 |
| `公众号长图生成.py` | HTML→整图 PNG（归档）+ 4 张分片 `发布长图_<标题>_01~04.png`（按 h2 章节切，每张 80~216 万像素规避微信 600 万限制；**v2.18 增强**：8+ 个 h2 自动走均衡切点 头部+立意/规范词+论证/语录+句式/迁移+速记，实测 156~246 万像素）+ 原文链接.txt | `python 工作流/公众号长图生成.py <文章标题> --date <YYYY-MM-DD或目录>` | venv playwright+Chrome+PIL |
| `封面图生成.py` | **封面图生成（v2.16 本地底图版）**：读 `封面图模版库.json` 按日期轮动选底图，复制直出 `公众号/封面图.png`(900×383)，纯底图不加字；⚠️当前只出公众号封面，知乎封面(16:9 1080×608)待「母图自动裁切」统一实现 | `python 工作流/封面图生成.py --date <YYYY-MM-DD>`（自动读状态.json 选文；`--articles` 可指定） | venv PIL |
| `去水印lama.py` | LaMa 去水印（v2.15 起仅公众号封面备用，小红书 HTML 无水印已退役） | `python 工作流/去水印lama.py <图片或目录> --out <输出目录>` | venv iopaint+torch+opencv+big-lama.pt |
