## 安装规则
- pip 装包**必须加清华源**：`pip install <pkg> -i https://pypi.tuna.tsinghua.edu.cn/simple`（官方源慢/超时）
- 依赖都装进 venv（`envs/default`），**禁止全局安装**
- iopaint 锁 Pillow==9.5.0（Py3.13 装不上高版本）→ `pip install iopaint --no-deps` + 手动补依赖
- zhdate 算农历：`ZhDate.from_datetime(datetime(2026,8,28,12,0))`（传 datetime 不传 date）
