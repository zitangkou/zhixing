# 方法论（流程/SOP 精华）

> 各环节的"正确做法"，供自动化与人工参考。

## 内容生产链路（7步SOP v2.18，含平行产出）
抓取评论版(版面号随日期浮动) → 原文 HTML（步骤1.5 批量，`原文HTML生成.py`，统一版式）→ 5维打分筛选 → 选2篇 → 三刀解剖 → 多平台文案 → 生图 → 自检 → 归档+云端+通知；步骤10-16 = v2.18 增强版平行产出（三刀+两翼，落 `物料/<日期>-v18/`，失败不阻塞主流程，2026-09-18 收敛评审）
- 完整总纲：`工作流/人民日报内容运营_7步完整流程.md`（v2.18）

## 图片链路（小红书：v2.17 标准 7 卡 / v2.18 平行 8 卡，均=双封面+正文）
- **卡片适配铁律（2026-09-05）**：卡片固定 1242×1660，内容超出时由渲染脚本「渲染-测量-降级」循环按章节语义阶梯省略（教学核心=论证方法/套用模板最后删，论据/小结/仿写先删），省略处显式「……」标记+指引看正文长图；短内容章节自动两两合并（考题定位+骨架=立意·骨架，迁移指南+速记=迁移·速记）——空卡与截断都由脚本兜底，不需人工干预
1. `小红书卡片渲染.py` 解析公众号 HTML，按 h2 章节重排成 1242×1660 卡片，文字 100% 准
2. 双封面并出：`01_封面A_大标题品牌色.png`(经典大红) + `01_封面A_分色对撞.png`(上墨黑下米白+红章「申论·精读」)，人工自主选择
3. 正文 5 张：骨架 / 规范词 / 论证骨架(3分论点合一) / 万能句式(3句式合一) / 速记+行动
4. 可读性检测（v2.1 文字级低对比+饱和度），❌必须处理/⚠️人工复核（HTML 渲染无水印，去水印退役）

## 封面链路（模板库模式 v3.0）
读 `物料模板/封面模板库.json` → copy-design → 改文字框（4框：主标题前缀/主标题/副标/日期）→ export → 本地贴方形头像（圆角蒙版+白边不裁圆）→ 封面图.png
- 模板新增：用户 Canva 建模板发短链 → 解析 → 登记 JSON

## 公众号发布（长图方案A）
A套HTML → 长图PNG（750×N，样式100%，剔除原文链接文字+往期）→ 公众号「原文链接」字段填 原文链接.txt 的 URL → 群发（可申请原创，建议文末版权声明）

## 解剖方法论（v2.18 三刀+两翼）
三刀=骨架(归纳概括)→论证方法(论证结构)→规范表达(规范表达)；两翼=前置「考题定位」(主题归类/标题机关/立意路径)+后置「迁移指南」(适用考题⚠️参考/套用警示/今日仿写示范)；总骨架含 开头范式/过渡技巧；语录穷尽开采、动词与骨架同步；精简铁律=字段≤60字。立意与笔法层是 v2.18 对 v2.16 的核心增量（教学级拆解）。

## 模板进化机制
用户驳回 → 根因分析 → 模板版本+0.1 → 物料模板总览登记 → 重做物料 → 重审

## 知识库维护
每日日志（memory/日期.md）→ 增量沉淀长期知识（知识库/）→ 会话开始读 知识库/索引.md
