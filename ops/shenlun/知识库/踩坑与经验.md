## 微信/发布
- 2026-08-28 · 微信编辑器粘贴 HTML 会剥离样式白名单外属性（padding/圆角/line-height 必丢）→ 弃用粘贴，改长图发布
- 2026-08-28 · 公众号后台不支持上传 HTML 文件 → 需 MD 版/长图
- 2026-09-04 · 公众号长图 750×8352px（626 万像素）**超微信 600 万像素硬限制**，上传会被拒/强制压缩致文字模糊；且 1.2MB 大图弱网加载慢 → 解法=按 h2 章节切 4 张分片（每张 80~216 万像素 / 152~486KB）+ 整图仅归档不发布；分片在章节边界切割、无切字问题

- 2026-08-29 · **DeferExecuteTool 传 perform-editing-operations 时 array/number 被序列化成 object/string**（MCP 客户端 bug，非 Canva 接口问题）：错误 `Expected array, received object` + `Expected number, received string`；`page_index: 1` 被当字符串、`operations: [...]` 被当 object 包装；**变通**：换用 find_and_replace_text + 字符串化包装均失败；**当前会话内 perform-editing 完全不可用**（之前 cover 测试偶发能用，本次持续失败）→ 套组方案必须加**手动改字兜底**（生成 design + 发链接 + 用户在 Canva 网页手动改 5 张卡 10 秒）
- 2026-08-29 · **canva 封面模板 DAHToXORtnU 是单页固定布局**（page_count=1, is_responsive=false），双封面是同一页内左右布局；不能直接作为多页套组基础 → 套组必须用多页 design
- 2026-08-29 · **link+search+copy+start+commit+export 链路在当前会话稳定**（除 perform-editing 外），套组方案的非改字部分可放心推进

## 2026-09-05（v2.18 开发与演练期）

1. **iCloud 同步回滚**：iCloud Drive 目录下文件写入并验证通过后，仍可能被旧版本同步覆盖（试产预览 HTML 清理后回滚）。→ **写入后延迟数秒读回复核**；关键清理操作做两次验证。
2. **文件名引号形式陷阱**：生产目录/文件名用**半角引号**（`"渐"的耐心与"进"的节奏`），开发时误用全角引号（`“渐”…`）导致 Read/ls 误报不存在；且部分 grep 工具递归输出时把全角引号显示为半角，造成「存在第二份文件」的误判。→ 路径一律从 `find`/`ls` 输出复制，不要手打引号；权威验证用 python os.walk。
3. **自适应测量的比较对象**：渲染降级循环若用「是否溢出」的布尔值判断降级是否有效，两轮都溢出时会误判「无进展」提前退出（布尔恒 True 相等）→ 必须比较 scrollHeight **数值**是否减小。
4. **bs4 片段 str() 副作用**：`BeautifulSoup(片段, 'lxml')` 再 `str()` 会补全 `<html><body>` 包装——嵌入外层文档靠浏览器容错，但会让正则/统计失真；片段级删行后要清理删空的 div 壳（否则残留空边框卡片）。
5. **卡片省略标记的生成时机**：省略说明文字若在字号缩放（×2.2）前生成会被放大成巨字 → 用原始尺度字号（13px）书写，缩放后自然合理。
6. **历史目录结构陷阱**：早期日期目录（2026-08-26）平台子目录（小红书/抖音）直挂日级，`scan_articles` 类扫描会误当文章名（知乎页脚曾出现「下一篇：小红书」）→ 扫描口径统一为「含 解剖/公众号/小红书/知乎/抖音 任一子目录的一级目录」。
