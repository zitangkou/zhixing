# 申论学习内容体系扩展方案（咨询稿）

> **版本**：v1.0（2026-09-05）｜ **用途**：对外咨询用方案书，供教学、产品、考培等多方面论证
> **核心问题**：现有「三刀解剖」是系统性精读方法（输入端），申论还有多种题型需要专项训练——方法层与输出层的产品如何设计？

## 一、项目背景

### 1.1 品牌与定位

- **品牌名**：杜衡阁（公众号 / 小红书 / 知乎 / 百家号四平台同名）
- **定位**：人民日报评论文章的申论视角精读——「时评精拆」系列
- **目标用户**：公务员考试（国考/省考）备考人群，核心痛点是「读了很多范文还是不会写」「规范表达积累零散」「小题不知道怎么答」
- **内容来源**：人民日报评论版（人民论坛/人民时评/评论员观察/金台随笔/微观等栏目），每日自动抓取

### 1.2 生产模式（核心特色：全自动化内容工厂）

每个工作日早上 6:40，定时任务自动执行 7 步 SOP：

```
抓取人民日报评论版 → 5维度打分筛选 → 自动选文
→ 三刀解剖 → 多平台物料生成 → 规则自检+AI交叉审核 → 归档+云端+通知
```

- 全程无人值守，用户只做事后抽检；每一步有「规则自检脚本」做确定性校验（字段完整性、字数、配色、命名等 30+ 项硬校验）
- 单篇产出周期约 30-60 分钟，人工成本趋近于零
- **已稳定运行**：自 2026-08-26 起每日产出，2026-09-04 起全自动化验证通过

### 1.3 发布形态（四平台差异化）

| 平台 | 形态 | 说明 |
|------|------|------|
| 公众号（杜衡阁） | 长图 4 分片 + 封面图 | HTML 渲染成图发布，规避微信编辑器样式剥离；百家号复用 |
| 小红书 | 图文卡片 7 张 + ≤1000 字纯文本 | 1242×1660 竖版卡片：封面 + 骨架/规范词/论证/句式/速记 |
| 知乎 | HTML 文章 | 公众号内容为底 + 来源引用卡 + 上/下一篇导航 |
| 百家号 | 复用公众号长图 | — |

## 二、三刀法详解（现有核心产品）

### 2.1 方法论定义

「三刀」是对一篇人民日报评论的三层拆解，每刀对应一项申论核心能力：

| 刀 | 拆什么 | 对应申论能力 | 产出物 |
|----|--------|--------------|--------|
| **第一刀 · 看清骨架** | 引题→总论点→分论点（每个分论点拆 标题/论据/小结）→总结 | 归纳概括能力 | 全文骨架箭头流图 |
| **第二刀 · 拆开论证** | 每个分论点的论证方法（正反对比/点例排比/因果论证等）+ 方法说明 + **可迁移的「套用模板」**（如：变"甲"为"乙"亮观点→正面案例佐证→反向推演→比喻收束） | 论证结构能力 | 分论点级论证模板 |
| **第三刀 · 带走表达** | 规范词表（词语+分类+白话释义，≥6个）、权威语录（出处+释义）、高频动词、句式模板（原文/模板/跨主题仿写三层） | 规范表达能力 | 可直接背诵引用的素材包 |

### 2.2 v2.18 升级：「三刀 + 两翼」（2026-09 定稿）

在三刀基础上前后各加一翼，把「拆文章」升级为「教学级拆解」：

- **前置翼「考题定位」**：主题归类（五大领域+话题标签）/ **标题机关**（标题的修辞结构如何统摄全文，如「‘渐’与‘进’的对立统一如何裂变为三个分论点」）/ **立意路径**（现象→矛盾→总论点的完整思维链）——解决「读者看到结论看不到作者怎么想」的问题
- **后置翼「迁移指南」**：适用考题（对接真题命题趋势，标注参考）/ 套用警示（何时不能硬套）/ **今日仿写示范**（150-250 字完整考场段落）——从「看懂」到「能写」
- 总骨架同时新增「开头范式」（切入法+可复制开头模板）与「过渡技巧」（段间衔接笔法）

**一句话概括**：三刀回答「这篇文章好在哪」，两翼回答「我怎么用到这里」。

### 2.3 一个真实样例

以《多想一些 向前一步》（人民日报 2026-08-07，讲外卖「接力送」引出基层善治）为例：

- 标题机关：「多想一些」=态度上的主动预见，「向前一步」=行动上的创新作为——标题即两个分论点的动词化拆解
- 分论点套用模板：`变"甲"为"乙"亮观点 → 点例排比（案例一+案例二）→ 归因分析 → 对仗金句收束`
- 今日仿写示范：把同款骨架迁移到「养老服务」主题，写出 190 字考场段落
- 迁移指南警示：此骨架适治理服务类命题，纯经济产业类需重构，异主题只取句式

### 2.4 方法论演进史（关键决策节点）

| 版本 | 变化 | 驱动因素 |
|------|------|----------|
| v2.9 | 确立 7 步 SOP | 从手工作坊到流程化 |
| v2.15 | 生图改为 HTML 卡片渲染 | AI 生图中文字形崩坏，改代码渲染保文字 100% 准确 |
| v2.16 | 全自动无人值守 | 取消人工审核卡点，规则自检+AI 交叉审核兜底 |
| v2.17 | 四平台定稿 + 长图分片 | 微信 600 万像素限制 → 4 分片发布 |
| **v2.18** | **三刀+两翼 + 平行产出** | **教学质量升级：从「摘抄级」到「教学级」拆解**（对比试产发现：旧版漏收开头切入法、过渡技巧、典故、考题对接等最有教学价值的层） |

## 三、软件产品背景（技术架构与能力边界）

### 3.1 技术栈

- **语言/运行时**：Python 3.13，独立 venv
- **AI 环节**：deepseek-v4-flash（解剖生成、交叉审核、文案），「模板即 prompt」机制——每个产出物有固定模板文件，AI 按模板结构逐项填充，禁止自创结构
- **渲染**：Playwright + Chrome（HTML→长图/卡片截图），文字 100% 准确（绕开 AI 生图不可控问题）
- **解析/处理**：BeautifulSoup、PIL（图片裁剪）、规则正则
- **调度**：WorkBuddy 定时任务（周一至周五 06:40），状态机 JSON 支持断点续跑与幂等

### 3.2 质量保障体系（三层）

1. **规则自检脚本**：30+ 项确定性硬校验（解剖字段完整性/摘录字数/卡片张数命名/配色色号/简化版字数上限/目录结构），exit 0 才放行
2. **AI 四角色交叉审核**：教研审核（内容质量）→ 事实核查（引用逐字比对）→ 视觉审核（可读性专项）→ 合规审核（无违规承诺），任一高严重度问题自动打回重做
3. **可读性检测**：OpenCV 文字级低对比检测（背景/文字对比度、纹理干扰）

### 3.3 能力边界（扩展新产品的技术评估基线）

| 能力 | 现状 | 扩展难度 |
|------|------|----------|
| 按模板生成结构化内容（MD/HTML/JSON） | ✅ 成熟 | 低——加模板文件即可 |
| HTML 渲染出图（长图/卡片，多规格） | ✅ 成熟 | 低——加版式模板 |
| 文本提取与聚合（从历史产出中抽取字段） | ✅ 可行 | 低——解析既定格式的 MD |
| 出题与参考答案生成 | ⚠️ 未验证 | 中——需要出题质量评估（AI 生成题目的一致性/难度控制） |
| 用户提交内容的批改 | ❌ 无 | 高——涉及用户交互端，当前无产品承载 |
| 检索/词典类交互 | ⚠️ 静态库可行 | 中——静态检索页面/资料包易，动态查询需小程序/App |

## 四、申论学习需求分析（空白在哪）

### 4.1 题型 × 学习环节矩阵

申论五大题型：**归纳概括、综合分析、提出对策、应用文（贯彻执行）、大作文**（前三者俗称「小题」）。

```
学习环节        现有覆盖                      空白
─────────────────────────────────────────────────────────
输入·素材积累  ████████ 三刀解剖（每日精读）    —
方法·题型套路  ██       仅大作文论证结构间接覆盖  五种题型的作答方法论未产品化
输出·练习反馈  █        仅「今日仿写示范」静态展示 无练习题、无批改示范、无格式库
```

### 4.2 关键判断

- 三刀解剖对**大作文**是直接训练（立意/结构/论证/语言全覆盖），对小题是**间接**积累（规范表达）
- 小题（尤其归纳概括与公文格式）是多数考生的失分重灾区，恰恰是现有产品的空白
- 素材输入已有每日节奏，缺的是把积累「变成题目、变成词典、变成格式」的产品化路径

## 五、专项训练方案（五个方向详细设计）

### 方向一：「一篇评论两用」——评论变材料（每日模拟题）⭐ 衔接成本最低

- **内容设计**：每天的三刀解剖完成后，将当日评论文章反向改造成 1 道模拟小题 + 参考答案 + 评分要点。题型轮换（周一归纳概括 / 周二综合分析 / 周三提出对策 / 周四应用文 / 周五大作文片段）
- **产出形态**：公众号长图文末新增「📖 今天的题」区块；小红书加 1 张题卡（8→9 卡）；参考答案次日在知乎公布
- **生产方式**：解剖完成后 AI 基于原文出题（出题模板需新建并验证难度一致性）
- **独特卖点**：市面模拟题材料是编造的，此处材料是**当日人民日报真文**——「素材即考题」
- **成本**：每日 +1 次生成 +1 张卡片渲染；**依赖**：出题质量评估机制（新增）
- **风险**：题目难度不稳定 → 需要难度校准样例集；法律/政策类表述需事实核查

### 方向二：规范词词典——从每日积累到可检索资产 ⭐ 零新增生产成本

- **内容设计**：每日解剖的规范词表（8-10 词，含分类+白话释义）自动聚合进一个持续增长的**主题规范词库**（政治/经济/文化/社会/生态五大领域，预计半年积累 1000+ 词）
- **产出形态**：静态检索资料包（网页/表格/PDF 周更）→ 远期可升级小程序查询
- **生产方式**：聚合脚本扫描历史解剖 MD 的规范词表 → 按主题去重合并 → 周更发布
- **独特卖点**：小题作答时「这个词的规范表达是什么」一查即得；词库本身是品牌的**数据护城河**（竞品需要一年才能追平的积累）
- **成本**：一次性开发聚合脚本（半天）；**依赖**：无
- **风险**：无

### 方向三：题型方法论专栏（15-20 期系列）

- **内容设计**：五种题型各出方法论系列——归纳概括「四步法」、综合分析「词句理解三问」、提出对策「主体×维度」矩阵、大作文「立意三问」；每周固定 1-2 期
- **产出形态**：小红书方法论卡片 + 公众号长图文（不依赖每日文章，独立成系列）
- **生产方式**：一次性规划大纲，按周 AI 生成+人工审校
- **成本**：前期策划 1 天 + 每周维护；**依赖**：方法论的权威性需教学方把关（**咨询重点**）
- **风险**：方法论内容同质化严重（市面已饱和），需做出差异化——建议与三刀解剖的真题案例绑定（每个方法论配 3 个人民日报实例）

### 方向四：应用文格式速查库 ⭐ 小红书爆款形态

- **内容设计**：15+ 种公文/应用文格式的「标题-称谓-正文结构-落款」速查卡：倡议书、公开信、通知、短评、编者按、报道、调研提纲、发言稿、工作方案、经验交流材料……
- **产出形态**：小红书系列卡片（格式图解），可做成合集
- **生产方式**：一次性批量制作（模板化程度最高）
- **成本**：一次性 1-2 天；**依赖**：格式准确性需对照最新公文国家标准（**咨询重点**）
- **风险**：低

### 方向五：大作文骨架仿写训练（互动型）

- **内容设计**：每月一个主题发布「骨架仿写题」（给论点套用当月经典模板写分论点）；下期展示优秀仿写+批改点评
- **产出形态**：小红书图文（征集+展示两期循环）；依赖评论区/私信收集用户作业
- **成本**：每月 2 期内容 + 批改人力（可 AI 初批+人工终审）
- **风险**：冷启动期参与度不足；批改质量是口碑关键（**咨询重点**：AI 批改申论的可信度）

## 六、最优方案汇总（推荐路线图）

### 6.1 推荐组合与分期

| 阶段 | 时间 | 上线内容 | 理由 |
|------|------|----------|------|
| **第一期** | 即刻 | **方向二 规范词词典**（聚合脚本+首版发布） | 零新增生产成本，立刻把 10 天积累变成资产 |
| **第二期** | +1 周 | **方向一 评论变材料**（每日 1 题，并入自动化） | 补「输出层」空白，形成「精读→做题→积累」每日闭环 |
| **第三期** | +2 周 | **方向四 应用文格式库**（15 张系列卡） | 小红书引流爆款，一次性制作长期复用 |
| **第四期** | +1 月 | **方向三 方法论专栏** + **方向五 仿写训练** | 待前三期用户反馈定具体选题与节奏 |

### 6.2 产品矩阵终态

```
每日（自动化已就绪）          每周（新增栏目）           资产（持续增长）
├─ 三刀解剖（精读）    →     ├─ 评论变材料（每日1题）   ├─ 规范词词典（周更）
├─ 四平台发布                ├─ 方法论专栏（1-2期）      └─ 应用文格式库
└─ 自检+审核                └─ 仿写征集/点评（月度）
```

### 6.3 不做什么（边界）

- 不做视频课程（生产成本高，非现有能力）
- 不做用户作业的实时批改承诺（口碑风险，仅做精选点评）
- 不引入题库付费/小程序交易（先验证内容价值再说变现）

## 七、咨询问题清单（带着这些问题去问）

### 问教学/考培老师

1. 「评论变材料」的出题质量：AI 基于 1200 字评论出归纳概括题，难度能对标真题吗？需要什么样的题目校准机制？
2. 方向三的方法论体系（如归纳概括「四步法」、对策「主体×维度」），从教学角度看是否有明显漏洞或更优框架？
3. 应用文 15 种格式的清单是否完整？哪些格式近三年考频最高值得优先做？
4. 三刀解剖的「套用模板」（论证结构模板化）会不会导致考生作文模板化扣分？边界在哪？

### 问考生/用户

5. 每天精读一篇+做一道题的组合，你的坚持成本能接受吗？（对比：只看不练的完成率）
6. 规范词词典你期望的形态：网页检索 / PDF 资料 / 小程序查询？
7. 小红书上你见过哪些申论内容形态最想收藏？（验证卡片方向）

### 问产品/技术

8. AI 批改申论作文的成熟度与可信度？如果做方向五的批改点评，人机分工怎么切？
9. 规范词词典做小程序查询的合规与成本？（涉及内容资质）
10. 多平台内容矩阵（图文为主）扩展到题库类产品，运营侧的最大坑是什么？
