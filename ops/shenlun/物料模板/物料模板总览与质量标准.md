# 物料模板总览与质量标准

**版本：** v2.18
**更新日期：** 2026-09-05
**发布与引流：** 公众号文首码、回复数字、H5 入口见同级云盘 [内容运营/杜衡阁公众号发布与引流规范.md](../../内容运营/杜衡阁公众号发布与引流规范.md)（与 `申论学习/`、`政治理论/` 同级）。本文件只管三刀物料模板与质量基线。
**版本号规则（2026-08-31 用户定）：** 全局**只有一套版本号 = SOP 主版本**。所有模板/文档/JSON 统一跟随主版本，不再有子模块独立版本号；子模块的修改时间用 `updated` 字段记录，方案演进记入「打回记录与维护日志」。
**定位：** 人民日报内容运营工作流的「模板中枢」。每个产出物料必须且只能对应一个模板文件，模板是质量基线；审核打回的物料必须反哺模板，形成「产出 → 审核 → 打回 → 模板进化」的持续提升闭环。

## 三、审核打回 → 模板维护机制（核心进化闭环）

### 3.1 处理流程

```
审核打回（用户反馈驳回+原因）
        │
        ▼
① 根因分析：是「模板要求不足」还是「执行偏差」？
        │
        ├── 模板不足 → ② 更新对应模板（详见3.2）
        │              ③ 用更新后的模板重做物料
        │
        └── 执行偏差 → ③ 按现有模板重做物料
        │
        ▼
④ 更新审核记录.md（打回原因、根因、处理结果）
        │
        ▼
⑤ 重新提交审核
```

### 3.2 模板更新规则

- 每个模板文件在 frontmatter 记录 `version: v2.16`（全局唯一版本号，跟随 SOP 主版本），并加 `updated: YYYY-MM-DD` 标记本文件最后修改日期
- 模块/方案演进**不另立版本号**，改用「方案名 + 维护日志」区分（见 §3.4）
- 每个模板末尾固定设「## 打回记录与维护日志」章节，追加记录：

```
| 日期 | 打回物料 | 打回原因 | 根因(模板/执行) | 模板改进点 |
|------|----------|----------|----------------|------------|
| YYYY-MM-DD | 公众号HTML | 排版未用中国红 | 模板 | 补充配色规范 |
```

- 打回记录累积 ≥3 次同类问题 → 将该检查项升级为「质量自检清单」强制项
- 模板更新后，总览文档的映射表同步更新 `updated` 日期

### 3.3 责任分工

- **自动化运行（06:30）**：按模板产出物料 + 自检清单逐项自查
- **人工审核**：对照质量自检清单验收，打回时给出具体原因
- **助手（审核循环）**：根因分析、更新模板、重做物料、记录留痕

## 四、视觉风格体系（主风格 + 主题元素叠加 + 可读性铁律 + 时令装饰）

### 4.0 可读性铁律（第一优先级，2026-08-27 用户强调）

**背景与文字颜色冲突 = 不合格，必须重新生成。可读性优先于一切风格效果。**

1. 对比度硬标准：文字与背景亮度对比 ≥ 4.5:1（简化执行：深字浅底 / 浅字深底二选一，禁止中间地带）
2. 生成 query 必须写明：文字用最深/最浅色与背景强对比、禁止相近色相、纹理/插画区加文字底衬
3. 程序化检测：产出后运行 `工作流/可读性检测.py`（已集成进规则自检，WARN 级提示）
4. 人工终审：交叉审核视觉角色逐卡确认可读性（机器只能测亮度，颜色相配/装饰干扰必须人工看图）

### 4.1 风格定位（2026-08-27 确认：复古油墨风 = 主风格）

**生产模式：模板风格 + 文章主题元素叠加。** 生成卡片时，query 按「风格 + 主题元素」双轨注入——风格保证视觉调性统一，主题元素保证卡片与文章内容共鸣（见 `物料模板/小红书卡片风格库.md` 主题元素库）。

| 层级 | 风格 | 角色 | 说明 |
|------|------|------|------|
| 主风格 | **复古油墨风** | 识别担当（2026-08-27 确认） | 做旧泛黄纸 / 双色印刷 / 老式铅字 / 斑驳油墨，年代日报质感，契合人民日报 IP，识别度极高 |

### 4.3 时令装饰规范（节日 / 季节 / 节气 / 考公节点）

**触发源（按运行日期自动判断）：**
| 类别 | 示例 | 说明 |
|------|------|------|
| 节日 | 元旦 / 春节 / 元宵 / 清明 / 端午 / 中秋 / 国庆 | 大节点全套换肤，小节点轻装饰 |
| 季节 | 春绿 / 夏青 / 秋金 / 冬白 | 季度级配色微调 |
| 节气 | 立春 / 惊蛰 / 清明 / 立夏 / 立秋 / 秋分 / 冬至 等 | 封面角标 + 时令文案（如「今日立秋」） |
| 考公节点 | 国考报名 / 省考 / 出分季 / 考前冲刺周 | 对考公人群精准运营节点，转化力最强 |

**时令皮肤层（只加不改）：**
- 封面角标 / 报头标语（如「今日立秋」「国考报名倒计时」）
- 背景纹理：剪纸 / 水墨 / 霜花 / 银杏 / 烟花 等，按节日与季节取用
- 配色微调：叠加时令色（春节金红、清明淡青、中秋月金），保留平台主色系
- 时令文案与标签、话题词联动（小红书 #立秋 #处暑 等）

**应用范围：** 封面卡 + 页脚/引导卡 + 标签与配文；**不进入内容卡**（保持 8 卡结构、内容文字、审核流程不变）。

**执行方式：** 自动化运行时按日期判定当日时令，将时令要素注入 AI 生图提示词、Canva query 与公众号 HTML 头图；无时令日期则纯主风格。

**合规红线（强制）：** 不使用国旗 / 领导人肖像 / 宗教符号 / 敏感意象；装饰只做氛围，不改变内容严肃性与准确性；节日素材（如春节）不得出现不雅或低俗元素。

### 4.4 单套生成机制（2026-08-27 决策，替代旧双套）

每篇文章的物料**只生成一套最优视觉（A 套主风格）**，不再双套供选，降低生成量与成本：

| 项 | 说明 |
|----|------|
| 生成范围 | 公众号 HTML（A 报纸版 + B 手账版，文本零成本保留）+ 小红书 8 图（单套） |
| 抖音 | **暂不生成**（v2.6），`抖音/` 目录与 `抖音卡片模版.md` 保留，恢复时启用 |
| 备选手账风 | 保留定义（4.1/4.2），需要时恢复双套 |

**目录结构（文章级）：**
```
<文章标题>/
├── 公众号/
│   ├── <标题>_公众号.html              # A 套 · 报纸电子版
│   └── <标题>_公众号_备选手账.html      # B 套 · 手账笔记
├── 小红书/
│   ├── <标题>_卡片文案.md
│   ├── canva预览/                      # Canva 预览稿（01_预览.png~04）
│   └── 图片A-主风格/01_封面.png~08     # 最优一套成品
└── 抖音/（保留待启用，当前不生成）
```

**说明：** ① 小红书成品图 = 主风格（报纸头版识别 + 简洁骨架 + 水墨金句点缀）+ 时令装饰，存 `图片A-主风格/`；② 备选手账风、抖音卡片均保留模板与目录定义，作为恢复开关；③ 恢复双套/抖音时，按旧双套/抖音模板执行即可。

**成本（v2.6 优化后）：** 每篇每日生图量从 32 张（双套×双平台）降至 8 张（小红书单套），ImageGen/Canva 调用量与生成时长约降 75%。
