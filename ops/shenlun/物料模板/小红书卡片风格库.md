# 小红书卡片风格库（Canva Pro 多套模板备用）

## ⚠️ 可读性铁律（第一优先级，2026-08-27 用户强调）

**可读性是底线，任何风格都不得牺牲可读性。** 背景与文字颜色冲突 = 不合格，须重新生成。

1. **对比度硬标准**：文字与所在背景的亮度对比 ≥ 4.5:1（WCAG AA）。执行时简化为——**深字配浅底 / 浅字配深底，二选一，禁止中间地带**
2. **query 必须写明对比规则**：每卡 query 追加「文字用最深色/最浅色，与背景形成强对比，禁止文字颜色与背景相近或同色系」；背景纹理/插画区域需加**文字底衬**（半透明深/浅色块垫在文字下）
3. **禁用搭配**：红字压橙底、深蓝字压深红底、金字压米黄底、白字压浅色插画区等相近色相组合
4. **文字密集卡必须卡片式/底衬布局（v1.4 新增 2026-08-28）**：概览(02)、规范词(05)、论证骨架(06) 三张文字最多、最易与背景冲突——query 额外要求「每行文字配独立浅色/深色底衬条；规范词卡每个词条独立色块卡片式排版；禁止裸文字直接压在插画/纹理上」
5. **程序化检测辅助**：产出后运行 `工作流/可读性检测.py`（v2.1 含**文字级低对比检测** + **整体饱和度检测**），标 ❌ 的图必须处理（换构图/重新生成）；标 ⚠️ 的人工复核
6. **风格禁忌（v1.5 新增 2026-08-28，用户反馈 02/05 字体冲突后定）**：主风格=复古油墨风（暖彩色：做旧泛黄纸+墨黑铅字+朱砂红点缀）。**双保险**——① query 必须写「**禁止黑白灰、禁止冷灰色调、禁止现代扁平风**」锚定句；② 选图时运行可读性检测，**整体饱和度 < 40（黑白灰）的构图一律弃用**，从剩余构图选或重新生成
7. **人工终审**：机器只能测亮度/边缘，**颜色相配与装饰干扰由人工看图最终把关**——交叉审核视觉角色必须逐卡逐行确认可读性，重点检查文字密集卡（见 交叉审核角色定义.md）

## 说明

用于步骤6「生图」的风格选型。**生产模式（2026-08-27 用户确认）：模板风格 + 文章主题元素叠加**——主风格为「复古油墨风」，生成 query 按「风格 + 主题元素」双轨注入（见下方「主题元素库」）。风格库收录已实测探索的视觉风格方向，每组含：关键词、配色、适用场景、可复用的 Canva generate-design query（≤220字）。选定主风格后 → 搭 8 卡模板（模板自动化路线）→ 每日套文案。**用户偏好状态实时更新。**

## 主题元素库（风格 × 主题双轨，v1.1 新增）

生成 query 必须同时注入「风格」+「文章主题元素」，否则卡片空有风格、缺乏主题共鸣。按申论高频主题匹配视觉元素：

| 乡村振兴 | 田野麦浪、村庄、农机、农产品、返乡青年 |

**query 结构（标准模板）**：`小红书[卡片类型]竖版3比4，[风格关键词]＋[主题元素]＋[卡片内容要点]＋文字清晰无错字`

## 使用规则

1. **风格探索期**（当前）：用上述 query 出多组样图，人工选定主风格 + 1~2 组备选
2. **模板固化期**（选定后）：对主风格出 8 卡完整设计规范（布局/配色/字号/元素），在 Canva 搭品牌模板 → 每日复制+替换文字+导出（文字 100% 准、无水印）
3. **时令联动**：节日节点可临时切换到对应风格（如春节=国潮红金），日常保持主风格
4. **query 复用**：每组 query 可直接用于 generate-design，也可改造成 ImageGen 提示词（作背景/装饰图用）
5. **AI 额度注意**：generate-design 每次消耗 Canva AI 额度（Pro 约 500/月），风格探索期集中消耗，模板固化后不再消耗
