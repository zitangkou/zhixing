# 公众号封面图模板（方案：本地底图 + HTML 叠字）

## 说明
用于步骤5「公众号物料」。每日为每篇入选文章生成公众号头条封面。**2026-08-31 起（用户定）：** 放弃旧 Canva 模板库方案（copy-design 多次 MCP 调用、流程重、易失败，2026-08-31 因此跳过封面图），改为 **本地底图模板库模式**——用户手动把封面底图放进 `物料模板/封面图模版/`，程序每日按日期轮动选 1 张，在其上用 **HTML + playwright 渲染叠加动态文字**（标题/期号/日期/栏目等），输出 `封面图.png`。零外部依赖、失败率极低、文字 100% 准确（可先渲染预览再定稿）。

**演进（按时间，不标独立版本号）：**
- 2026-08-28：Canva AI 直出 presentation + 智能裁剪（已弃：文字不可控、裁切到字）
- 2026-08-29：Canva 模板库（copy-design 改文字框）（已弃：流程重、易失败）
- 2026-08-31 起：**本地底图 + HTML 叠字**（启用，待用户补图）

## 底图来源（核心，2026-08-31 建立）
- **存放目录**：`物料模板/封面图模版/`（用户手动放图；放图规范见同目录 `放入说明.md`）
- **登记表**：`物料模板/封面图模版库.json`（机器可读，自动化直接读）——文件名/尺寸/风格标签/文字区坐标/启用状态
- **选图逻辑**：按日期轮动 `(日期 - 起始日) % 模板数`；同一天两篇取相邻序号。可复现、可追溯。模板放好后在此 JSON 的 `templates` 数组登记。
- **头像**：`物料模板/方形头像_杜衡阁.png`（1024×1024，方形原样贴入，**不裁圆**；圆角蒙版+白边）

## 生成步骤（步骤5 内执行，两篇分别）
1. **取底图**：读 `封面图模版库.json` 的 `templates`，按日期轮动算出当日序号，取对应底图文件
2. **叠文字**（HTML 渲染）：以底图为背景，绝对定位叠加以下字段（字体/字号/颜色可调，先用 CSS 控制，可预览）
   - 主标题前缀：`时评精拆｜今日文章`
   - 主标题：`《{文章标题}》`
   - 副标：`人民日报 {YYYY-MM-DD}期 {版次}：{栏目}`（从原文 md 取）
   - 日期：`{YYYY年MM月DD日} · 农历{月日}`（zhdate 算农历 + 节气表）
3. **贴头像**：按 `avatar` 参数把方形头像贴右下（圆角蒙版+白边）
4. **渲染截图**：playwright 截图为 `公众号/封面图.png`（1800×766）
5. 失败兜底：底图缺失/渲染异常 → 记录「封面图未生成」到 README，不阻塞流程

## 规格与安全区
| 项 | 值 |
|----|-----|
| 画布 | 底图原尺寸（建议 1800×766，2.35:1 公众号头条安全区）；做图时核心内容放中间 2.35:1 区域 |
| 文字 | HTML 渲染，程序精确控制，无错字 |
| 配图 | 固定杜衡阁方形头像（本地贴，不耗额度、无上传限制） |
| 输出路径 | `物料/YYYY-MM-DD/<文章标题>/公众号/封面图.png` |

## 质量自检清单（门4 公众号）
- [ ] 1800×766（2.35:1），标题/主题条完整未被裁切
- [ ] 主风格贴合底图；备选底图可用同目录其他图
- [ ] 主标题与原文一致无错字；主题词条「适用申论 · XX主题」
- [ ] 期号与 README 记录一致（时评精拆·第2026-MM-DD期）
- [ ] 饱和度≥40（非黑白灰）；文件名：`封面图.png`
