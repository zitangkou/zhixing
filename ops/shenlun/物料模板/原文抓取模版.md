# 原文抓取模板

## 说明
用于步骤1「自动抓取」。每篇抓取的文章保存为一个 md 文件，命名 `<版次>_<栏目>_<文章标题>.md`，存放于 `物料/YYYY-MM-DD/原文/`。

## 模板

```markdown
# <文章标题>

> **来源**:人民日报 <YYYY年MM月DD日> 第<XX>版 <版面名> | 栏目:<栏目名>
> **链接**: <原文URL>

（正文全文,保留原文分段,不得增删改）
```

## 字段要求

| 字段 | 要求 |
|------|------|
| 标题 | 与版面页标题完全一致,含书名号/引号等原符号 |
| 版次 | 如 04版/05版 |
| 栏目 | 如 人民论坛/大家谈/人民时评/金台随笔/评论员观察 |
| 链接 | 电子版文章页完整URL |
| 正文 | 从 id="ozoom" 或 <!--enpcontent--> 提取,清理HTML标签,保留原文分段 |

## 质量自检清单（门1）
- [ ] 全文完整无缺字、无乱码
- [ ] 标题、版次、栏目、日期、链接准确
- [ ] 正文未增删改,分段保留
