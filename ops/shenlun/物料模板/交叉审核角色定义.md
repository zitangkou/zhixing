# 交叉审核角色定义（多智能体串行审核）

## 说明
用于审核循环。物料产出并通过「规则自检脚本」后，模型**依次**以以下 4 个独立角色视角审查同一物料（多角色串行交叉审核），各自输出结构化问题清单，最后汇总仲裁。每个角色只关注自己的领域，互不干扰，避免单一视角漏检。

**v1.1 变更（2026-08-27）：** 视觉审核员新增「可读性专项」检查（背景/文字对比、纹理干扰、可读性检测脚本结果、主题元素匹配、时令合规），**可读性问题判「高」严重度必须处理**——用户强调可读性是第一优先级。

**v2.18 变更（2026-09-05）：** v2.18 三刀解剖（三刀+两翼）新增字段接入审核——教研审核员新增 5 项立意/笔法/迁移审查，事实核查员新增 2 项（真题不编造/典故出处）；仅适用于 v2.18 版解剖（含「## 考题定位」章节，平行产出落 `物料/<日期>-v18/`），v2.16 旧版解剖按原清单审。

## 审核总流程

```
物料产出 → 规则自检脚本(确定性拦截)
        → 角色1 教研审核
        → 角色2 事实核查
        → 角色3 视觉审核
        → 角色4 合规审核
        → 汇总仲裁（合并问题清单，判定通过/需改）
        → 需改：按清单自动修复 → 复审
        → 通过：标记 ✅已通过，进入下一步
```

## 四角色定义

### 角色 1 · 教研审核员（对应门3 解剖）
**职责：** 从申论教学的专业角度审查内容质量。

**审查清单：**
- 总论点是否一句话准确概括原文核心主张
- 分论点提炼是否忠实原文、逻辑是否层层递进
- 论证方法命名是否准确（点例排比/正反对比/因果论证/时间推进…）
- 套用模板是否真的可迁移（去掉具体内容后框架是否成立）
- 规范词释义是否「白话」到位（读者能否看懂）
- 句式仿写是否与原文主题呼应、可独立使用
- **【v2.18 新增，仅 v2.18 版解剖】** 考题定位 3 项：
  - 标题机关是否点破统摄逻辑（禁止复述标题字面）
  - 立意路径是否完整还原「现象→矛盾→总论点」三步思维链
  - 主题归类是否准确（五大领域+话题标签）
- **【v2.18 新增，仅 v2.18 版解剖】** 笔法 2 项：
  - 开头范式是否提炼为可复制模板（切入法+三步链）
  - 过渡技巧是否注明原文原句、可迁移
- **【v2.18 新增，仅 v2.18 版解剖】** 迁移指南 2 项：
  - 适用考题/套用警示是否可操作（设问方式具体、警示有效）
  - 今日仿写示范是否为完整考场段落（总起+论证+收束，150-250 字）

### 角色 2 · 事实核查员（对应门1/门3）
**职责：** 逐字比对原文，核查引用与事实。

**审查清单：**
- 原文摘录是否与原文逐字一致（不得增删改）
- 金句、语录引用是否准确、出处是否正确
- 论据案例（人名/地名/数字/政策名称）是否与原文一致
- 规范词释义是否偏离原意、是否编造
- 版次/栏目/日期/链接等元信息是否正确
- **【v2.18 新增，仅 v2.18 版解剖】** 迁移指南「适用考题」中的真题引用是否真实存在（年份/层级/主题不得编造；无法确证时必须标注「⚠️ 参考，以真题原文为准」）
- **【v2.18 新增，仅 v2.18 版解剖】** 语录中典故/古诗文出处是否正确（篇名/作者；无法确证时标「出处待核实」而非编造）

### 角色 3 · 视觉审核员（对应门4/门5）
**职责：** 核查排版与图片的视觉规范。

**审查清单：**
- 公众号是否用中国红 #D0021B（无深蓝 #1F3864 混入）
- 小红书是否复古油墨风（油墨黑/旧纸黄/朱砂红）、抖音是否纯黑/亮橙红/亮黄
- 卡片张数、顺序、结构是否正确（小红书8张、抖音8张）
- 字号层级是否清晰、封面标题是否超字数
- 成品图文字是否清晰无遮挡、无错字、无乱码
- 图片是否 3:4 竖版、文件名是否符合规范
- **可读性专项（第一优先级，v1.1 新增，v1.2 强化 2026-08-28）**：
  - [ ] **背景与文字对比是否充足**（深字浅底/浅字深底，无相近色相组合，如红字压橙底、金字压米黄底、深蓝字压深色插画区）
  - [ ] **逐卡逐行/逐词条检查文字清晰可见**——重点卡为**文字密集卡：概览(02)、规范词(05)、论证骨架(06)**（这些卡文字最多、最易与背景冲突）；每行文字、每个规范词条都要能看清，无"文字压在背景图案/纹理上看不清"
  - [ ] **文字区域是否有背景纹理/插画干扰**（花底纹上的小字、装饰元素压字、文字与背景同色系）
  - [ ] 是否已运行 `工作流/可读性检测.py`（v2.0 含文字级低对比检测）且无 ❌ 项；⚠️ 项是否已人工确认；**任一卡出现「低对比文字」提示 → 必须逐行看图确认**
  - [ ] 主题元素与文章主题是否匹配（创新→科技元素，治理→街巷/握手等）
  - [ ] 时令装饰是否合规（无国旗/领导人肖像/宗教符号）、是否只作用封面/页脚
  - **任一卡可读性存疑 → 判「高」严重度，必须换构图/重新生成**（可读性检测 ❌ 的卡一律视为可读性存疑）

### 角色 4 · 合规审核员（对应门4）
**职责：** 核查内容合规与版权边界。

**审查清单：**
- 有无敏感表述、绝对化用语（最/第一/唯一等夸大宣传）
- 有无「必考」「押题」「上岸保证」等违规承诺
- 是否尊重版权（标注来源、说明为学习加工稿）
- 是否混入广告/营销话术、渠道深链是否合规
- 领导人、政策表述是否准确规范

## 问题清单输出格式（每角色）

```markdown
### 角色X · XXX审核
| # | 位置 | 问题 | 严重度 | 修改建议 |
|---|------|------|--------|----------|
| 1 | 分论点2论据 | 案例与原文不符 | 高 | 改为原文表述 |
| 2 | 图3金句 | 错别字"xx" | 高 | 更正为"xx" |
| 3 | 封面标题 | 超20字 | 低 | 精简至16字内 |
```

- **严重度**：高（必须改）/ 中（建议改）/ 低（可忽略）
- 无问题则写「无」

## 汇总仲裁规则

- **判定「通过」**：所有角色均无「高」严重度问题
- **判定「需改」**：任一角色存在「高」严重度问题 → 按清单自动修复 → 复审
- **升级人工**：同一物料复审 3 次仍未通过，或出现「合规」类高严重度问题 → 转人工决策
- 每次审核的问题清单与处理结果，追加到 `物料/<日期>/审核记录.md`

## 与人工的关系（自动为主 + 抽检兜底）

- 交叉审核**自动执行**，通过即进入下一步，不阻塞流程
- 人工从「逐项审核」降级为「抽检 + 终审」：
  - 抽检：每天随机抽查 1 个物料核对审核质量
  - 终审：交付前对「合规类」问题做最终确认
  - 异常决策：交叉审核 3 次不通过 / 选文分差过小 / 合规存疑时人工介入
