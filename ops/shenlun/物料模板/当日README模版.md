# 当日 README 模板

## 说明
用于步骤7「目录维护」。生成 `物料/YYYY-MM-DD/README.md`,作为当日运行的完整记录与交付说明（汇总入选的 2 篇文章）。

**v1.1 变更（2026-08-27）：** 每日入选 2 篇文章，加工物料按文章名称分目录归档。
**v1.2 变更（2026-08-27）：** 公众号/小红书/抖音 A/B 双套生成，README 记录风格选择结果。
**v1.3 变更（2026-08-28）：** ① 生图收敛单套（v2.6 起），产出清单更新为 图片A-主风格/（去水印前原始）+ 图片/（去水印后成品）；② 公众号新增封面图产出；③ 抖音暂不生成标注。
