# 小红书发布 · 详细文档说明 + Canvas 生成用 MD

以下是两份文档，第一份是完整的小红书运营流程说明，第二份是可直接交给 Canvas 生成图片的 MD 文档。

# 文档一：小红书内容发布 · 详细流程说明

## 一、整体流程概览

从“人民日报选文”到“小红书发布完成”，共8个环节，总耗时约3.5小时（熟练后约2.5小时）。

text

选文 → 精读 → 三刀解剖 → 转化卡片 → 制作图片 → 撰写文案 → 发布 → 互动复盘
30min   45min   30min      20min      60min      20min     5min     15min

|环节|耗时|产出物|工具|
|---|---|---|---|
|① 选文|30min|文章链接|人民日报App|
|② 精读|45min|标注版原文|手机备忘录|
|③ 三刀解剖|30min|MD文档|Typora / VS Code|
|④ 转化卡片|20min|8张卡片文案|已定模板|
|⑤ 制作图片|60min|8张PNG图|Canva|
|⑥ 撰写文案|20min|正文文案|已定模板|
|⑦ 发布|5min|已发布笔记|小红书App|
|⑧ 互动复盘|15min|数据记录|复盘表|

---

## 二、各环节详细操作说明

### 环节①：选文（30分钟）

**目的：** 找到适合解剖的人民日报文章

**选文标准：**

|维度|标准|排除|
|---|---|---|
|来源版面|人民时评、人民论坛、评论员文章、暖闻热评|纯新闻、数据公报、文件全文|
|主题|民生、治理、改革、发展、生态、文化、创新|纯外交、纯军事、纯党建理论|
|长度|1000-1500字|超过2500字的深度长文|
|结构|有清晰分论点（2-4个）|散文式、叙事式|
|发布时间|当日或前一日|超过一周的旧文|

**操作步骤：**

1. 每天早上 7:00-7:30，打开人民日报App → 点击“评论”频道
    
2. 浏览当日评论文章列表（通常3-5篇）
    
3. 按标准选1篇，将文章链接复制到备忘录
    
4. 在“选文记录表”中记录标题和日期
    

**选文记录表模板：**

text

【选文记录 · 2025年8月】
□ 8/24  从“一刻钟”悟发展之道（人民论坛）✅
□ 8/25  待选
□ 8/26  待选
□ 8/27  待选

---

### 环节②：精读（45分钟）

**目的：** 充分理解文章，标记关键信息

**操作步骤：**

1. 将文章全文复制到手机备忘录或电脑Word
    
2. 用高亮/标记三类内容：
    
    - 黄色高亮：核心论点句（总论点 + 分论点）
        
    - 绿色高亮：规范词 / 金句
        
    - 蓝色高亮：案例 / 论据
        
3. 精读完成后，确认能回答三个问题：
    
    - 文章的总论点是什么？
        
    - 分论点有几个？分别是什么？
        
    - 最值得记忆的金句是哪句？
        

---

### 环节③：三刀解剖（30分钟）

**目的：** 将文章拆解为可复用的申论素材

**操作步骤：**

1. 复制已有的“三刀解剖MD模板”
    
2. 按模板结构填充内容
    
3. 保存为 `文章标题.md`
    

**解剖内容检查清单：**

|□|检查项|标准|
|---|---|---|
|□|原文摘录|200字以内，保留核心金句|
|□|总骨架|有总论点+分论点结构|
|□|分论点拆解|每个有标题/论据/小结/论证方法/模板|
|□|规范词|至少6个，含分类和白话释义|
|□|语录|至少2条，含出处和释义|
|□|高频动词|至少4个|
|□|句式模板|至少3个，含原文/模板/仿写|

---

### 环节④：转化为小红书卡片文案（20分钟）

**目的：** 将MD解剖内容精简为8张卡片的文字

**卡片转化对照表：**

|卡片|来源模块|精简原则|
|---|---|---|
|图1 封面|文章标题+核心主题|标题不超过20字|
|图2 概览|原文头部信息|3行以内|
|图3 金句|语录模块|选1-2句最强金句|
|图4 骨架|总骨架模块|文字流程图格式|
|图5 规范词|规范词表|选6个最核心|
|图6 论证骨架|分论点拆解|选最精彩的1个|
|图7 万能句式|句式模板|选1个最易套用|
|图8 速记卡|总结+语录+案例|极简可直接背诵|

---

### 环节⑤：制作图片（60分钟）

**目的：** 用Canva将卡片文案制作成8张图片

**统一视觉规范：**

|元素|规范|
|---|---|
|主色|深蓝 #1F3864|
|辅色|金色 #C9A85C|
|背景|米白 #FAF9F5 / 纯白 #FFFFFF|
|字体|思源黑体 / 阿里巴巴普惠体|
|封面比例|3:4（1242×1656像素）|
|内页比例|3:4（统一）|

**Canva操作流程：**

1. 创建新设计 → 自定义尺寸 1242×1656像素
    
2. 设置背景色
    
3. 添加文字框，按卡片文案输入内容
    
4. 添加装饰元素（图标、线条、色块）
    
5. 导出PNG
    

**效率建议：** 首次制作时花时间做好模板，在Canva中保存为“品牌模板”，后续每篇只需替换文字，30-40分钟完成8张图。

## 三、效率优化建议

### 批次处理法

|日期|做什么|
|---|---|
|周一至周五早上|选文+精读+解剖（只做文字部分，30-40分钟/天）|
|周六上午|集中将本周5篇解剖内容转化为卡片文案（1.5小时）|
|周日下午|集中制作图片（3小时，用Canva模板批量替换）|
|每天晚上|定时发布次日内容|

### 模板复用原则

**只做一次的事情：**

- Canva品牌模板（8张图的排版）
    
- 正文文案结构
    
- 标签池
    
- 复盘表
    

**每次都做的事情：**

- 替换文字内容
    
- 添加个性化仿写
    
- 发布+互动
    

### 一鱼多吃

同一篇解剖内容，分发到三个平台：

|平台|形态|侧重点|
|---|---|---|
|小红书|8张图+短文|视觉化干货，碎片化积累|
|微信公众号|长文排版|系统化深读，全文拆解|
|抖音/视频号|口播视频|讲1个句式/1个词，30秒|

## 四、30天运营里程碑

|阶段|时间|目标|行动重点|
|---|---|---|---|
|启动期|第1-7天|发布7篇，跑通流程|先完成再完美，熟悉模板|
|稳定期|第8-21天|发布14篇，数据记录|形成固定节奏|
|优化期|第22-30天|发布21篇，优化方向|根据数据调整选题|

---

## 五、常见问题与应对

|问题|应对方案|
|---|---|
|某天实在没时间|提前一晚用30分钟做好解剖，图片用模板快速替换|
|数据不好，没动力|看单篇涨粉而不是浏览量，收藏率>3%就是好内容|
|仿写不出来了|直接用模板套用最熟悉的话题|
|担心内容同质化|不定期加入“读者答疑篇”“月度合集篇”|
|找不到合适的文章|周末提前储备2-3篇备用|

# 文档二：Canvas（Canva AI）生成用 MD

> 本部分用于步骤6「Canva AI 预览稿生成」。Canva 作为小红书/抖音卡片图的 **AI 生成源**：用卡片文案构造 query 调用 Canva `generate-design`，产出 AI 风格预览稿（存 `canva预览/`）作为视觉风格参考；正式成品图以 ImageGen 为主（文字可控），Canva 预览稿文字准确时可直接采用。

## 一、Canva generate-design 调用规范

| 参数 | 值 | 说明 |
|------|-----|------|
| design_type | `xiaohongshu` | 小红书笔记设计类型 |
| query | 见下方「query 构造模板」 | 直接使用中文，包含卡片视觉规范与关键文字 |
| 输出 | 4 个 AI 构图（url + thumbnail） | 下载 thumbnail 到 `小红书/canva预览/01_预览.png`~`04_预览.png` |

**query 构造模板（小红书版）：**

```
小红书笔记封面/信息卡设计，竖版3比4。
配色：深藏蓝 #1F3864 主色，金色 #C9A85C 辅色，米白/纯白背景。
风格：极简、扁平、优雅留白、文艺感。
共8张卡片，内容与版式：
图1 封面：标题"<封面主标题，≤20字>"，副标"三刀解剖法·人民日报时评拆解"
图2 概览：<文章核心信息3行内>
图3 金句："<金句1>"
图4 骨架：总论点→分论点1→分论点2→分论点3 箭头流程图
图5 规范词：6个规范词+白话释义
图6 论证骨架：四段式（提出论点/论据排比/升华收束/论证方法）
图7 万能句式：类型+原文+模板+仿写
图8 速记卡：速记要点+行动清单
文字清晰准确，不要出现错别字。
```

**使用要点：**
1. 生成后先检查 4 个构图的文字：文字准确且风格达标的，可挪为成品图（复制到 `图片/` 并重命名为 `0X_xxx.png`）；有错字/水印的仅作风格参考
2. Canva AI 图带「包含AI生成」水印：作为成品前需在 Canva 中打开设计链接（url）精修去水印，或在审核记录/README 标注「预览稿待精修」
3. Canva 免费版限制：AI 生成的设计无法直接导出/定位 design_id，只能下载预览缩略图；正式导出能力需 Canva Pro（品牌模板链路），升级后流程另行升级
4. 若 Canva generate-design 调用失败，跳过预览环节直接 ImageGen 出成品图，并在 README 记录「Canva 预览未生成」
