# 筛选清单模板（含确认结果）

## 说明
用于步骤2「AI初步筛选」和步骤3「自动选文（每日2篇）」。生成 `物料/YYYY-MM-DD/筛选/候选清单.md`，选定 2 篇文章后追加「确认结果」部分。

**v1.1 变更（2026-08-27）：** 每日入选文章由 1 篇改为 2 篇（总分前2名，均≥21分自动入选），确认结果列出两篇；入选文章在 `物料/YYYY-MM-DD/<文章标题>/` 下各建目录归档加工物料。

## 模板

```markdown
# 候选清单 · YYYY-MM-DD

抓取来源:人民日报 <日期> 04版【人民论坛】+ 05版评论

## 候选文章（按总分排序）

### 第1名 <总分>/25 分  ★★★
- 标题:（文章标题）
- 栏目:（栏目名）
- 链接:（原文URL）
- 打分:主题价值X | 申论适用性X | 结构可拆性X | 金句密度X | 时效性X
- 推荐理由:（1-2句,说明为何值得拆解、适用什么申论主题）

### 第2名 <总分>/25 分  ★★
（同上结构）

### 第3名 ...
（同上结构）

---

## 确认结果

- 入选文章1:（文章标题）  总分:（X/25）  依据:（自动:≥21分且领先第3名≥3分 / 人工指定原因）
- 入选文章2:（文章标题）  总分:（X/25）  依据:（同上）
- 确认时间:YYYY-MM-DD HH:MM
- 状态:（待确认 / 已确认）
- 入选文章物料目录:物料/YYYY-MM-DD/<文章标题1>/ 、物料/YYYY-MM-DD/<文章标题2>/
```

## 打分维度（每项1-5分）

| 维度 | 说明 |
|------|------|
| 主题价值 | 话题是否重要、贴合时事热点 |
| 申论适用性 | 能否作为申论大作文素材（治理/民生/发展/创新等高频主题） |
| 结构可拆性 | 分论点是否清晰（2-4个），论证方法是否典型 |
| 金句密度 | 是否包含可背诵的规范词、金句、万能句式 |
| 时效性 | 是否回应近期热点事件 |

## 星级标准
- ★★★ 强烈推荐（≥21分） / ★★ 推荐（16-20分） / ★ 一般（≤15分）

## 入选规则（每日2篇）
- 取总分前 2 名；两篇均 ≥21 分且第2名与第3名分差 ≥3分 → 自动入选
- 否则标记「需人工确认」，由用户从候选清单中指定两篇
- 同分时优先「评论性强」（观点鲜明、贴近时事热点）的文章

## 质量自检清单（门2）
- [ ] 全部候选文章均列出，无遗漏
- [ ] 打分有依据，推荐理由贴合文章实际
- [ ] 排序合理，标注星级与默认选择
- [ ] 确认结果写明入选2篇文章与各自依据
- [ ] 为每篇入选文章创建物料目录 物料/YYYY-MM-DD/<文章标题>/
