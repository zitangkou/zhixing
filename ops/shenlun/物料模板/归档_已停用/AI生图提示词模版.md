# AI 生图提示词模板（小红书版 / 抖音版）

## 说明
用于步骤6。将卡片文案逐张转化为文生图提示词/Canva query，**v2.7 起主用 Canva Pro `generate-design` 直出成品**：
1. **Canva Pro 直出（主，v2.7）**：按 `物料模板/小红书卡片风格库.md` 的「风格+主题元素」双轨 query 结构，逐卡调用 generate-design（design_type=xiaohongshu），最佳构图下载作成品（存 `图片A-主风格/`），其余作备选（存 `canva预览/`）
2. **ImageGen（停用，v2.7 起不再调用）**：本模板的提示词规则仍可作为 query 提炼参考，但不再用于 ImageGen 生成成品
3. 可读性检测：产出后运行 `工作流/可读性检测.py`，❌ 图重新生成/换构图，⚠️ 图人工复核

## 通用规则
- 使用中文自然语言描述，query 每组 ≤220 字（Canva 上限）
- 颜色用中文名称，不使用十六进制色号
- 不使用 Emoji 和特殊符号
- 文字内容用引号标出，明确区分指令和显示内容
- 每张卡片对应一个 query，图片统一 3:4 竖版（1242×1656）
- **可读性铁律（v1.2 起强制，用户强调第一优先级）**：
  - 每组 query 必须写明文字与背景对比：如「文字用最深色/最浅色，与背景形成强对比，禁止文字颜色与背景相近或同色系」
  - 有纹理/插画背景时必须写「文字下方垫半透明底衬」
  - 禁止相近色相搭配（红字压橙底、金字压米黄底、深蓝压深红等）
  - 产出后运行 `工作流/可读性检测.py`，❌ 图重新生成，⚠️ 图人工复核；最终可读性由交叉审核视觉角色人工看图把关

## 备选风格 · 学霸笔记/手账风提示词结构（v1.4 起，B 套）

**通用要点：** 风格关键词「手账笔记风 / 学习笔记 / 手写感」，配色墨蓝 #2B3A67 + 荧光黄 #FFF3B0 + 荧光蓝 #BDE3F2 + 荧光绿 #C9F0C9 + 笔记本纸底 #FBF8F1（用中文描述：墨蓝、荧光黄、荧光蓝、荧光绿、米黄笔记本纸）。每组 ≤150 字、中文颜色、无 Emoji 无色号，文字用引号标出。

**小红书 B 套（8张）：** 手账笔记卡——封面「人民日报这样读 / 申论下笔有神」手写体+胶带贴纸角标；概览=笔记本纸横线底+荧光笔标题；金句=蓝色荧光划线+手写批注「重点背」；骨架=手绘箭头流程图+便签纸分论点；规范词=荧光黄高亮词条+手写释义；论证=贴纸式四段卡片；句式=笔记本页+红色批注圈圈；速记卡=上下两格（速记要点+行动清单勾选框）。

**抖音 B 套（8张）：** 笔记大字重点勾画——纯黑底+荧光黄超大粗体标题（圆圈/划线强调）、手写风副标；图8 关注卡=纯黑底「每天拆一篇人民日报」+荧光黄下划线+亮橙按钮。

**成品图质量要求（门5）**
- 3:4 竖版，文字逐字核对无错字（标题/金句/规范词是重灾区）
- 文字清晰无变形、无遮挡、无乱码
- 与提示词描述一致，风格统一
- 文件命名：`01_封面.png` ~ `08_速记卡.png`（抖音：`08_关注引导卡.png`）
- Canva AI 预览稿存 `canva预览/`（命名 `01_预览.png`~`04_预览.png`），采用为成品前清理/标注 AI 水印
- **双套（v1.4）：** A 套存 `图片A-主风格/`，B 套存 `图片B-备选/`，均 01~08 命名；人工选定后复制到 `图片/`

- [ ] 文字内容与卡片文案逐字一致
- [ ] 提示词可直接用于 ImageGen 成品图，也可提炼为 Canva query 出预览稿
- [ ] 每篇每平台已生成 Canva AI 预览稿（canva预览/ 主风格 + canva预览B/ 备选）
- [ ] 每篇每平台已生成两套成品图（图片A-主风格/ 与 图片B-备选/ 各 8 张）
