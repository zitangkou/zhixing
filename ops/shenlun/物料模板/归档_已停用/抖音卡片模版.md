# 三刀解剖 · 抖音图文卡片模板

## 说明
用于步骤6「抖音版」。基于小红书8张卡改造：大字、强对比、快节奏；规范词精简为3个；图8为关注引导卡。产出：8张卡片文案 + 8组AI生图提示词 + Canva AI 预览稿（存 canva预览/）+ 8张成品图（3:4竖版，ImageGen 主出）。

**v1.1 变更（2026-08-27）：** 接入 Canva 生成源——先用 Canva `generate-design`（design_type=poster，query 含抖音8卡视觉规范与文字要点）产出 AI 风格预览稿存 `抖音/canva预览/`，作风格参考与成品兜底；正式8张成品图以 ImageGen 为主（文字可控），预览稿文字准确时可直接采用（复制到 图片/ 并重命名，采用前清理 AI 水印）。

## 小红书 → 抖音 调整规则

| 维度 | 小红书 | 抖音 |
|------|--------|------|
| 封面背景 | 深蓝底 | **纯黑底** |
| 点缀色 | 金色 | **亮橙红 #FF4D2E + 亮黄 #FFC300** |
| 标题字号 | 60-80px | **80-100px 超大** |
| 规范词数量 | 6个 | **3个（精选最核心）** |
| 分论点展示 | 完整拆解 | **只留核心公式** |
| 万能句式 | 原文+模板+仿写 | **模板+仿写,原文省略** |
| 最后一张图 | 速记卡+行动清单 | **关注引导卡** |
| 底部引导 | 评论仿写打卡 | **关注+进主页** |
| 内容风格 | 干净优雅留白多 | **大字、强对比、快节奏** |

## AI生图提示词规则（抖音版）
- 每组 ≤150 字，中文自然语言描述，无 Emoji 无色号
- 颜色用中文：纯黑、深藏蓝、亮橙红、亮黄、暗金、灰、暖米白
- 文字内容用引号标出，明确区分指令与显示内容
- 每张对应一个提示词，参照上述卡片文案逐张编写
- 提示词双用途：ImageGen 成品图（主）+ 提炼为 Canva generate-design query 出预览稿（辅）

## Canva AI 预览（抖音版）
- 调用 Canva `generate-design`，design_type=poster，query 含：纯黑底/亮橙红+亮黄/大字强对比/8张卡（封面"人民日报这样读"、今日拆解、金句、骨架、规范词3个、论证公式、万能句式、关注引导卡）
- 下载返回的缩略图到 `抖音/canva预览/01_预览.png`~`04_预览.png`
- 预览稿带「包含AI生成」水印，采用为成品前需在 Canva 中打开链接精修去水印，或标注「预览稿待精修」
- Canva 免费版无法导出 AI 生成设计（无 design_id），仅能下载预览图；正式导出需 Canva Pro（品牌模板链路）

## 风格与时令（v1.3 起）
- 报纸头条风：封面卡可加红报头栏 / 大字头条样式 / 网格底纹（见模板总览 4.1-4.2）
- 时令装饰：封面大字标签按当日时令注入（如「今日冬至」「国考报名倒计时」），配色微调保留纯黑+橙红+黄主系（见模板总览 4.3）
- 合规：不使用国旗/领导人肖像/宗教符号，装饰不改内容严肃性

## 备选风格 · 手账笔记大字版（v1.4 起，B 套）
- 产出：A 套（报纸头条大字）存 `图片A-主风格/`，B 套（手账笔记大字）存 `图片B-备选/`，均 01~08 命名
- B 套视觉：纯黑底 + 荧光黄 #FFF3B0 超大粗体（圆圈/下划线强调）+ 手写风副标 + 亮橙 #FF8A3D 按钮；图8 关注卡=「每天拆一篇人民日报」+荧光黄下划线
- Canva 预览：A 套存 `canva预览/`，B 套存 `canva预览B/`
- 人工选定后复制到 `图片/` 作为正式成品，未选中套保留追溯
