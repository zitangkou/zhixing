# 小红书卡片模板搭建规范（v1.0 · 5 卡套组）

> 配套《小红书卡片文字结构规范.md》使用：文字结构规范管「每卡放什么字段」，本规范管「每卡怎么排版、字号多少、怎么搭」。
> 用途：指导在 Canva 搭出 5 页套组模板（多页 design），后续自动化 copy → 改字 → 导出。

---

## 一、小红书平台规范（硬标准）

| 项 | 值 |
|----|-----|
| 画布尺寸 | **1242×1660 px**（3:4 竖版，官方推荐清晰度） |
| 图文张数 | 我们 5 张（平台上限 18 张，5 张是干货类黄金数量） |
| 安全边距 | 四边留白 **≥ 80px**（防发布时边缘裁切，文字/关键元素不进 80px 内） |
| 首图（卡1 封面） | 决定点击率，主标题要大、要一眼看懂 |
| 字号下限 | 正文最小 **36px**（缩略图/手机端仍可读；再小会糊） |

## 二、通用视觉规范（复古油墨风 · 5 卡统一）

| 项 | 值 |
|----|-----|
| 纸底 | 米白做旧 `#F5F0E6`（全 5 卡统一底） |
| 主文字 | 墨黑 `#1A1A1A`（正文/标题） |
| 点缀 | 朱砂红 `#C03028`（标签/印章/分隔线/编号） |
| 次要文字 | 深灰 `#5A5A5A`（出处/日期/注释） |
| 字体 | 标题用**宋体/衬线**（报纸铅字感），正文用**思源黑体**（清晰） |
| 可读性铁律 | **深字浅底**，对比 ≥4.5:1；禁止浅字浅底、禁止彩色字压花纹 |
| 文字框原则 | 每个字段 = **一个独立可编辑文本框**（自动化改字目标）；文本框留 10-15% 宽裕防溢出 |

---

## 三、每卡文字框规范（逐框 checklist）

> 字号为 px；「字数上限」超出会溢出，务必遵守。位置按「上/中/下 + 左/中/右」描述，搭模板时大致对齐即可。

## 四、可动 / 不可动元素

| 类型 | 举例 | 是否可动 |
|------|------|---------|
| 文字框（上面所有字段） | 主标题/金句/规范词… | ✅ 可动（自动化改字目标） |
| 纸底背景 | 米白做旧底 | 🔒 锁死 |
| 装饰元素 | 印章/分隔线/编号圆点/角标 | 🔒 锁死（统一风格） |
| 主题角标位 | 预留装饰区（后续换主题元素） | ⏸ 暂留空，后续按主题替换 |

## 五、套组搭建步骤（Canva 操作）

1. Canva → 新建设计 → **自定义尺寸 1242×1660**
2. 做卡1 封面（放 4 个文字框，按上表）
3. 右上「复制页面」→ 得到第 2 页 → 删掉封面文字框 → 放卡2 的 7 个文字框
4. 重复到第 5 页（共 5 页 = 5 卡）
5. 统一设置：全选 → 纸底米白 / 字体（宋体+思源黑体）/ 配色
6. 保存，复制地址栏链接发我

## 六、发我链接前的自检

- [ ] 5 页齐全，页序 = 卡序（封面→骨架→金句规范词→论证句式→速记卡）
- [ ] 每个字段都是**独立文本框**（不是拼在一个框里）
- [ ] 文字都 ≥36px，深字浅底，无彩色字压花纹
- [ ] 文字不贴边，四边留白 ≥80px
- [ ] 字数按上表上限控制（尤其主标题≤20、金句≤40）
- [ ] 风格统一：纸底/字体/点缀色一致
