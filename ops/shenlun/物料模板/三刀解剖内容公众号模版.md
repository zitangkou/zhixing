# 公众号文章 Markdown 模板（方案：发布用）

## 说明
用于步骤5「公众号物料」。**公众号发布工具不支持 HTML 文件格式**，需产出 Markdown 版物料（2026-08-28 用户反馈）。内容结构与 HTML 版（A 报纸版）完全一致，仅排版换为 Markdown（表格/加粗/引用/分隔线）。

**v1.0（2026-08-28）：** 初版。单套 MD（对应 A 套内容）；HTML 双套保留作预览/存档。

## 使用
- 生成路径：`<文章标题>/公众号/<标题>_公众号.md`
- 生成规则：**必须先按 三刀解剖内容公众号模版.html 完成 HTML 双套**，再按其 A 套内容转写为 MD（内容逐字一致，禁止增删）
- 顶部规则（2026-08-28 用户定）：开篇引导含可点击原文链接；原文速览落款**不带作者名**，只写「——人民日报 YYYY年MM月DD日第XX版」
