# 政治理论每日出题 · 工作流脚本

本目录存放「每日人民日报政治理论出题+运营物料」自动化流程的生成脚本。

## 脚本清单

| 脚本 | 功能 | 用法 |
|------|------|------|
| `gen_rmrb_card_html.py` | 公众号HTML + 小红书22张卡片 | `python gen_rmrb_card_html.py --date YYYY-MM-DD --title "文章标题"` |
| `gen_rmrb_long_zhihu.py` | 公众号超长图+4张分段长图 + 知乎HTML | `python gen_rmrb_long_zhihu.py --date YYYY-MM-DD --title "文章标题"` |
| `gen_structure_html.py` | 结构化MD → 三刀样式展示HTML（每日必做） | `python gen_structure_html.py --md <结构化MD> --title <标题> --source <来源> --date <日期> --link <URL> [--subtitle] [--out]` |
| `gen_origin_html.py` | 原文txt → 三刀样式汇总原文HTML（分卷文章用） | `python gen_origin_html.py --txt <原文txt> --title <标题> [--source] [--meta] --out <输出>` |
| `gen_paper_md.py` | 单篇文章题目JSON → 后台导入格式套题MD | `python gen_paper_md.py --date YYYY-MM-DD --title "文章标题"` 或 `--json <题目.json>` |
| `gen_rmrb_20260904_questions.py` | 出题引擎参考模板（09-04实例） | 参考用，含20题完整定义+校验+价值分逻辑 |
| `gen_rmrb_sco_questions.py` | 出题引擎参考模板（09-02实例） | 参考用，上合讲话20题 |

## 输入要求

两个生成器均从云盘读取题目JSON（自动定位文章聚合目录 `物料/<date>_<文章名>/`，优先于 `物料/<date>/`）：
```
政治理论/物料/YYYY-MM-DD_文章标题/题目/人民日报YYYY-MM-DD_文章标题_20题.json
```

JSON必须包含（2026-09-07 更新，与模拟套题字段规范对齐）：
- 顶层：`value_score`（数字，禁止硬编码92）、`value_label`（标签文本，仅存JSON供管理）、`material_anchor`（原文链接URL，供知乎/公众号原文链接与原文链接.txt）、`answer_distribution`（A/B/C/D分布）
- `questions[]`：每题含 `question_id/stem/options(A-D)/answer/explanation/distractors/source_ref/topic/tag/subtype/difficulty`
- `tag` 必须用**字符串**（禁止数组，否则小红书卡标题栏会泄漏 Python 列表，如"['根本任务','贺信']"）
- `subtype` 用**题型**（直接判断/组合/计数），不用考点分类
- 组合/计数题在 JSON 加 `answer_short` 供速查卡展示

**生成器版本约束（2026-09-07 确立）**：
- 唯一代码来源：本目录（`政治理论/工作流/`）下的 `gen_rmrb_*.py`
- **严禁使用** `/Users/dnn/Projects/zhixing-gongkao/scripts/xingce/` 下的旧版生成器（无五题版、无原文链接.txt、价值分硬编码92，已废弃；09-06/09-07 每日物料旧版样式即由此产生）

## 结构化文档转换（MD + HTML，2026-09-09 起，每日必做）

- **对象**：当日确定出题的文章（头版 S1/S2 或理论版备选文章），跳过日不生成
- **步骤**：
  1. 按《物料模板/文章转MD结构化文档经验总结.md》把原文转为结构化 MD——三章结构（总论/分论/保障）→ 每节 `>` 引用块完整保留原文、小节名粗体 → 节末【关键词】块（3-8个、`/`分隔）→ 文末可附核心概念速查表
  2. **文首标签/分类（2026-09-10 起必做）**：结构化 MD 第一个 `## 章` 之前的引用块须含 `> 标签：a, b, c`（3-8个文章级标签）与 `> 分类：xxx`（主题分类，如 思想理论/大国外交/经济发展/生态文明）；节末【关键词】不是文章标签；渲染时自动抽取，必要时用 `--tags/--category` 覆盖
  3. 运行通用渲染脚本 `工作流/gen_structure_html.py` 把同一结构渲染为三刀解剖样式 HTML
- **产物**：`素材/人民日报YYYY-MM-DD_文章名_结构化MD.md` + `素材/人民日报YYYY-MM-DD_文章名_结构化HTML.html`（引导卡含 标签/分类 行）
- **HTML 样式规范**（对齐 zhixing 三刀解剖 displayHtml，已实渲染验证）：报头红字三段式（人民时评·精读系列/标题/副标题）→ 引导卡浅红底+左侧红条（含 **标签：** / **分类：**，供知行后台导入抽取）→ 章标题红字+红下划线 → 节标题红徽章+标题 → **整节一张连续灰卡**（小节名红色加粗、段间紧凑）→ 关键词浅红卡文本流（`·` 分隔，**不是**文章标签）；全内联样式
- **知行导入约定（2026-09-10）**：引导卡须有 `标签：A · B · C`（或逗号）与 `分类：思想理论`。分类名必须已在知行「分类管理」中。节末【关键词】不要写入标签行。
- **渲染脚本用法**：`python3 工作流/gen_structure_html.py --md <结构化MD> --title <标题> --source <来源> --date <日期> --link <原文URL> [--tags "思想建设,理论武装"] [--category "思想理论"] [--subtitle] [--out]`
  MD 文首 `> 标签：` / `> 分类：` 会被写入引导卡；CLI 可覆盖。缺省标签 `政治理论`、分类 `思想理论`。

## 套题MD文档（2026-09-10 起，每篇理论文章必做）

- **对象**：每篇理论文章的 20 题（含每日出题日文章与跳过日复制的 T0c 卷题目）
- **脚本**：`工作流/gen_paper_md.py --date <日期> --title <文章名>`（或 `--json <题目.json>` 直接指定）
- **产物**：`文章目录/题目/人民日报<date>_<title>_20题_后台导入.md`
- **格式**：题干 `**N. …**` 粗体 + `A．B．C．D．` 选项 + `> **答案：**`/`> **原文依据：**`/`> **解析：**`/`> **技巧点拨：**`，zhixing 后台 `parse_questions_markdown` 可直接导入（已用真实解析器回读验证 20 题 0 错误）
- **每日任务整合**：定时任务步骤⑦-2 自动生成，跳过日同样生成

## 分卷文章汇总原文HTML（2026-09-09 起，一文多卷必做）

- **对象**：一篇文章分为多卷出题的（《十五五规划纲要》→T0c纲要专项卷01-05、《十五五规划建议》→T0-十五五规划卷01·04·05）
- **步骤**：运行 `工作流/gen_origin_html.py --txt <原文txt> --title <文章名> --source <来源> --meta 结构 --meta 分卷 --meta 用途 --out 物料/<文章名>/素材/<文章名>-原文汇总.html`
- **产物**：三刀样式汇总原文HTML（报头/引导卡/目录锚点/篇·章·节层级/正文），放 **该文章目录** `物料/<文章名>/素材/` 下（与原文txt同目录），严禁放类型目录
- **已生成**：`物料/十五五规划纲要/素材/十五五规划纲要-原文汇总.html`、`物料/十五五规划建议/素材/十五五规划建议-原文汇总.html`
- **每日任务整合**：定时任务步骤⑩-2 自动生成/更新，并同步文章目录 README 分卷说明

## 套题汇总（2026-09-09 起，每日同步）

- **脚本**：`物料/模拟套题/merge_paper.py`，自动发现指定套题目录下全部卷（含 `题目/*.json`）并合并
- **用法**：`python3 merge_paper.py --series-dir "T0c-纲要专项" --title "《十五五规划纲要》政治理论 100 题汇总"`
- **输出**：`套题目录/汇总/<标题>_后台导入.md` + `<标题>_汇总.json`
  - MD 为 **zhixing 后台可导入格式**（`parse_questions_markdown`）：题干 `**N. …**` 粗体、选项 `A．`、引用块 `> **答案：**` / `> **原文依据：**` / `> **解析：**` / `> **技巧点拨：**`；组合题/计数题按单选导入
  - JSON：多辑 questions 合并，每题保留原 question_id 并新增 `volume` 来源卷标记；顶层含 article/source_ref/material_anchor/value_score/value_label/answer_distribution/type_distribution/difficulty_distribution/volumes
- **每日任务整合**：定时任务每日产出后自动重跑适用组合（必跑 T0c-纲要专项；当日新增/更新模拟套题卷则对应文章一并重跑），保证汇总与卷集同步
- **已验证**：T0c 5 卷 100 题生成后，用 zhixing 真实解析器回读 100 题 0 错误、解析完整

## 设计要点

### 五题版长图（2026-09-05 起，发布主用）
- **每张图 5 道纯题目**，5 题之后集中放「📝 本组答案与简析」（每题：✅答案 + 1-2 句精简解析）
- **每张图自带完整报头与行动卡，独立成篇**——一期 20 题拆 4 篇公众号文章；无新素材日可顺延发布某一辑，解决"断更"问题
- 引导卡自动读取题目 JSON 的 `value_score`；页脚标注第 N/4 辑；行动卡引导其余辑次至合集

### 答案滞后设计（原切片版保留）
- **小红书卡片**：滞后1题（第2题卡开头放第1题答案+解析）
- **公众号长图/知乎**：滞后3题（第4题前才放第1题答案，延迟满足感更强）
- 最后3题答案在文末单独公布+4×5速查表

### 小红书上题解析格式
每张卡片开头的上题解析包含：
- ✅ 正确项内容
- ▸ 2个干扰项手法分析（如"▸ A项（以偏概全）：..."）

### 公众号长图拆分
- 5题一组，共4张分段
- 第1张含完整报头+引导卡
- 第2-4张用简化页眉（"考点精拆·第06-10题"+期数"2/4"）
- 不在题目中间裁切

### 文案合规
- 统一使用"时政考点"替代"政治理论"
- 封面主标语："时政考点·每日一练"
- 避免平台敏感词检测

1. 正确项位置（目标A/B/C/D各25%）
2. 设问句式（覆盖主流句式）
3. 选项长度（政治理论8-30字）
4. 干扰项手法（偷换概念/以偏概全/无中生有/绝对化/张冠李戴）
5. 难度分布（简单20%/中等50%/较难30%）
