# 政治理论模拟题项目（iCloud 云盘）

基于人民日报头版权威文章，生成接近真题模式的政治理论模拟题，用于公考行测学习。

## 目录结构

```
政治理论/
├── 工作流/      # SOP + 出题引擎脚本
├── 物料模板/    # 题目 / 一致性评估模板
├── 物料/        # 按日期组织（YYYY-MM-DD/）
│   └── YYYY-MM-DD/
│       ├── 素材/    # 原文全文 + 要点索引
│       ├── 题目/    # 模拟题结构化 JSON
│       └── 报告/    # 题目全文 + 一致性评估
└── 知识库/      # 长期知识（考情分类与选题标准 / 真题来源对照表 / 一致性口径 / 决策约定）
```

## 数据基础

- 每日选题判断依据：[知识库/考情分类与选题标准.md](知识库/考情分类与选题标准.md)（基于 2020-2026 国考政治类真题来源分布实证，110 题样本）
- 真题结构化数据：`~/Projects/zhixing-gongkao/xingce-structured-data/`（2020-2025 全量 + 2026 政治理论模块，schema v2）

## 优化与训练体系

- [知识库/题库与知行公考适配方案.md](知识库/题库与知行公考适配方案.md)：真题库接入产品的字段映射、兼容红线、增量新增清单、导入协议、数据补全批次（B0-B5）
- [知识库/题型训练方案-01-政治理论.md](知识库/题型训练方案-01-政治理论.md)：首个模块训练方案（题型×干扰项手法×五种训练模式×模拟卷配比引擎），兼作 02-06 模块模板

## 命名规范

- 物料按日期：`物料/YYYY-MM-DD/`
- 文件命名：`人民日报YYYY-MM-DD_文章名_类型.扩展名`
- 素材 / 题目 / 报告 分目录存放

## 与内容运营的关系

- 发布、文首码、对话回复：**同云盘根目录** [内容运营](../内容运营/)（与 `申论学习/` 同级），主文档 [杜衡阁公众号发布与引流规范.md](../内容运营/杜衡阁公众号发布与引流规范.md)
- 本目录只负责时政选题、出题、五题版图和结构化 MD；不在这里另写一套引流话术
