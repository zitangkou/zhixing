# 文章转MD结构化文档经验总结

## 一、核心思路

将一篇政策类/时政类文章转化为结构化MD文档，本质是**用“三章结构”框架重新组织原文，并为每个层级提取关键词记忆锚点**，服务于公务员考试备考的“理解+记忆+检索”需求。

## 二、三章结构框架

### 固定的三层逻辑

| 层级 | 名称 | 功能 | 命名规则 |

|:---|:---|:---|:---|

| 第一章 | 总论 | 背景、意义、总体要求、指导思想 | 概括性标题，如“总论：×××” |

| 第二章 | 分论 | 核心任务部署、具体举措 | 按原文章节逐一对应 |

| 第三章 | 保障 | 组织保障、落实要求、号召 | 概括性标题，如“保障：×××” |

### 各章内部的节

- **总论章**：1—3节。通常为“战略定位”“历史成就”“指导思想”“总体要求”

- **分论章**：N节。**直接沿用原文的小标题**作为节的标题，原文没有标题则按段落主旨概括

- **保障章**：1—3节。通常为“组织实施”“责任落实”“号召”等

### 实操要点

1. **每节必须以原文引用块`>`）开头**，完整保留原文，不省略

2. **原文中若有带序号的小节**（如“（一）（二）”），在引用块内用粗体标出小节名

3. **每节末尾添加【关键词】块**，用 `/` 分隔各关键词或短语

## 三、关键词提取规则

### 原则：只取“记忆锚点”，不要完整句子

| 类型 | 做法 | 示例 |

|:---|:---|:---|

| 核心名词 | 直接提取 | “枫桥经验”“新质生产力” |

| 数字 | 保留关键数字 | “GDP增长5%”“2035年建成” |

| 固定搭配 | 完整保留 | “听党指挥、能打胜仗、作风优良” |

| 排比列举 | 全部保留，用顿号分隔 | “政治建军、改革强军、科技强军” |

| 判断句 | 提取主谓宾核心 | “党是领导一切的” |

### 关键词格式规范

```

**【关键词】**

关键词一 / 关键词二 / 关键词三

```

- 长段落的可换行分条，但每行仍保持简短

- 一般控制在3—8个关键词，不超过10个

- 关键词之间用 `/` 分隔

## 四、整篇MD文档的格式

### 标题结构

```

# 文章标题（三章结构·关键词版）

> 来源：×××

> 日期：×××

> 标签：思想建设, 理论武装, 凝心铸魂（文章级 3–6 个；不是节末【关键词】）

> 分类：思想理论（须与知行后台分类树中文名一致；理论版默认思想理论，头版时政用时政要闻）

```

### 层级符号

```

## 第一章 ×××

### 第×节 ×××

> 原文内容

**【关键词】**

××× / ×××

```

### 全文通用规则

1. 引用块中原文**不加删减、不加改编**

2. 关键词块**紧跟引用块之后**

3. 节的标题尽量用**原文标题或原文首句的核心短语**

4. 章标题用**概括性表述**（“总论”“分论”“保障”）

## 五、不同类型文章的转换侧重

| 文章类型 | 分论章组织方式 | 关键词侧重点 |

|:---|:---|:---|

| **讲话稿** | 按讲话的段落层次 | 核心论断、排比句、引语 |

| **意见/规定** | 按原文的“一、二、三”或“（一）（二）” | 具体举措、数字、禁止性要求 |

| **新闻通稿** | 按会议议程/报道逻辑 | 人物、时间、地点、核心表述 |

| **论述摘编** | 按时间顺序或主题逻辑 | 关键论断、出处、背景 |

| **理论文章**（如十个明确） | 按条目逐一对应 | 每个条目的核心命题 |

## 六、配套试题生成规则

在结构文档基础上，配套试题遵循：

1. **题量**：根据原文长度——短文（<3000字）20—30题；中篇（3000—8000字）30—50题；长文（>8000字）50—100题

2. **题型比例**：单选:多选 ≈ 1:1

3. **每道题附**：原文依据 + 技巧点拨

4. **命题点选取**：

   - 固定搭配（如“立军之本”“必由之路”）

   - 数字与时间节点

   - 排比列举（六力、五个坚持、四大成就）

   - 易混淆概念（如“八项规定”与“八项规定精神”）

   - 反向干扰项（“完全”“彻底”“所有”等绝对化表述）

## 七、经验沉淀总结

**核心方法论一句话：先“框”后“填”——先用三章结构框定文章骨架，再用原文引用块填实内容，最后用关键词做记忆锚点。**

三个“始终”：

1. **始终保留原文**——结构文档的引用块中原文一字不删

2. **始终有锚点**——每节必有【关键词】，绝不遗漏

3. **始终有呼应**——章标题、节标题、关键词、试题选项形成从宏观到微观的完整链条
