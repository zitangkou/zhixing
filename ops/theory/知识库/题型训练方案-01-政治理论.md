- **词表**：topic 5 个板块相关 + tag 约 30 个（2025 年 16 个 + 2026 年新增 15 个）

## 2. 题型体系与识别规则

### 2.1 三种题型（kind）

| kind | 识别规则（导入器自动判定） | 2026 例 |
|---|---|---|
| `direct` 直接判断 | options 为四个完整陈述句 | Q5（法治一体建设）、Q8（政治局民生） |
| `combo` 组合题 | options 为 ①②③ 的组合（如 "①②③"） | Q3（文化强国 ②③④） |
| `count` 计数题 | options 全为 "N项" | Q1（自信自立 4 项）、Q11（战略思维 2 项） |

### 2.2 五种干扰项手法（distractor_tricks，取自 2026 真题实证）

| 手法 | 代码 | 典型真题例证（2026） |
|---|---|---|
| 时间/序次错 | `time` | Q2-A"起始于1949"（实为一五计划1953）；Q20-B"第一次确立大国地位"（实为"重新确立"）；Q2-D"第一次网络征求意见"（十四五已做过） |
| 主体/地域错（张冠李戴） | `subject` | Q19-A 把山西"资源型经济转型试验区"安给江苏；Q19-D 把海南自贸港政策安给贵州 |
| 方向/对向错 | `direction` | Q9-C"由社会治理向政府治理"（反向）；Q6-D"掌舵人转划桨人"（反向）；Q10-D"事后处理向事中控制"（应为事前预防）；Q4-D"经营性向公益性"（反向） |
| 搭配/限定词错 | `collocation` | Q15-C"党风是保障、党纪是表现"（与原文对调）；Q17-A"马克思创立了辩证法"（应为"唯物"辩证法） |
| 程度/定性错 | `degree` | Q7-C"以量取胜"（应为以质取胜）；Q18-D"无目的的本能活动"（实践恰是有目的的）；Q14-A"突出经济发展需求"（应为国家重大需求） |

> 训练价值：手法是"可教学的错误模式"。专项刷按手法训练 = 教学员识别陷阱，比按考点刷更接近提分本质。

## 3. 训练维度标注示例（analysis_payload_json）

```json
{
  "kind": "direct",
  "distractor_tricks": {"A": null, "B": null, "C": "degree", "D": null},
  "confidence": "green",
  "difficulty_hint": 3,
  "source_class": "B2领导人文章",
  "note": null
}
```

导入时自动预填 `kind/confidence`；`distractor_tricks` 首批由规则引擎预填（"由X向Y转变"句式→direction、"第一次/起始于/多年前"→time、地名/主体并列→subject）+ 每期人工校准 20 题。

## 4. 五种训练模式设计

| 模式 | 集合类型 | 数据来源 | 出题规则 | 入口 |
|---|---|---|---|---|
| **真题卷** | `paper`（真实题位） | 2025 三卷、2026 三卷（ politics 1-20） | 原卷原题号原顺序；门禁：confidence ∈ {green, yellow} 才进入；2026 Q11-20（橙）暂以"标灰练习"提供 | 练习 Tab → 真题库 → 国考真题 |
| **模拟卷** | `paper`（合成卷） | 2020-2026 真题池 + 物料模拟题池 | 配比引擎（§5）动态组卷 20 题 | 练习 Tab → 真题库 → 智能模拟卷 |
| **每日一练** | `daily`（8 题） | 当天物料 20 题抽 6 + 近 7 天错题重练 2 | 与现有 theory_daily/时政阅读链路并存；窗口期（选题标准 §5 日历 14 天内）替换为窗口预热专题 | 今日 Tab 清单 + 练习 Tab |
| **专项刷** | `topic`（10 题/组） | qb 全池 | 四个维度任选：考点 tag / 题型 kind / 干扰项手法 / 来源分类 A-F；同 tag 7 天内不出重复 | 练习 Tab → 真题库 → 专项 |
| **错题复盘** | `review` | `qb_practice_answers` 错题 | 按 tag 聚合生成复盘集；间隔重练（简单 3 天/中等 2 天/难 1 天，先线性，SRS 二期接 `srs.py`） | 练习 Tab → 错题（qb 独立分区） |

**门禁对齐**（适配方案 §6.3）：真题卷只收绿/黄；橙级（2026 Q11-20 推导级）在专项刷可用并提示"答案待权威源复核"；黑/null 只能"题干练习不判分"。

## 5. 模拟卷配比引擎（20 题规则表）

| 维度 | 规则 |
|---|---|
| 板块 | 马原 2-3 / 习思想 13-14 / 政策与会议 3-4 / 时事 0-1 |
| 题型 kind | direct 15-17 / combo 2 / count 1-2 |
| 答案分布 | A/B/C/D 各 5±1（抽题时按当前累计分布动态平衡） |
| 手法覆盖 | 5 种手法至少 4 种出现在干扰项中（读 distractor_tricks） |
| 难度 | 1-2 星 6 题 / 3 星 9 题 / 4-5 星 5 题（初期按 difficulty_hint，积累答题数据后回标） |
| 查重降权 | 近 2 年国考真题已直接考过的 tag 降权（联动《考情分类与选题标准》§6）；同 tag 卷内不重复（一题一专题原则） |
| 来源配比 | 引子=总书记论述的题 ≥ 10 题（对应真题 70% 特征） |

引擎实现：`qb_training_service.generate_paper(topic_pool, rules)`，输出合成 `paper` 集合，组卷过程存元数据便于复盘归因。

## 6. 质量红线

1. 任何进入判分的题必须 `answer` 非空且 confidence ≥ 橙
2. 答案与解析同源（explanation 为空时答题页只给答案不给解析，并提示待补）
3. 模拟题（origin_type=generated/manual）与真题（real）**分区展示**，模拟卷允许混排但复盘报告分开统计
4. 答案冲突纪律：单来源答案不得静默升级为绿（B站键 8/12 证伪的教训写入导入器注释）

## 7. 度量与反哺

- **正确率矩阵**：kind × tag × trick 三维统计（数据侧 `qb_practice_answers`）
- **手法诊断**：某手法正确率 < 60% → 每日一练自动加权该手法题目
- **考点诊断**：某 tag 正确率 < 50% 且属 A/B/C 类高频源 → 推送专项组
- **反哺选题**：某考点模拟正确率持续 > 85% 且真题近 2 年未考 → 选题标准"真题关联度"降权（避免重复劳动）；反之命中率低的高频源加大物料供给
