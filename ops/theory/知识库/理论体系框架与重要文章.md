## 1. 体系总框架（一张图）

**历史地位**：当代中国马克思主义、二十一世纪马克思主义，中华文化和中国精神的时代精华（十九届六中全会《决议》定性）。

```
习近平新时代中国特色社会主义思想
├── 核心内容：「十个明确」          ← 十九届六中全会《决议》(2021-11)
├── 基本方略：「十四个坚持」        ← 十九大报告 (2017-10)
├── 实践成就：「十三个方面成就」    ← 十九届六中全会《决议》
├── 世界观方法论：「六个必须坚持」  ← 二十大报告 (2022-10)
│     人民至上 / 自信自立 / 守正创新 / 问题导向 / 系统观念 / 胸怀天下
├── 根本途径：「两个结合」          ← 马克思主义基本原理同中国具体实际相结合、
│                                     同中华优秀传统文化相结合
└── 分领域思想（枝干，每个都有确立场合+代表文本）：
      经济思想 / 法治思想 / 文化思想 / 生态文明思想 / 强军思想 /
      外交思想 / 总体国家安全观 / 党的建设 / 网络强国 / 统一战线
```

> 考法提示：真题最喜欢考"体系定位"——把某句话归到"十个明确"第几条、"六个必须坚持"第几个、"X个坚持/几个X"的完整列举（计数题/组合题的天然素材）。

## 5. 使用与维护

1. **出题定位法**：拿到文章 → 先判体系分支（本表）→ 查该分支锚文章 → 按《题型训练方案》出题 → 解析中点明"这是XX思想的XX表述"。
2. **两篇高价值补做文献**（跳过日优先）：《在文化传承发展座谈会上的讲话》（求是 2023-17，"第二个结合"总源头）、《推进生态文明建设需要处理好几个重大关系》（求是 2023-22，五对重大关系）。
3. **维护**：季度核对"待核"期号；五中全会（2026-10）后补党建分支新文本；国考后更新已考标记。

## 6. 系列化试题产出排期（体系框架 → 专题系列）

**发布节奏**：每日头版有信号照常出题；跳过日 + 每月最后一周设"专题周"，连发对应系列的 8 辑；发布后按辑号在本表登记进度，一个系列发完再开下一个。

**优先从人民日报获取的口径**：系列文章凡讲话全文，均以人民日报受权播发版为准（与每日工作流同源）；《求是》文章作为理论文本补充，解析中注明两个载体的对应关系。
