# 内容生产脚本（从 iCloud 拷贝）

两套运营物料流程的脚本与 SOP，供管理后台「内容生产」步骤调用。

| 目录 | 来源 | 产物（`OPS_MATERIAL_ROOT` 下） |
|------|------|--------------------------------|
| `shenlun/` | 申论学习 | `shenlun/物料/<日期>/<标题>/{原文,解剖,公众号}/` |
| `theory/` | 政治理论 | `theory/物料/<日期>_<标题>/{素材,题目,报告,公众号}/` |

- 不提交历史 `物料/` 成品。运行时写入环境变量 `OPS_MATERIAL_ROOT`（默认 `server/data/ops-materials`）。
- 工作目录：对应 `ops/shenlun` 或 `ops/theory`。
- 知行导入约定：`docs/时评精拆原文HTML_知行导入约定.md`、`docs/政治理论每日出题运营物料_会话沉淀_20260905.md`（自动导入后台为后续步骤）。
- 定时 cron 仅在后台存配置，第一期不会自动触发。
