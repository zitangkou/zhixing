# 知库 · AI 知识库原型

独立于现有知行公考学员端的移动端交互原型，提供首页、个人空间、文档阅读、定向分享与阅读权限设置体验。

## 预览

在仓库根目录运行：

```bash
python3 -m http.server 4173 --directory zhishiku
```

浏览器打开 `http://127.0.0.1:4173`。

## 当前原型内容

- 首页：全局搜索、精选专题、热门资料分类、推荐内容。
- 我的：收藏、阅读历史、分享管理、离线资料、隐私安全和外观配置入口。
- 阅读体验：Markdown 风格文档预览，含只读提示、身份水印、收藏、AI 解读和分享入口。
- 定向分享：演示成员访问、有效期、访问链接和只读保护配置。
- 文件类型展示：MD、PDF、DOCX。
- 移动优先布局，适配桌面预览；数据均为演示数据。

## 商业化落地注意

当前目录是可交互前端原型，不包含登录、文件上传/解析、AI 服务、订阅支付或后端权限校验。禁止复制/文本选择与 CSS 水印只能增加普通使用门槛，不能阻止截图、拍照、开发者工具或客户端绕过。正式上线需要服务端校验每次文档访问与分享授权、动态生成带身份的水印、设置访问审计与撤销能力，并按授权策略控制原文件下载。

建议先接入的真实资料管线：

1. MD / TXT：服务端安全解析为受控阅读内容，过滤危险 HTML 与外链。
2. PDF：服务端抽取文本及页码；扫描件接 OCR，阅读端按权限提供分页/图片化视图。
3. DOCX / PPTX / XLSX：服务端统一抽取正文、表格和元信息，保留原文件与转换结果的关联。
4. 统一文档元数据、版本、可见范围、指定成员、有效期、访问次数和 AI 分析任务状态。

不要把此演示原型里的静态开关或前端判断当作商业访问控制。
