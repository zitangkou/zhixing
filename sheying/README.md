# 光线练习簿

摄影学习微信小程序原型，技术栈与仓库内知库小程序一致：Taro 4 + Vue 3 + TypeScript。

## 运行

```bash
npm install
npm run dev:weapp
# 微信开发者工具打开本目录，项目目录选择 dist/
npm run dev:h5
```

开发环境可复制 `.env.example` 为 `.env` 并设置后端地址。微信开发者工具需配置可访问的局域网地址和 request 合法域名；未配置服务地址时，小程序使用内置示例课程。

当前包含首页、技巧课目录、拍摄练习记录、摄影知识地图与个人练习统计。课程默认内置在 `src/data/lessons.ts`；配置 `TARO_APP_API_BASE_URL` 后会从知行后端读取管理端已发布课程和知识地图。练习记录保存在设备本地，暂未同步到云端。内容由知行现有管理后台「摄影学习」菜单维护，子菜单为「技巧课程」和「知识地图」。小程序 AppID 使用 `touristappid` 占位，发布前需替换为正式 AppID，并完善隐私指引、备案和审核配置。

产品方案、课程体系和运营物料见 `../内容运营/摄影/`。
