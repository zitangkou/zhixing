# 光线练习簿

摄影学习微信小程序原型，技术栈与仓库内知库小程序一致：Taro 4 + Vue 3 + TypeScript。

## 运行

```bash
npm install
npm run dev:weapp
# 微信开发者工具打开本目录，项目目录选择 dist/
npm run dev:h5
```

开发环境可复制 `.env.example` 为 `.env` 并设置后端地址。微信开发者工具需配置可访问的局域网地址和 request 合法域名；未配置服务地址时，小程序使用内置示例课程。

当前包含首页、技巧课目录、作品案例拆解、拍摄练习记录、摄影知识地图与个人练习统计。配置 `TARO_APP_API_BASE_URL` 后会从知行后端读取已发布课程、知识地图和人工审核的作品案例；课程仍提供内置内容。练习记录保存在设备本地，暂未同步到云端。后台由「摄影学习」下的「技巧课程」「知识地图」「作品案例」维护。案例图片必须使用微信后台已配置的 HTTPS 下载域名并具备有效展示授权。目前没有用户图片上传和自动 AI 分析功能。本工程有独立微信小程序 AppID；AppSecret 只放在服务端 `SHEYING_MINIPROGRAM_APP_SECRET`，不得放入小程序包。发布前还需完成隐私指引、备案和审核配置。
