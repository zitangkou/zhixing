# AI 百宝箱

AI 百宝箱微信小程序，使用 Taro 4.0.9 + Vue 3。现阶段包含首页、个人中心、资料编辑、登录、隐私说明、设置、收藏、浏览记录和反馈基础功能。具体 AI 工具仍为规划展示，不提供实际处理能力。


## 小程序资料建议

- 名称：AI百宝箱
- 简介：汇集 AI 绘图、文件处理、录音转文字与日常效率工具，让生活中的灵感和琐事都能一站式轻松处理。
- Logo：`src/assets/logo/ai-toolbox-icon.png`（1254 × 1254 PNG）

## 开发与构建

```bash
cd baibaoxiang
npm install
npm run dev:weapp
```

使用微信开发者工具打开 `baibaoxiang` 目录（项目配置指向 `dist/`）。`.env.example` 是环境变量模板，本地 `.env` 已初始化并由 Git 忽略。接入后端时只需在本地 `.env` 填写 `TARO_APP_API_BASE_URL`。运行开发或构建命令前，会自动从本地 `.env` 的 `APP_ID` 同步微信开发者工具配置。`APP_SECRET` 仅保留在本地环境文件，不能注入小程序前端包；需要由服务端使用。

## 当前范围

- 首页：搜索工具、分类筛选、推荐卡片与工具目录；工具点击只记录本机浏览记录并提示工具仍在准备中。
- 访客个人中心：本地昵称、收藏、最近浏览、偏好设置及本机数据清理。
- 微信快捷登录：调用微信 `login` 并将一次性 code 发送给共享后端 `/api/auth/wechat/login`；需在服务器配置 `MINIPROGRAM_APP_ID`、`MINIPROGRAM_APP_SECRET` 且 API 地址可访问。secret 不能注入小程序前端包。
- 个人资料：本地编辑昵称；登录后同步至共享后端 `/api/user/me`。
- 反馈：登录后通过共享后端 `/api/feedback` 提交，最多 500 字。
- 管理后台继续共用知行现有后台，本项目当前不新增管理端功能。

## 发布准备

正式提审前须完成以下外部配置和人工核验：

1. 运营主体已知为个人；核对其与微信公众平台登记信息一致。
2. 在服务器环境中配置小程序 `MINIPROGRAM_APP_ID` 和 `MINIPROGRAM_APP_SECRET`；secret 不能放进小程序 `.env` 或客户端包。服务器 `.env.example` 已有对应变量名，本地值不在此展示。
3. 本地 `.env` 中 `TARO_APP_API_BASE_URL` 是公开 API 地址配置；确认它指向可访问的 HTTPS 服务端，且域名已加入微信小程序 request 合法域名。后端公开产品键 `general` 需要启用。
4. 在微信公众平台补齐个人主体可用的隐私问题联系渠道、服务类目、隐私保护指引、用户协议和正式隐私政策。页面中的隐私说明是当前开发范围说明，不能直接代替正式发布材料。
5. 按微信平台当前要求完成隐私接口声明与用户授权流程；在微信开发者工具及真机检查登录拒绝、网络失败、退出、清理数据等路径。
6. 校验名称、简介、Logo、截图、类目和备案信息与小程序实际能力一致。AI 图片、文件、录音工具尚未实现，发布介绍不得声称这些能力已可使用。
7. 运行 `npm run build:weapp`，使用微信开发者工具打开 `baibaoxiang` 并完成真机预览、体验版审核和隐私合规检查。


小程序前端环境变量会被编译进客户端，只能放 API 地址等公开配置；微信 `AppSecret`、模型 API Key 等敏感凭据应保存在服务端环境中。
