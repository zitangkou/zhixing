# AI 百宝箱

AI 工具聚合小程序的第一阶段界面原型，包含首页工具发现、搜索与分类筛选，以及个人中心的资料、使用概览、常用工具和设置入口。工具数据集中维护在 `src/data/tools.ts`，后续可逐步接入真实能力与知行管理后台。

## 本地预览

```bash
cd 百宝箱
npm install
npm run dev
```

访问 Vite 输出的本地地址即可用手机视口预览。当前是可交互的 H5 原型；后续接入微信小程序时，可沿用页面与工具数据结构迁移到 Taro/原生小程序，并在现有服务端增加百宝箱工具配置能力。

## 当前阶段

- 首页：搜索工具、按类型筛选、推荐与热门工具列表。
- 我的：个人资料入口、使用概览、快捷工具、历史/收藏/帮助/设置入口。
- 工具详情与 AI 执行流程暂用“即将开放”提示，等待分步接入。
- 管理后台沿用知行现有后台，本阶段不增加后台功能。
