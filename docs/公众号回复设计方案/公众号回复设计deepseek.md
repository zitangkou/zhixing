## 一、调研发现：头部公众号做对了什么？

通过对**十点读书、视觉志、罗辑思维、丁香医生、水滴互助**等多个头部公众号的自动回复体系进行调研，总结出以下核心规律：

### 1.1 十点读书：思路清晰，绝不浪费流量

被关注回复第一句话就交代清楚价值——“从今天起，我们一起相约读书，成为更好的自己吧！”此后是三条工具性质的链接，分别指向**往期内容、知识付费和小程序电台**，思路清晰的设计，丝毫不浪费流量。

### 1.2 视觉志：极简主义，降低用户负担

自动回复仅一句欢迎语、一个关键词提示和一个热门文章链接。“欢迎来到视觉志。回复‘日签’获取今日美图，回复‘故事’阅读精选文章。菜单栏有更多精彩。”——**总字数约35字，两行排版**，用户取关率低于行业平均30%，菜单栏点击率提升25%。

### 1.3 罗辑思维：直接导向核心业务

两条图文链接，一条介绍如何“玩转”罗辑思维（每天早上六点半60秒语音），第二条直接引导至得到App下载页面。

### 1.4 丁香医生：预设关键词库，打造智能问答

通过预设**200+问题关键词**的自动回复系统，在春节期间实现**48小时内8.2万次互动**。

### 1.5 水滴互助：分步引导，逐步展示价值

关注后**连续弹出三条自动回复**，每条导向不同需求，总有一条吸引用户。

### 1.6 核心结论


| 策略维度      | 头部账号共性做法                   |
| --------- | -------------------------- |
| **字数控制**  | 50字以内是黄金法则，超过50字阅读完成率不足20% |
| **分段排版**  | 每段不超过两行，段间空行，视觉上轻盈透气       |
| **价值先行**  | 第一句话交代“关注我能得到什么”           |
| **行动引导**  | 2-3个清晰关键词入口，不让用户猜          |
| **人格化语气** | 用“你”而非“您”，像朋友打招呼           |
| **关键词数量** | 控制在5-10个核心关键词，太多用户记不住      |


## 二、核心设计理念

个人号没有底部菜单，用 **“数字导航 + 关键词”双轨制**代替菜单。参考十点读书、罗辑思维的交互逻辑，把公众号做成一个 **“轻量学习终端”** ——用户发消息=点击菜单，回复内容=页面跳转。

**留存的三个钩子**（基于调研优化）：

- **每日必来**：每天有新题，答案后置制造悬念（蔡格尼克效应）
- **连续打卡**：天数可视化，断卡可惜心理（损失厌恶）
- **进度积累**：题库/素材越攒越多，离开成本高（沉没成本）

## 三、用户旅程地图（优化版）

```
新关注（黄金30秒）
  │
  ▼
[被关注回复] → 精简欢迎语（≤50字）+ 价值诱饵 + 3-5个核心导航
  │
  ├─ 回复「1」→ 今日一练（刷题模式）—— 每日必来
  ├─ 回复「2」→ 三刀精读（阅读模式）—— 内容沉淀
  ├─ 回复「3」→ 题库检索（查询模式）—— 自助服务
  ├─ 回复「5」→ 打卡中心（留存模式）—— 最关键
  ├─ 回复「6」→ 加群/交流（社群模式）—— 私域沉淀
  └─ 回复「0」→ 主菜单（随时召回）
  │
  ▼
活跃用户 → 每日固定时间刷题/打卡 → 形成习惯
  │
  ▼
留存用户 → 连续打卡N天 → 解锁奖励 → 主动转发
```

## 四、主菜单导航设计（精简版）

### 4.1 被关注回复（黄金30秒）—— 参考视觉志的极简风格

```
🎉 欢迎来到「三刀精读」

每天一篇人民日报评论拆解 + 一套时政考点模拟题，
用碎片时间搞定公考政治理论。

📋 回复数字使用功能：
  1 ─ 今日一练（每日新题）
  2 ─ 三刀精读（文章拆解）
  3 ─ 题库检索（往期查询）
  5 ─ 打卡中心（连续学习）
  6 ─ 加入学习群
  0 ─ 显示菜单

💡 新用户回复「新人」领取《政治理论高频考点100条》
```

**设计要点**：

- 总字数控制在50字以内
- 每段不超过两行，段间空行
- 核心功能从9项精简到6项（参考十点读书的3条链接思路）
- 第一句话交代价值

### 4.2 主菜单召回

任何时候用户回复 `0`、`菜单`、`help`、`?` 都返回主菜单导航。

## 五、六大模式详细设计（优化版）

### 模式 1：今日一练（刷题模式）— 核心留存功能

**触发关键词**：`1`、`今日`、`刷题`、`一练`

**交互流程**：

```
用户：1

公众号：
📝 今日考点一练｜2026-09-07
素材：《十五五规划纲要·开局产业科技数字》
价值分：97/100｜难度：中等偏上

📌 规则：题目分4组推送，每组5题。
做完一组回复「下一组」继续，
全部做完回复「答案」看解析。

—— 第1组（第1-5题）——
1. 《纲要》回顾"十四五"时期成就指出，我国国内生产总值：
   A.突破130万亿元  B.突破140万亿元
   C.突破150万亿元  D.迈上140万亿斤台阶
...（共5题）

回复「下一组」继续 →

用户：下一组

公众号：—— 第2组（第6-10题）—— ...

用户：答案

公众号：
✅ 今日答案速查
1.B  2.C  3.A  4.D  5.B ...（共20题答案）

📖 详细解析回复对应题号，如「解析3」
💾 完整题目+解析长图：[公众号文章链接]
🏆 完成今日一练！回复「打卡」记录学习
```

**关键设计点**（参考丁香医生互动模式）：

- 答案后置（先做题再要答案），制造完成感
- 分组推送（5题一组），避免刷屏
- 单题解析可查（回复“解析3”），支持深度学习
- 完成后引导打卡，形成行为闭环

### 模式 2：三刀精读（阅读模式）

**触发关键词**：`2`、`精读`、`三刀`、`评论`

```
用户：2

公众号：
📖 三刀法精读专栏

三刀法 = 是什么（拆解观点）+ 为什么（分析逻辑）+ 怎么办（提炼对策）

📚 近期精读（回复对应数字）：
  21 ─ 最新一期（文章标题）
  22 ─ 上期（文章标题）
  23 ─ 申论万能句式合集
  24 ─ 规范词速查表

💡 想拆解哪篇文章？直接发标题，我会优先安排
```

### 模式 3：题库检索（查询模式）

**触发关键词**：`3`、`题库`、`搜题`、`历史`

**设计要点**（参考丁香医生200+关键词库模式）：

- 已积累XX套模拟题，XXX道题
- 按专题分类（31-35）
- **支持模糊匹配**：用户发任意关键词（如“人工智能”“乡村振兴”），系统匹配相关题目
- 建议设置至少10-20个高频关键词，覆盖用户80%的常见需求

### 模式 4：申论素材（素材模式）

**触发关键词**：`4`、`申论`、`素材`、`金句`

**设计要点**（参考“彩蛋式”福利设计）：

- 规范词300条（按领域分类）
- 万能句式模板（开头/过渡/结尾）
- 人物素材/案例库
- 人民日报金句摘抄
- 每周更新，回复数字获取

### 模式 5：打卡中心（留存模式）— 最关键

**触发关键词**：`5`、`打卡`、`签到`、`我的`

**设计要点**（参考水滴互助分步引导思路）：

- 打卡成功后展示连续天数、累计天数、完成套题数、正确率
- 里程碑奖励分级（3/7/14/30天）
- **打卡数据持久化存储**（开发者模式必需）

```

公众号：

📊 你的学习数据：
  连续打卡：7天 🔥
  累计打卡：23天
  已完成套题：12套

🏆 里程碑奖励：
  ✅ 3天 ─ 规范词100条
  ✅ 7天 ─ 申论万能句式合集
  ⬜ 14天 ─ 政治理论高频考点100条PDF
  ⬜ 30天 ─ 一对一备考规划咨询

💪 继续保持！明天见～
```

### 模式 6：加群/交流（社群模式）

**触发关键词**：`6`、`加群`、`交流`、`群`

**设计要点**（参考私域引流策略）：

- 群内福利介绍

## 六、智能兜底回复（优化版）

## 十、技术实现路径

### 阶段1：后台自动回复（本周可做，无需开发）

停用开发者模式，用公众号后台关键词回复实现：

- ✅ 被关注回复
- ✅ 主菜单导航（0-6数字关键词）
- ✅ 固定内容回复（素材包、精读文章链接）
- ❌ 打卡天数记录（无法持久化）
- ❌ 动态当日题目（无法读取云盘JSON）
- ❌ 题库关键词搜索

### 阶段2：开发者模式+后端实现（推荐，2-3天开发）

在现有FastAPI后端加微信消息处理模块，实现：

- 今日一练自动读取云盘当日题目JSON
- 题库检索读取全部历史题目JSON做关键词匹配
- 打卡数据持久化，连续天数自动计算
- 用户做题进度记忆

### 阶段3：进阶功能（后续迭代）

- 答题判分：用户发选项字母，自动判对错+返回解析
- 错题本：自动收集错题，支持复习
- 个性化推荐：根据薄弱考点推送相关题目
- 周/月学习报告：自动生成学习数据总结
