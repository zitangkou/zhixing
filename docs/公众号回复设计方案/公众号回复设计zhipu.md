# 公众号回复设计zhipu

已对当前头部公众号的回复功能设计做了系统研究，核心发现：**做得好的公众号在回复设计上分四大流派——人格化欢迎语派（新世相、故宫淘宝等）、工具导航派（得到、粉笔思路）、流程式获客派（教育类账号）、智能增强派（自建消息服务+带参二维码）**。结合你的 v1.0 方案，输出以下 v2.0 升级设计方案。全文为标准 Markdown，全选复制后保存为「公众号自动回复体系设计方案v2.0.md」即可下载使用。

> 本版目标：借鉴头部公众号成熟做法，强化「留住用户」与「推广增长」两大能力

## 一、头部公众号回复设计研究成果

### 1.1 四大流派概览


| 流派      | 代表做法                | 核心逻辑                                     | 对本号的借鉴          |
| ------- | ------------------- | ---------------------------------------- | --------------- |
| 人格化欢迎语派 | 内容型大号（新世相、故宫淘宝、咪蒙等） | 欢迎语=人设名片，30字内让用户记住"你是谁"                  | 改造被关注回复         |
| 工具导航派   | 学习类产品号（得到、粉笔思路）     | 对话框即菜单，数字+关键词双轨                          | v1.0已采用，保留      |
| 流程式获客派  | 教育类获客号              | 用户发任何消息都按预设流程连续推送，多轮对话收集准客户信息促转化         | 新增7天养成流程        |
| 智能增强派   | 自建消息服务的技术流号         | 自建被动回复服务，支持全消息类型、粉丝ID鉴权、带参二维码渠道溯源、多条消息连发 | 消息类型差异化兜底+渠道二维码 |


### 1.2 关键案例拆解

**（1）人格化欢迎语：第一次互动决定第一印象**

关注后的自动回复是与用户的第一次真正互动，核心诉求是"跟用户发生更多的关系"。经典文案：

- 新世相：「你闻讯而来，我大喜过望。」
- 故宫淘宝：「既然关注了，从此你就是本宫的人了。」
- 咪蒙：「欢迎来到脱稿界天后的世界，下一次更新文章有可能是下周，也有可能是下辈子。」
- 连岳：「要按照你想的去生活，否则你迟早将按照你生活的去想。祝开心。」
- 高冷人设款：「唉，想不到真会有人来关注呢。」

**诊断 v1.0 的问题**：欢迎语是"功能说明书"，信息过载（7个数字+福利）、无人设、无情绪、无记忆点。

**（2）流程式回复：对话即收线索**

获客型教育号的典型玩法：无论用户发什么，系统都按流程继续推送——先送资料建立信任→再问"你考什么"→引导入群。本质是把匿名粉丝转化为有档案的准客户。v1.0 完全没有信息收集环节，需要补上（但改用于留存而非硬转化）。

**（3）智能增强玩法（技术流）**

- 自建消息服务可支持文本/图片/语音/视频等 7 种消息类型回复；
- 每个粉丝有唯一 ID，可做鉴权和差异化服务；
- 带参二维码：不同渠道扫码关注触发不同回复，用于推广渠道效果统计；扫码用户只收到二维码指定的回复，不会与默认欢迎语重复；
- ⚠️ 官方规则限制：关注回复**不支持延时**，只能调整多条消息的发送顺序。

### 1.3 提炼出的七条设计原则

1. **黄金 30 秒**：欢迎语 = 人设名片 + 价值承诺 + 唯一行动指令
2. **单点行动指令**：一条回复只引导一个动作，避免选择瘫痪
3. **钩子后置**：答案、资料、奖励后置，制造回访理由
4. **对话即收线索**：把匿名粉丝变成有档案的用户
5. **渠道可溯源**：不同推广入口用不同带参二维码
6. **消息类型全覆盖**：文字/图片/语音/视频各有兜底，不掉线
7. **一切指向可度量行为**：每次回复都以打卡/分享/留资收尾

## 二、v2.0 核心升级：两大新增模块 + 三处改造

### 2.1 改造一：被关注回复 v2.0（人格化）

```
刀已磨好，就等你了。

欢迎来到「三刀精读」
每天一篇人民日报评论三刀拆解 + 一套时政 20 题，
别人刷短视频的时间，你刷的是考点。

👉 新人先领：回复「新人」拿
《政治理论高频考点100条》PDF

📋 其他功能（随时回复数字调用）：
1 今日一练｜2 三刀精读｜3 题库检索
4 申论素材｜5 我的打卡｜6 学习群
0 返回本菜单
```

**设计逻辑**：

- 首句呼应"三刀"品牌人设，取代"🎉 欢迎来到"模板腔
- **行动指令唯一化**：新用户只需记住「新人」一个动作；菜单压缩为一行作为次级信息
- 价值主张一句话讲清（碎片时间刷考点）

### 2.2 改造二：消息类型差异化兜底


| 用户行为        | 回复策略                             |
| ----------- | -------------------------------- |
| 发文字（无关键词命中） | 先尝试搜题，未命中走智能引导                   |
| 发图片         | "收到图片～想要素材包回复 4，想搜题直接发关键词"       |
| 发语音         | "语音没能识别，打字更稳：1 刷题 / 4 素材 / 0 菜单" |
| 发视频         | 引导至三刀精读栏目                        |
| 发文章标题/链接    | 进入精读点播队列，回复"已收到，安排中"             |


技术实现：开发者模式解析 MsgType 字段分发，文字类消息（text）再走关键词路由。

### 2.3 改造三：兜底回复接入搜题

原兜底只做导航。v2.0 把用户发的"任意文字"先当关键词过一遍题库检索（复用 question_search 服务），命中则直接返回相关题目，未命中才走引导文案——让每次发言都有"可能中奖"的惊喜感，这是工具型公众号提升好感的关键细节。

### 2.4 新增模式七：分享裂变（推广引擎）

**触发关键词**：`7`、`分享`、`邀请`、`推荐`

```
用户：7
公众号：
🚀 帮你朋友也上岸

方式一：把今天的「今日一练」转发给
备考的朋友/群，回复「已分享」领取
《时政考点周报 PDF》

方式二：组队打卡
邀请 2 位好友关注并回复「组队+你的昵称」，
全队连续打卡 7 天，全员解锁《申论范文 10 篇》

📊 我的邀请战绩：3 人
（每邀请 1 人，里程碑奖励解锁速度 +10%）
```

**机制设计**：

- **专属邀请码**：后端为每个用户生成邀请码（如 sd8888），好友关注后首次发消息带码即绑定邀请关系
- **邀请激励分层**：1 人→周报 PDF；3 人→月度精华；5 人→一对一备考咨询优先权
- **组队打卡**：社交绑定强化留存（同伴压力 + 承诺一致性）
- **战绩海报**：自动生成带公众号二维码的打卡战绩图（复用小红书卡片生产线），用户转发即自带拉新入口

> ⚠️ **合规红线**：所有奖励采用"回复已分享即领"的信任制，**不设强制分享验证**、群发文案不出现"转发朋友圈得 XX"字样，规避平台诱导分享处罚。

### 2.5 新增模式八：新人 7 天养成流程（留存引擎）

个人订阅号**无法主动推送**，因此流程设计为"指针式"——用户每主动发一次消息，流程前进一步，互动即推进：


| 天数    | 用户触发点     | 系统动作                   | 收集信息 |
| ----- | --------- | ---------------------- | ---- |
| D0    | 发「新人」     | 发新人礼包 + 引导回复 1         | —    |
| D1    | 发 1 做今日一练 | 正常推题 + 完成后引导打卡         | —    |
| D2    | 发「打卡」     | 打卡成功 + 追问"你准备哪年考试？"    | 备考年份 |
| D3    | 任意互动      | 追问"行测申论哪个更头疼？（回复 A/B）" | 薄弱科目 |
| D4    | 任意互动      | 按薄弱科目定向推专题题号           | —    |
| D5    | 任意互动      | 引导加群 / 分享              | —    |
| D6-D7 | 打卡        | 连续 7 天达成，发句式合集 + 战绩海报  | —    |


**收口价值**：7 天结束时系统已建档（openid、备考年份、薄弱科目、打卡习惯），后续个性化推荐、阶段三的错题本与周报功能都有了抓手——这正是头部获客号流程式回复的商业本质，此处用于留存。

## 四、推广渠道带参二维码方案

不同投放渠道使用不同参数二维码，扫码关注触发差异化欢迎语，后端记录来源：


| 渠道      | 二维码参数     | 定制欢迎语侧重        |
| ------- | --------- | -------------- |
| 知乎      | ch=zhihu  | 引导三刀精读（契合长文场景） |
| 小红书     | ch=xhs    | 引导今日一练（契合刷题卡片） |
| 社群/好友推荐 | ch=social | 资料直领 + 加群引导    |
| 默认      | 无参数       | v2.0 标准欢迎语     |


每周输出渠道质量报表：**渠道 → 涨粉量 → 7 日留存 → 打卡率 → 做题完成率**，把推广精力投向高质量渠道。带参用户只收二维码指定回复，不重复触发默认欢迎语，避免打扰。

## 八、风险与合规提示

1. **诱导分享**：奖励一律信任制领取，不设强制分享验证，避免触发平台处罚
2. **回复频率**：消息自动回复（兜底）对同一用户每小时限 1-2 条，流程设计已全部基于"用户主动发消息"触发，天然规避
3. **不做延时回复**：官方规则下关注回复不支持延时，仅调整多条消息顺序
4. **不设计主动触达环节**：个人订阅号无客服消息/模板消息权限，任何"系统到点主动找用户"的设计都不成立
