# 杜衡阁公众号回复与小程序推广优化方案

日期：2026-10-18｜状态：设计建议，尚未修改或发布公众号规则。

## 一、目标与统一定位

公众号负责内容触达、需求分流与资料领取，杜衡阁小程序负责练习、素材积累和学习记录。对外统一使用“杜衡阁”，不再让用户理解旧方案里的“知行日知 / 知行策论”双产品关系。

核心表达：**读到好内容，顺手练起来。**

主要路径：公众号文章或金句卡 → 对应关键词 / 文末小程序入口 → 一个明确的学习页面 → 完成一次练习或积累。欢迎语突出小程序；具体回复只推荐与本次需求相关的一项功能。

推广优先级：小程序统一入口 > 每日练习与金句素材 > 申论练习与速算训练 > 知识框架 > 专项资料领取。

## 二、依据与功能边界

用户已确认杜衡阁小程序上线。本方案核对当前仓库代码与项目操作手册；本次未连接生产数据库、未核对微信线上包版本及公众号实际权限。因此，“代码已实现”与“线上可投放”分别验收。

| 能力 | 当前证据与边界 | 推广安排 |
|---|---|---|
| 杜衡阁小程序 | 用户确认已上线；根工程为主产品 | 主推广入口 |
| 每日练习 / 专题练习 | 首页露出；每日练习进入题目选择页 | 首批推广，核对正式版内容可用 |
| 金句素材 | 首页露出；后台审核通过且启用才向学员展示 | 首批推广，主承接公众号金句内容 |
| 资料分析 / 速算训练 | 首页有速算入口；近期扩展在手册中仍有“本地实现、待部署”记录 | 只宣传正式版已有训练，不宣称扩展题型全部上线 |
| 知识框架 | 首页露出，后台维护 | 首批辅助入口，先检查正式版可见节点 |
| 申论练习 | 已有题目审核发布、学员作答、参考要点与订正页面 | 核对正式版和已发布题目后开放关键词；不用“AI批改 / 自动评分”表述 |
| 后台词汇素材、申论素材 | 当前供教研维护，不能据菜单存在认定学员可见 | 转化为公众号内容及已发布练习的供给，不宣传独立学员素材库 |
| 金句采集、自动出题、教研反馈、模型用量 | 内容生产与管理能力 | 用于提高供给与审核质量，不作为用户功能入口 |
| 错题与学习记录 | 有登录及对应功能边界 | 放在练习后的使用说明，不占首屏主推广位置 |
| 隐藏功能及其他独立小程序 | 主端部分菜单隐藏；百宝箱等为独立产品 | 本轮不混入公考导航 |

后台菜单增加，不等于公众号应该增加同样数量的入口。面向用户按“我想练题 / 积累表达 / 练申论 / 练速算 / 找资料”组织。

## 三、现有回复需要解决的问题

1. 默认欢迎语仍要求回复 1/2/3，主推今日文章、时政练习、时评精拆，与现有小程序首页不一致。
2. 默认“时政练习”仍描述“阅读全文 → 考点练习”，手册中的时政要点已改为一条要点一套题，回复应按现有产品重写。
3. 默认“申论”进入旧时评文章列表，未体现新申论练习承接。
4. 现有三个变量仅生成 H5 地址：`today_url` 实际指向首页、`theory_url` 指向题目选择、`rmrb_url` 指向时评文章列表。不能将旧变量重命名后直接假装小程序入口。
5. 当前回调只构建文本 XML，不能把一段普通页面路径当作可点击小程序卡片。
6. 默认配置只在初始化时使用；已有数据库发布版本不会因改默认常量自动升级。正式生效必须通过“消息回复”保存、校验、预览、发布。

## 四、公众号菜单设计

建议使用三个主菜单，名称均围绕用户动作：

| 主菜单 | 子入口 | 去向 |
|---|---|---|
| 开始练习 | 每日练习 | 小程序每日练习页 |
| 开始练习 | 申论练习 | 小程序申论题目列表，验收后开放 |
| 开始练习 | 速算训练 | 小程序正式版已有速算页 |
| 素材积累 | 金句素材 | 小程序金句列表 |
| 素材积累 | 知识框架 | 小程序知识框架 |
| 学习帮助 | 打开杜衡阁 | 小程序首页 |
| 学习帮助 | 资料领取 | 资料导航回复或可维护说明页 |
| 学习帮助 | 使用说明 | 固定说明页或导航回复 |
| 学习帮助 | 问题反馈 | 小程序反馈页 |

初次上线可只开放已核验入口，避免空菜单。菜单跳转小程序是推荐配置，需在微信后台核对账号能力、小程序关联和发布权限。当前项目不具备自动发布公众号菜单的管理功能；本方案不将菜单设计视为已完成配置。

若采用 `click` 事件菜单，当前回调未实现对应菜单键路由，需要开发后才能使用；不要直接配置后期待关键词规则自动接管事件。能在微信后台直接选择小程序页面的入口，优先按实际可用配置方式完成。

## 六、首期可用回复文案

以下是“文本回调即可落地”的版本。菜单配置未完成前，将“点击下方菜单”统一换成“在微信搜索小程序『杜衡阁』”，不能提前承诺可点击入口。

### 1. 关注欢迎语

```text
欢迎来到「杜衡阁」🌿
读到好内容，顺手练起来。

杜衡阁小程序已上线：练题、积累金句、梳理知识，都能从这里开始。

点击下方菜单「学习帮助 → 打开杜衡阁」，先完成一次学习。

也可回复：
「练题」找练习｜「金句」积累表达
「资料」领资料｜「菜单」看完整导航
```

### 2. 小程序

```text
杜衡阁小程序已上线。

想练题，选「每日练习」；
想积累表达，选「金句素材」。

点击下方菜单「学习帮助 → 打开杜衡阁」。
也可在微信搜索小程序「杜衡阁」。
```

### 3. 每日练习 / 专题练习

```text
今天先完成一组练习。

打开杜衡阁小程序，进入「每日练习」，选择一组题，作答后查看解析。

点击下方菜单「开始练习 → 每日练习」。
```

时政规则可用同一结构，将首句改为“把读过的要点，变成一次练习”，不再承诺必须先阅读全文。登录记录等说明以正式版实际支持为准。

### 4. 金句

```text
好句子，记住以后还要会用。

打开杜衡阁小程序「金句素材」，查看已整理的句子，挑一句用于今天的表达练习。

点击下方菜单「素材积累 → 金句素材」。
```

### 5. 申论（正式版验收通过后启用）

```text
申论积累之后，再动笔练一题。

进入杜衡阁小程序「申论练习」，选择已发布题目，先作答，再对照参考要点与解析订正。

点击下方菜单「开始练习 → 申论练习」。
这是自主练习与参考解析，不提供自动评分。
```

### 6. 速算

```text
资料分析，先把计算练熟。

进入杜衡阁小程序「速算训练」，选择当前开放的训练，做完一组再看解析。

点击下方菜单「开始练习 → 速算训练」。
```

### 7. 知识框架

```text
知识点零散时，先看看它们的关系。

打开杜衡阁小程序「知识框架」，选择要复习的主题，按结构梳理。

点击下方菜单「素材积累 → 知识框架」。
```

### 8. 资料导航

```text
目前可领取：
回复「十五五」：规划纲要360题资料。

想直接练题，可回复「练题」。
```

十五五专属回复保留原有文件名、领取链接、口令及“模拟练习、不是官方真题”的说明。只在末尾增加一行：“想接着练题，回复「练题」进入杜衡阁学习入口。”不擅自替换历史领取地址。

### 9. 菜单

```text
杜衡阁｜学习导航

「小程序」打开杜衡阁
「练题」每日练习
「金句」积累表达
「速算」计算训练
「框架」梳理知识
「资料」领取资料

回复对应关键词即可。先选一项，完成一次学习。
```

申论正式承接验收后，在金句后增加“「申论」动笔练习”。

### 10. 兜底与非文字消息

兜底：
```text
暂时没识别到对应入口。
回复「小程序」打开杜衡阁，或回复「菜单」查看学习导航。
```

非文字：
```text
自动回复目前支持文字关键词。
请发送「练题」「金句」或「菜单」。
```

未知事件回复使用简短导航或按后续事件设计处理；取消关注等不适宜回复的事件继续遵循现有回调处理，不批量发送推广消息。不得暗示存在人工客服、自动加群或后续定时回复能力。

## 七、小程序打开方式与技术落地

### 第一阶段：配置现有文本回复 + 微信菜单

现有草稿、规则、预览、发布、回退可复用。文本明确告诉用户从菜单打开，搜索小程序作为备用。公众号文章由运营人员插入实际可用的小程序入口或小程序码；本系统尚未自动生成或发布这些入口。

公众号文本回调、客服消息、自定义菜单、文章内小程序入口属于不同能力，不可混用。当前只返回文本，不承诺回复小程序卡片；普通 HTTPS H5 地址也不能标注成“小程序直达”。

| 功能 | 代码注册的小程序候选路径 | 首发验证 |
|---|---|---|
| 首页 | `pages/index/index` | 正式包、冷启动 |
| 每日练习 | `pages/question/article-pick` | 有题、可提交及看解析 |
| 金句素材 | `pages/quotes/index` | 只见已审核启用内容 |
| 速算训练 | `pages/ziliao/quick-calc` | 正式版本支持的题型 |
| 知识框架 | `pages/knowledge/index` | 已发布节点可见 |
| 申论练习 | `pages/rmrb/exercise-list` | 有已发布题、作答与订正可用 |
| 反馈 | `pages/user/feedback` | 登录及提交行为 |

以上是代码路径候选，不等于已验证线上菜单路径。不得将需要任务参数的 `pages/shenlun/training` 直接作为通用入口。所有页面先通过微信实际跳转，再投入运营。

### 第二阶段：后台入口管理（需要开发）

保留“系统 → 消息回复”，不新建重复菜单。页面建议分为“基础回复 / 关键词规则 / 推广入口 / 模拟预览 / 发布记录”。

新增入口目录：业务名称、目标类型（小程序/H5/资料）、受控页面路径、是否开放、备用入口、最近人工核验时间、状态说明；AppID 等标识引用服务端账号配置，不复制到方案或导出中，密钥不进数据库正文。

规则从自由拼链接演进为“文案 + 入口绑定”，由统一渲染层生成最终文字；入口变更与规则同一发布快照保存，回退时一起恢复。新变量只有加入服务端白名单和预览器后才能使用。现阶段不能直接填写 `{{miniapp_url}}` 等不存在的变量。

发布检查：重复标准化词、旧别名遗漏、未验收目标、未发布内容、占位符、长度、入口降级、版本记录。新版本发布后仍沿用现有按版本隔离的去重机制。

优先开发入口管理与人工核验记录，再评估菜单发布接口、动态小程序入口或卡片。微信账号实际接口权限未核验前，不将它们写入首发承诺。

## 八、内容推广联动

| 内容类型 | 单一主引导 | 后台供给 |
|---|---|---|
| 公众号金句合集 | 文末“去杜衡阁积累金句”；无直接入口时回复「金句」 | 金句管理审核启用 |
| 时政要点 / 专题内容 | 文末“去做一组练习”，回复「练题」 | 时政要点与套题 |
| 申论方法 / 素材示例 | 关联同主题申论题；未有同题时明确为练习列表 | 申论素材教研 → 审核发布题目 |
| 资料分析技巧 | 关联正式版已有训练，回复「速算」 | 资料分析规则与解析 |
| 知识梳理 | 关联对应框架，回复「框架」 | 已发布知识节点 |
| PDF 资料文章 | 主引导领取原资料，末尾一句带到小程序练题 | 资料链接人工维护 |

文章模板示例：

> 今天读完了，再动手练一下。进入「杜衡阁」小程序，选择每日练习，完成一组题。也可回到公众号回复「练题」获取入口说明。

不要在每篇末尾塞入全部功能。历史文章已承诺的关键词继续可用。不得将纸版/客户端来源素材的存在表述为人民日报官方合作、官方题库或官方小程序。

## 九、上线顺序与验收

### 批次 A：运营配置，优先完成

1. 从后台读取并备份当前已发布版本；本方案核对的是代码默认值，实际线上文案须以该版本为准。
2. 真机核对小程序正式版：首页、练题、金句、速算、框架；申论单独验收。
3. 在公众号后台核对关联、菜单能力、当前服务器接管和现有菜单配置方式；避免两套规则重复接管。
4. 录入新欢迎语、关键词、兜底；保留旧数字词及十五五领取规则。逐个预览关键词并模拟关注。
5. 完成菜单配置后再采用“点击下方菜单”文案；未完成时使用搜索小程序版本。
6. 发布回复快照，用真实微信分别测试关注、关键词、未命中、图片、旧词和菜单跳转。
7. 同步两篇新文章的文末入口，记录发布日期、规则版本、菜单配置及验证结果。

### 批次 B：申论推广

正式小程序路径可达、有已发布练习、参考要点和订正闭环真实可用后，启用申论规则并调整菜单。仅有后台菜单不能验收。

### 批次 C：入口管理与统计开发

按前述设计开发入口目录、绑定、发布校验、回退与数据采集，再考虑菜单发布和更多消息形式。

验收必须包含：精确词及带标点输入、全部历史别名、冲突词、登录前后、冷启动、无内容、资料链接失效、菜单未配置、已发布入口撤回、规则回退。核心入口打不开时先将对应规则改成可用备用说明，并发布新版本；不继续投放坏入口。

## 十、效果衡量与维护

初期用人工表记录每周新增关注、文章阅读、微信平台可提供的小程序访问及用户反馈；平台未提供的数据记“不可得”，不填零。规则命中次数、来源归因及学习完成漏斗均需先核对或补充采集，不能把预览或菜单配置次数当实际用户打开。

后续建议事件：`wechat_reply_matched`（规则/版本）、`promotion_entry_opened`（入口/来源）、真实业务学习完成事件。公众号消息身份和小程序用户身份不默认相同，不用未经验证的身份关联推算转化率。跨端无法关联时只比较聚合趋势。
