# 当前公众号消息回复功能与“十五五”资料回复

更新日期：2026-10-07

## 当前实现梳理（2026-10-07 第一阶段已开发）

- **回调入口**：`POST /api/wechat/callback` 接收公众号服务器推送的消息；`GET /api/wechat/callback` 用于公众号服务器地址验证。
- **启用条件**：`WECHAT_OFFICIAL_ENABLED=true`，并配置有效的 `WECHAT_OFFICIAL_TOKEN`。回调未启用或配置不完整时接口拒绝处理。
- **当前路由方式**：确定性规则保存在数据库已发布快照中，支持关注欢迎语、今日学习、时政练习、时评精拆、菜单、十五五网盘资料、兜底和非文字消息提示；同一消息短时间重复投递会复用回复结果，切换发布版本后使用新的去重命名空间。
- **配置界面**：管理后台“公众号运营 → 消息回复”可编辑草稿、检查冲突、模拟预览、发布和回退。超管可发布/回退；编辑角色可查看和保存草稿；只读角色可查看。
- **初始化方式**：应用启动时将当前固定回复迁移为初始发布版本；新表由 SQLAlchemy `create_all` 自动创建。版本快照不可覆盖，回退会创建新发布版本。
- **服务器接管说明**：如果公众号在微信公众平台配置了开发者服务器回调，消息由应用后端处理。此时不应再在公众平台或第三方客服系统中重复配置相同关键词，避免双重回复。

## 生效边界

第一阶段修改目前位于本地代码和数据库设计中，尚未部署生产。应用回调是否接管公众号仍由微信公众平台的开发者服务器配置决定；本功能不会自动修改公众号原生“被关注回复/关键词回复”设置。若公众号使用应用回调，部署后在应用后台发布规则；若仍使用公众号原生自动回复，则需要在微信公众平台配置。
