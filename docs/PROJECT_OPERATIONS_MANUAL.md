# 知行全项目操作指引

> 文档范围：知行仓库内的学员端、各独立微信小程序、H5、共享后端与管理后台。本文不包含任何 AppID、AppSecret 或第三方 API 密钥。
> 功能以当前代码和对应产品说明为准；最后核对：2026-10-16。

## 1. 产品与系统关系

此仓库包含一个主学员端和四个独立小程序工程。学员端工程、微信 AppID、客户端存储和发布版本彼此分开；FastAPI 服务、数据库和 Vue 管理后台由仓库共用。不同产品通过 `X-Product-Key` 和微信登录时的 `X-Wechat-App-Key` 选择产品范围及对应凭据。

| 产品 | 工程目录 | 客户端形态 | 产品标识 | 管理后台入口 |
|---|---|---|---|---|
| 杜衡阁（知行公考） | 根目录 `src/` | 主 H5 + 微信小程序 | `general` | 侧栏：时政要点、人民日报（金句管理/词汇素材/申论素材）、知识框架、资料分析、用户、反馈、设置、消息回复、角色、操作指引 |
| AI 百宝箱 | `baibaoxiang/` | 独立微信小程序 | `general`；微信登录键 `baibaoxiang` | 侧栏“工具配置”显示图片配置、模型配置、图片记录和模型用量；文案配置仍可直链 `/manage/tool-config/copy` |
| 知库 | `zhishiku/` | 独立微信小程序；提供 H5 调试构建 | `zhiku` | 知库文档。侧栏已收起，直链 `/manage/knowledge-library` |
| 言遇英语 | `kaikoushuo/` | 独立微信小程序；提供 H5 调试构建 | `general`；微信登录键 `yanyu_english` | 英语学习。侧栏已收起，直链 `/manage/english/overview` |
| 光线练习簿 | `sheying/` | 独立微信小程序；提供 H5 调试构建 | `general`；微信登录键 `sheying` | 摄影学习。侧栏已收起，直链 `/manage/photography/courses` |

### 共享服务

- FastAPI：学员接口 `/api/*`，管理接口 `/admin/*`，健康检查 `/health`。
- 管理前端：Vue 3 + Vite，开发地址通常为 `http://localhost:5173/manage/`，生产挂载在 `/manage/`。
- 数据：SQLAlchemy + SQLite；上传文件及生成结果放在服务器数据卷内。具体备份与恢复方式见 `docs/release/cloud-server-deploy-guide.md`。
- 生产入口：域名 HTTPS → Nginx → Docker 中的 FastAPI；主 H5、管理前端和 API 由同一部署镜像提供。

## 2. 客户端功能清单

### 2.1 知行公考：根目录 `src/`

主端提供 H5 和微信小程序。当前审核整改展示版将首页和练习入口定位为公考练习，入口名称使用“每日练习 / 专题练习 / 行测真题”；金句素材、知识框架、签到、错题和账号能力保留。**本轮仅调整客户端展示文案和层级；时政要点、文章、时评及金句数据/API、后台和深链均未下线。**微信小程序打开登录页会先走微信登录；昵称仍是默认且没有头像时，先完善资料。

首页、练习、个人中心的实际露出受 `src/constants/featureVisibility.ts` 控制。页面清单见 `FEATURES.md`。

### 2.2 AI 百宝箱：`baibaoxiang/`

- 工具首页、分类和搜索；个人中心提供本地收藏、最近浏览和偏好设置。
- 微信登录、个人资料及反馈使用共享后端。
- 照片换风格：选图、选择已发布风格、生成前确认；登录后上传处理、查看任务状态并保存结果。
- 可用模型、图片风格和实际生成能力由管理后台配置；服务商密钥只从服务端环境变量读取。未配置可用模型/密钥时，生成不能完成。
- 本机后台图片配置保留原有“旅行手账·清透淡彩”，另有四种已复核风格和草稿“钢笔淡彩·漫游手账”；草稿含用户提供的原图/生成图对照图，仅用于后台测试。其余探索风格已从本地配置清理；源文件和配置说明见 `docs/ai-image-styles/`。本地数据库状态不会自动同步到生产服务器。
- 其他尚未实现的工具会显示准备中，不代表已经可用。

### 2.3 知库：`zhishiku/`

- 浏览后台发布的资料目录，按关键词搜索和分类筛选。
- 微信登录后可上传、阅读和删除个人文档；支持 MD、TXT、PDF、DOCX。
- 阅读页展示提取文本、只读提示和身份水印；个人上传文档仅本人可见。
- 扫描版 PDF 目前标记为待 OCR；文档权限、付费和定向分享能力尚未接入。

### 2.4 言遇英语：`kaikoushuo/`

- 今日推荐、英语场景浏览和课程单元练习。
- 对话中英对照、核心句块、情境替换任务；支持视频/音频媒体、字幕显示控制、录音回放或删除本地录音。
- 学习完成记录、学习统计和次日复习提示；完成记录可绑定微信登录用户。
- 管理后台可维护媒体类型、URL、官方来源和授权状态；只有标记为已获托管许可的直播放地址会在小程序内播放，外链课程只显示来源复制入口。
- 当前已发布 3 个原创情景单元，尚无已配置示范音视频；美剧及第三方学习视频需完成授权核验后再入库。

### 2.5 光线练习簿：`sheying/`

- 首页、技巧课程、课程详情、摄影知识地图、拍摄练习记录和个人练习统计。
- 已发布作品案例提供画面观察、EXIF、标明依据的摄影推断和一项关联本地练习记录的拍摄任务；案例由后台人工录入与审核。课程和案例通过 API 加载，API 不可用时保留内置课程。
- 微信登录关联用户身份；练习记录当前保存在设备本地，尚未同步到云端。
- 自动 AI 拆解、用户图片上传分析、云端练习档案属于后续规划；详细设计见 `内容运营/摄影/04-优秀摄影作品解析与练习闭环优化方案.md`，发布状态以代码为准。

## 3. H5 与微信小程序

- 根目录 H5 是知行公考主 H5，生产构建由 Docker 镜像打包；本地端口默认 `10087`。
- 根目录微信包由 `npm run build:weapp` 构建，生成 `dist/`。
- 微信端学习/我的使用 `pages/index/index` 单页容器与自定义底栏切换，页面内保留两侧面板，避免主 Tab 路由切换造成空白帧；H5 仍用独立页面路由。旧的 `pages/user/index` 微信路径会转到单页容器的“我的”面板。
- `kaikoushuo/`、`zhishiku/`、`sheying/` 是各自独立的 Taro 工程，可运行 H5 调试构建；其正式发布目标仍以各自微信小程序为准。
- `baibaoxiang/` 当前提供独立微信小程序构建，并在构建前同步项目配置。
- 每个小程序必须在微信开发者工具中核对项目名称与 AppID，上传后先进入开发版本；设为体验版是微信后台的后续操作。
- 微信 `AppSecret`、模型密钥等只放服务器 `.env`；不能写入小程序源码或构建包。微信请求域名在公众平台单独配置。

## 4. 管理后台功能与内容操作

管理后台是所有产品共用的一套 Vue 应用。日常侧栏只露出杜衡阁正在用的菜单。其他产品的页面和路由仍在，按上表直链进入。隐藏范围写在 `server/admin-web/src/config/featureVisibility.ts`。

| 后台菜单 | 状态 |
|---|---|
| 时政要点 | 侧栏可见。服务端分页（每页20/50/100条），一条要点一套题，可导入，也可逐题修改。不关联文章 |
| 金句管理 | 侧栏可见。先审核，通过后才能启用；列表同时显示来源文章日期与采集日期 |
| 词汇素材 | 人民日报分组内的新入口；按刊期、词语、类型、审核状态筛选；按日期采集当天全版面文章，AI 提取成语/固定表达/重点词语，逐条硬校验原文上下文，人工采用/退回/编辑，按刊期去重并保留多来源 |
| 申论素材 | 人民日报分组内的新入口；按来源日期、主题、类型、审核状态检索，维护事实/出处/主题场景/原创示例/使用边界；JSON 导入先预览校验，低于8分或触发否决的记录不能确认为合格素材 |
| 申论练习 | 人民日报分组内的新入口；编排四类申论练习，绑定来源文章和材料依据，审核后发布至小程序；学员提交后查看要点、评价维度和参考答案，可保存订正；后台页面分为“题目管理 / 自动出题 / 教研反馈”三个 Tab：题目管理维护练习；自动出题查看每日任务和运行批次；教研反馈提供按生成规则版本对照审核结论与修改率的统计，并可按当前题型分页导出完整 JSON 样本，样本附带审核时内容快照 |
| 模型用量 | 侧栏可见；按模块和日期统计调用、token、失败及配置价格后的费用估算 |
| 资料分析 | 侧栏可见；维护公式、题型、技巧和按概念组织的速算训练。速算包含分数比较、增长量/率、基期量、比重、平均数、倍数、混合增长率、独立的隔年增长率和年均增长、贡献率/拉动等；训练中组合多分数比较/排序、直接计算、计算辨析和混合材料题。年均复合增长率题使用多年度样本，解析既展示开方精确式，也提供快捷估算；隔年增长率按连续两年同比增速复合计算。数据改编题显示来源，不宣称为真题复刻；基期量题使用官方两期粮食产量/单产或货物贸易数据，题干标出来源、年份与单位，增速按一位小数展示并按题面数据求近似基期量。若真实样本在一位小数下无法区分选项，可显示两位小数。比重、平均数和倍数关联知识框架的“比重 | 倍数 | 平均数（比值）”节点；规则需关联已发布且学员可见的知识节点，再预览、发布；效果按题型及题目形式统计（需要 `ziliao:read` / `ziliao:write`）。速算扩展当前仅本地实现，尚未部署 |
| 知识框架 | 侧栏可见 |
| 用户、反馈、设置、消息回复、角色、操作指引 | 侧栏可见。用户列表可按昵称搜索，并区分微信与账号密码 |
| 文章、分类、今日学员端、时评精拆、行测 | 侧栏已隐藏，路由仍可直链 |
| 知库文档、英语学习、摄影学习、文案配置 | 侧栏已隐藏，路由仍可直链，对应其他小程序；工具配置组中的图片配置、模型配置、图片记录和模型用量已在管理后台侧栏开放 |

### 常用内容发布流程

1. 打开 `/manage/` 并用有相应读写权限的管理员账号登录。
2. 进入对应产品菜单创建或编辑内容，补齐必填字段及素材。
3. 保存草稿后检查预览、排序和发布状态；确认后发布。
4. 在对应小程序/H5 刷新内容。若客户端有缓存，重新进入页面或执行下拉刷新。

### 学员端时政要点与金句素材

1. 在「时政要点」创建要点或小节，填写摘要并发布。套题用导入写入这一条，不选文章。学员端点这一条就刷这一套。
2. 登录后练习会保存进度。重复练习不重复计分，错题可订正并更新错题本。
3. 金句在「金句管理」审核通过并启用后，出现在学员端「金句素材」。未启用的不会展示。

### 人民日报金句、词汇与申论素材

1. 金句任务先整理当天人民日报纸版评论内容；纸版入库不足 3 句时，补采人民日报客户端评论页最近 24 小时文章。客户端正文仅用于当次筛选，不写入全量文章档案。词汇与申论素材复用人民日报纸版采集与分析结果。自动任务需要服务端 LLM 配置，也可按需手动重跑。
2. 新结果均进入待审核。核对原文、来源、主题和用途后，再采用或退回；AI评分不能替代人工核验。
3. 金句任务状态展示纸版发现/处理数、客户端补采数、候选句数、入库数及零结果原因；上游词汇任务最多等待至北京时间 08:30，之后金句任务独立启动。可按日期、关键词、类型和审核状态筛选，编辑单条内容；导入 JSON 前先预览重复与无效项。导入不会自动发布。
4. 金句须先审核通过并启用，才会出现在学员端；词汇和申论素材当前仅供后台教研使用。

### 申论练习

1. 在「人民日报 → 申论练习」新建或编辑四类题目：归纳概括、提出对策、贯彻执行、申发论述。题目需关联可核验的来源与材料摘录。
2. 补齐题干、作答要求、参考要点及逐点材料依据、参考答案和解析；人工核对后再发布。AI草稿只进入审核队列，不会自动公开。
3. 学员提交后可查看参考要点、材料依据、评价维度、示例答案和解析，并进行订正复盘；系统不自动给申论作答打分。
4. 「自动出题」查看每日任务与批次；「教研反馈」汇总审核结果并支持导出样本。审核样本可用 `python3 server/scripts/analyze_shenlun_review_dataset.py <样本.json>` 生成复盘报告。

### 人民日报素材采集与模型用量

1. 金句、词汇和申论素材复用同一批文章采集与分析结果，减少重复调用；采集正文会按系统保留策略自动清理。
2. 在「模型用量」查看调用次数、Token、耗时和失败情况；配置输入、输出单价后可查看费用估算。
3. 具体调度时间、保留策略和规则版本见`server/README.md`；历史变更状态见`docs/PROJECT_OPERATIONS_CHANGELOG.md`。

## 5. 本地开发与构建

### 知行主端

```bash
npm install
npm run dev:h5       # H5，默认 http://localhost:10087
npm run build:h5
npm run dev:weapp
npm run build:weapp  # 微信代码产物 dist/
npm run lint
```

### 独立小程序

```bash
cd baibaoxiang && npm install && npm run dev:weapp
cd zhishiku && npm install && npm run dev:weapp
cd kaikoushuo && npm install && npm run dev:weapp
cd sheying && npm install && npm run dev:weapp
```

正式上传前在对应目录执行 `npm run build:weapp`，然后用微信开发者工具打开该项目，核对名称、AppID、`dist/` 产物和服务器域名。各工程的详细环境变量以对应 README 和 `.env.example` 为准。

### 后端与管理端

```bash
cd server
source .venv/bin/activate
uvicorn app.main:app --reload --port 8001

cd server/admin-web
npm install
npm run dev          # http://localhost:5173/manage/
# 多个 checkout 同时开发时，可指定后端及空闲前端端口：
# VITE_API_PROXY_TARGET=http://127.0.0.1:8002 npm run dev -- --port 5174
npm run build        # vue-tsc + Vite，产物 server/admin-dist
```

H5 本地访问 API 时，检查 `CORS_ORIGINS`；微信小程序请求不依赖浏览器 CORS，但需要在微信后台配置 HTTPS 合法域名。

## 7. 部署、数据与常见操作

- 生产更新按 `docs/release/cloud-server-deploy-guide.md` 执行；当前生产服务器内存有限，优先使用本机 `bash scripts/deploy-from-local.sh` 构建镜像并传输。
- 不要在生产服务器执行 `docker compose --build`，不要运行 `docker compose down -v`，不要覆盖服务器 `.env`。
- 部署后核验 `/health`、主 H5 `/`、管理端 `/manage/` 及本次变更涉及的 API。
- 数据备份、恢复、域名与 Nginx 配置按 `DEPLOY.md` 和云服务器部署指南操作。
- 生产数据库与上传资源位于 Docker 数据卷；发布管理端菜单/功能需要重新构建并部署完整镜像。

## 8. 文档维护规则

每次新增、修改、下线功能时，都要同步检查并更新：

1. 本文：产品矩阵、功能状态、后台操作、发布/运维步骤有变化就更新。
2. 对应产品 README：开发、构建、配置和发布步骤变更时更新。
3. `FEATURES.md`：知行主端页面、路由、隐藏状态和模块行为变更时更新。

### 2026-10-17 · 速算训练按题型组织（本地实现，待部署）

速算训练统一为分数比较、增长量、增长率、基期量四种题型。分数比较在同一组内覆盖分数性质、差分比较、同位比较和分母拆分场景，作答前只展示数据，作答后解析给出优先建议与推导。管理端按题型配置、预览和发布；新增分数比较规则初始为草稿，需显式发布。旧比较方法规则、版本及训练快照保留，历史统计和薄弱项推荐归入分数比较，建议方法分布单独统计。无需新增权限、菜单或环境变量。

### 2026-10-17 · 速算练习题目形式扩展（本地实现，待部署）

练习组自动组合两数比较、多分数选极值、多分数排序、直接计算、四项计算辨析。计算辨析题会明确要求选择唯一正确项或唯一错误项。管理端预览检查实际题目形式，训练效果可查看不同形式的答题数量。多分数排序属于教学模拟题；上生产前按标准流程部署后端并构建小程序包。

### 2026-10-17 · 混合训练综合材料辨析（本地实现，待部署）

混合训练选择 10 题或 20 题时，系统在每 10 题中加入 1 道综合材料辨析；需要增长量、增长率、基期量训练方法均处于已发布状态。材料使用同源同单位公开统计数据，四项选择分别考增长量、增长率、基期量和现期量，题干会随机要求选正确项或错误项。答后逐项查看计算结果与解析。该题记为综合材料辨析，不会归入某个单一计算概念的薄弱推荐。当前不需要管理员新增方法或单独发布该题型；该实现尚未部署。

### 2026-10-18 · 速算训练概念扩展（本地实现，待部署）

训练题型新增比重、平均数、倍数、混合增长率、隔年增长率、年均增长、贡献率/拉动。隔年增长率使用连续两年同比增速复合；年均增长率独立使用末期/初期比值开增长次数次方根，并在解析给出对称近似和选项代入法；年均题只抽取至少两个增长年度的数据。后台按题型校验和发布，知识框架节点必须已发布且对学员可见。题源来自国家统计局 2022—2024 年粮食分省产量/单产及分项、GDP 现价产业构成，以及 2023—2024 年海关贸易统计；增长量与增长率还会轮换粮食产量、单产的真实两期数据，优先保证正负增长场景均衡。计算辨析题仅使用展示精度下能区分常见错项的数据（增长量至少 2.5% 增速、增长率至少 0.5%），增长率训练包含低幅度增速；不使用人为“多计/少计”数值凑选项，更小增幅保留给其他概念练习。训练组按官方样本轮换，不足时不得伪造统计值；数据改编题不当作真题原题。增长量解题建议按数据特征选用除乘转化、乘数拆分、假设估算或错位加减，不以 n＋1/n−1 命名训练方法。使用 5/10/20 题训练时，服务端独立复核题源与计算关系、答案和干扰项唯一性；后台训练效果除汇总正确率、用时、错选项外，也按题目形式统计正确率和平均用时。若采用 GDP 混合增速，解析会标明现价口径，避免误作官方不变价实际增速。本功能目前仅本地实现，待部署。
