# 知行全项目功能与操作手册

> 文档范围：知行仓库内的学员端、各独立微信小程序、H5、共享后端与管理后台。本文不包含任何 AppID、AppSecret 或第三方 API 密钥。
> 功能以当前代码和对应产品说明为准；最后核对：2026-10-10。

## 1. 产品与系统关系

此仓库包含一个主学员端和四个独立小程序工程。学员端工程、微信 AppID、客户端存储和发布版本彼此分开；FastAPI 服务、数据库和 Vue 管理后台由仓库共用。不同产品通过 `X-Product-Key` 和微信登录时的 `X-Wechat-App-Key` 选择产品范围及对应凭据。

| 产品 | 工程目录 | 客户端形态 | 产品标识 | 管理后台入口 |
|---|---|---|---|---|
| 知行公考 | 根目录 `src/` | 主 H5 + 知行微信小程序 | `general` | 公考、时政、申论、题库等菜单 |
| AI 百宝箱 | `baibaoxiang/` | 独立微信小程序 | `general`；微信登录键 `baibaoxiang` | 工具配置、模型配置、图片生成记录 |
| 知库 | `zhishiku/` | 独立微信小程序；提供 H5 调试构建 | `zhiku` | 备考教学 → 知库文档 |
| 言遇英语 | `kaikoushuo/` | 独立微信小程序；提供 H5 调试构建 | `general`；微信登录键 `yanyu_english` | 英语学习 |
| 光线练习簿 | `sheying/` | 独立微信小程序；提供 H5 调试构建 | `general`；微信登录键 `sheying` | 摄影学习 |

### 共享服务

- FastAPI：学员接口 `/api/*`，管理接口 `/admin/*`，健康检查 `/health`。
- 管理前端：Vue 3 + Vite，开发地址通常为 `http://localhost:5173/manage/`，生产挂载在 `/manage/`。
- 数据：SQLAlchemy + SQLite；上传文件及生成结果放在服务器数据卷内。具体备份与恢复方式见 `docs/release/cloud-server-deploy-guide.md`。
- 生产入口：域名 HTTPS → Nginx → Docker 中的 FastAPI；主 H5、管理前端和 API 由同一部署镜像提供。

## 2. 客户端功能清单

### 2.1 知行公考：根目录 `src/`

主端提供 H5 和微信小程序构建。核心学习链路包括：

- 今日驾驶舱、考试倒计时、今日任务、复习提醒和学习足迹。
- 时政文章阅读、文章题目、时事推荐和文章错题。
- 申论/人民日报时评阅读、精拆、规范词与阶梯训练。
- 行测题目、真题套卷、资料分析专项练习和手动错题。
- 知识框架、学习计划、复习中心、事件复盘、语料积累。
- 用户登录、签到积分、排行、主题设置和反馈。

首页、练习、个人中心等功能的实际露出受 `src/constants/featureVisibility.ts` 控制；隐藏功能可能仍保留路由。按页面、路由及当前隐藏状态查 `FEATURES.md` 和 `docs/planning/FEATURE_INVENTORY.md`。

### 2.2 AI 百宝箱：`baibaoxiang/`

- 工具首页、分类和搜索；个人中心提供本地收藏、最近浏览和偏好设置。
- 微信登录、个人资料及反馈使用共享后端。
- 照片换风格：选图、选择已发布风格、生成前确认；登录后上传处理、查看任务状态并保存结果。
- 可用模型、图片风格和实际生成能力由管理后台配置；服务商密钥只从服务端环境变量读取。未配置可用模型/密钥时，生成不能完成。
- 其他尚未实现的工具会显示准备中，不代表已经可用。

### 2.3 知库：`zhishiku/`

- 浏览后台发布的资料目录，按关键词搜索和分类筛选。
- 微信登录后可上传、阅读和删除个人文档；支持 MD、TXT、PDF、DOCX。
- 阅读页展示提取文本、只读提示和身份水印；个人上传文档仅本人可见。
- 扫描版 PDF 目前标记为待 OCR；文档权限、付费和定向分享能力尚未接入。

### 2.4 言遇英语：`kaikoushuo/`

- 今日推荐、英语场景浏览和课程单元练习。
- 对话中英对照、核心句块、情境替换任务；支持视频/音频媒体、字幕显示控制、录音回放或删除本地录音。
- 学习完成记录、学习统计和次日复习提示；完成记录可绑定微信登录用户。
- 管理后台可维护媒体类型、URL、官方来源和授权状态；只有标记为已获托管许可的直播放地址会在小程序内播放，外链课程只显示来源复制入口。
- 当前已发布 3 个原创情景单元，尚无已配置示范音视频；美剧及第三方学习视频需完成授权核验后再入库。

### 2.5 光线练习簿：`sheying/`

- 首页、技巧课程、课程详情、摄影知识地图、拍摄练习记录和个人练习统计。
- 已发布作品案例提供画面观察、EXIF、标明依据的摄影推断和一项关联本地练习记录的拍摄任务；案例由后台人工录入与审核。课程和案例通过 API 加载，API 不可用时保留内置课程。
- 微信登录关联用户身份；练习记录当前保存在设备本地，尚未同步到云端。
- 自动 AI 拆解、用户图片上传分析、云端练习档案属于后续规划；详细设计见 `内容运营/摄影/04-优秀摄影作品解析与练习闭环优化方案.md`，发布状态以代码为准。

## 3. H5 与微信小程序

- 根目录 H5 是知行公考主 H5，生产构建由 Docker 镜像打包；本地端口默认 `10087`。
- 根目录微信包由 `npm run build:weapp` 构建，生成 `dist/`。
- `kaikoushuo/`、`zhishiku/`、`sheying/` 是各自独立的 Taro 工程，可运行 H5 调试构建；其正式发布目标仍以各自微信小程序为准。
- `baibaoxiang/` 当前提供独立微信小程序构建，并在构建前同步项目配置。
- 每个小程序必须在微信开发者工具中核对项目名称与 AppID，上传后先进入开发版本；设为体验版是微信后台的后续操作。
- 微信 `AppSecret`、模型密钥等只放服务器 `.env`；不能写入小程序源码或构建包。微信请求域名在公众平台单独配置。

## 4. 管理后台功能与内容操作

管理后台是所有产品共用的一套 Vue 应用。当前侧栏入口由 `server/admin-web/src/config/nav.ts` 和 `featureVisibility.ts` 共同控制，并受登录账号权限控制。

| 后台菜单 | 常见操作 |
|---|---|
| 时政考点 | 维护文章、分类和今日学员端预览 |
| 公众号运营 | 配置公众号消息回复 |
| 人民日报 | 维护全量文章、采集批次、逐篇全文 AI 评估和评论文章物料；AI 评估结果须核对原文证据并人工确认，评论三刀草稿也须人工审核 |
| 时评精拆 | 维护时评文章、规范词、骨架模板、论证方法和句式类型 |
| 备考教学 | 编辑知识框架、发布知库文档；侧栏可见的其他入口以权限及功能开关为准 |
| 英语学习 | 查看学习概览、维护场景/课程单元、查看学习记录 |
| 摄影学习 | 维护技巧课程、知识地图和作品案例；发布案例需填写来源、作者、授权说明、观察证据、练习步骤与复盘标准 |
| 工具配置 | 维护文案、图片风格、模型配置和图片生成任务记录 |
| 系统 | 用户、反馈、行测管理、系统设置、角色权限，以及本手册入口「项目功能与操作」 |

### 常用内容发布流程

1. 打开 `/manage/` 并用有相应读写权限的管理员账号登录。
2. 进入对应产品菜单创建或编辑内容，补齐必填字段及素材。
3. 保存草稿后检查预览、排序和发布状态；确认后发布。
4. 在对应小程序/H5 刷新内容。若客户端有缓存，重新进入页面或执行下拉刷新。

### 人民日报评论文章物料流程

1. 全量人民日报采集批次完成后，系统从电子报评论版和命中的评论栏目识别文章，并尝试保存原文 Markdown/HTML；也可在「人民日报 → 评论文章」选择刊期手动扫描。
2. 若服务端已启用并配置 LLM，采集/扫描完成后会自动并发生成待审三刀解剖稿（最多 2 篇并发）；否则管理员可逐篇点击生成。原文失败的记录先检查来源链接/正文，不将目录标题当作完整文章。

### 人民日报全量文章 AI 评估

1. 每日全量采集完成后，所有有效文章进入全文评估队列；管理员也可在「人民日报 → 全量文章」选择日期范围或勾选当前页批量评估。无服务端 LLM 配置时任务保留待处理状态。
2. 评估输出体裁、申论关联、主题、适用场景、摘要、核心观点、文章结构、分项评分、原文证据和可用素材；关联等级高/中的正文进入文件版本归档，低关联正文不长期保存但保留正文哈希及评估证据。
3. AI 结果作为建议展示，不直接覆盖人工分类。审核人应核对原文证据、修正体裁和关联等级后确认；证据无法逐字定位时系统会阻止确认。高/中关联文章的正文在人工确认前已经按规则保存。
4. 全文识别为评论/社论且置信度足够的文章会同步进入评论文章物料流程，覆盖评论版以外的明确评论稿。无法抓取正文、输出异常或模型失败的记录可在列表按 AI 状态筛选并重试。
3. 编辑审核时核对引用是否完整且可在原文定位，检查事实、论证结构、申论适用主题/场景和仿写标注；审核通过后状态才变为可用。退回/不采用记录保留审核状态与意见。
4. 原文与解剖的 Markdown、HTML 文件保存在持久化 `server/data/rmrb/comments/刊期/文章ID/`。数据库保存文章关联、工作流状态和文件路径键；每日归档任务可重试，重复扫描会更新同一篇记录，不重复建档。

摄影课程、知识地图和作品案例由「摄影学习」维护。新增案例可上传 PNG/JPEG（单张不超过 5MB），也可录入 HTTPS 图片地址；同时填写来源地址、作者、授权类型与范围、可见画面观察、EXIF（没有则留空）、推断依据与置信度、单一练习目标和复盘标准。外部图片域名需加入微信后台 downloadFile 合法域名；后台上传图片通过知行服务域名提供。英语场景/单元由「英语学习」维护；知库目录由「知库文档」维护；AI 图片风格与模型由「工具配置」维护。

## 5. 本地开发与构建

### 知行主端

```bash
npm install
npm run dev:h5       # H5，默认 http://localhost:10087
npm run build:h5
npm run dev:weapp
npm run build:weapp  # 微信代码产物 dist/
npm run lint
```

### 独立小程序

```bash
cd baibaoxiang && npm install && npm run dev:weapp
cd zhishiku && npm install && npm run dev:weapp
cd kaikoushuo && npm install && npm run dev:weapp
cd sheying && npm install && npm run dev:weapp
```

正式上传前在对应目录执行 `npm run build:weapp`，然后用微信开发者工具打开该项目，核对名称、AppID、`dist/` 产物和服务器域名。各工程的详细环境变量以对应 README 和 `.env.example` 为准。

### 后端与管理端

```bash
cd server
source .venv/bin/activate
uvicorn app.main:app --reload --port 8001

cd server/admin-web
npm install
npm run dev          # http://localhost:5173/manage/
npm run build        # vue-tsc + Vite，产物 server/admin-dist
```

H5 本地访问 API 时，检查 `CORS_ORIGINS`；微信小程序请求不依赖浏览器 CORS，但需要在微信后台配置 HTTPS 合法域名。

## 6. 环境变量与凭据归属

| 产品/服务 | 服务端环境变量名 | 说明 |
|---|---|---|
| 知行主小程序 | `MINIPROGRAM_APP_ID`、`MINIPROGRAM_APP_SECRET` | 主产品微信登录 |
| 言遇英语 | `YANYU_ENGLISH_MINIPROGRAM_APP_ID`、`YANYU_ENGLISH_MINIPROGRAM_APP_SECRET` | 独立凭据；客户端登录键 `yanyu_english` |
| 知库 | `ZHIKU_MINIPROGRAM_APP_ID`、`ZHIKU_MINIPROGRAM_APP_SECRET` | 独立凭据及 `zhiku` 产品键 |
| AI 百宝箱 | `BAIBAOXIANG_MINIPROGRAM_APP_ID`、`BAIBAOXIANG_MINIPROGRAM_APP_SECRET` | 独立凭据；客户端登录键 `baibaoxiang` |
| 光线练习簿 | `SHEYING_MINIPROGRAM_APP_ID`、`SHEYING_MINIPROGRAM_APP_SECRET` | 独立凭据；客户端登录键 `sheying` |

本地服务使用 `server/.env`；生产环境使用 `/opt/zhixing-gongkao/.env`。只更新目标变量，不覆盖整份服务器 `.env`。服务器配置变更后需用 `docker compose up -d --no-build` 重新创建容器，单纯 `restart` 不会重新读取 `env_file`。

## 7. 部署、数据与常见操作

- 生产更新按 `docs/release/cloud-server-deploy-guide.md` 执行；当前生产服务器内存有限，优先使用本机 `bash scripts/deploy-from-local.sh` 构建镜像并传输。
- 不要在生产服务器执行 `docker compose --build`，不要运行 `docker compose down -v`，不要覆盖服务器 `.env`。
- 部署后核验 `/health`、主 H5 `/`、管理端 `/manage/` 及本次变更涉及的 API。
- 数据备份、恢复、域名与 Nginx 配置按 `DEPLOY.md` 和云服务器部署指南操作。
- 生产数据库与上传资源位于 Docker 数据卷；发布管理端菜单/功能需要重新构建并部署完整镜像。

## 8. 文档维护规则

每次新增、修改、下线功能时，都要同步检查并更新：

1. 本文：产品矩阵、功能状态、后台操作、发布/运维步骤有变化就更新。
2. 对应产品 README：开发、构建、配置和发布步骤变更时更新。
3. `FEATURES.md`：知行主端页面、路由、隐藏状态和模块行为变更时更新。
4. `ARCHITECTURE.md`：共享服务、数据模型、API、产品隔离或部署拓扑变更时更新。
5. 管理端操作指南：后台菜单、权限或内容流程变化时更新。

提交代码前按影响范围核对“客户端页面/API/管理后台/权限/环境变量/部署/隐私提示”，将已完成、隐藏、待配置和未实现状态区分清楚；不要把计划能力写成已上线能力，也不要把任何密钥或完整 AppID 写入文档。新增管理后台入口时，保持路由、导航、可见性和面包屑一致。
