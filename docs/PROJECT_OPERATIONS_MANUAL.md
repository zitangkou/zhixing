# 知行全项目功能与操作手册

> 文档范围：知行仓库内的学员端、各独立微信小程序、H5、共享后端与管理后台。本文不包含任何 AppID、AppSecret 或第三方 API 密钥。
> 功能以当前代码和对应产品说明为准；最后核对：2026-10-16。

## 1. 产品与系统关系

此仓库包含一个主学员端和四个独立小程序工程。学员端工程、微信 AppID、客户端存储和发布版本彼此分开；FastAPI 服务、数据库和 Vue 管理后台由仓库共用。不同产品通过 `X-Product-Key` 和微信登录时的 `X-Wechat-App-Key` 选择产品范围及对应凭据。

| 产品 | 工程目录 | 客户端形态 | 产品标识 | 管理后台入口 |
|---|---|---|---|---|
| 杜衡阁（知行公考） | 根目录 `src/` | 主 H5 + 微信小程序 | `general` | 侧栏：时政要点、人民日报（金句管理/词汇素材/申论素材）、知识框架、资料分析、用户、反馈、设置、消息回复、角色、项目说明 |
| AI 百宝箱 | `baibaoxiang/` | 独立微信小程序 | `general`；微信登录键 `baibaoxiang` | 侧栏“工具配置”显示图片配置、模型配置、图片生成记录和大模型用量；文案配置仍可直链 `/manage/tool-config/copy` |
| 知库 | `zhishiku/` | 独立微信小程序；提供 H5 调试构建 | `zhiku` | 知库文档。侧栏已收起，直链 `/manage/knowledge-library` |
| 言遇英语 | `kaikoushuo/` | 独立微信小程序；提供 H5 调试构建 | `general`；微信登录键 `yanyu_english` | 英语学习。侧栏已收起，直链 `/manage/english/overview` |
| 光线练习簿 | `sheying/` | 独立微信小程序；提供 H5 调试构建 | `general`；微信登录键 `sheying` | 摄影学习。侧栏已收起，直链 `/manage/photography/courses` |

### 共享服务

- FastAPI：学员接口 `/api/*`，管理接口 `/admin/*`，健康检查 `/health`。
- 管理前端：Vue 3 + Vite，开发地址通常为 `http://localhost:5173/manage/`，生产挂载在 `/manage/`。
- 数据：SQLAlchemy + SQLite；上传文件及生成结果放在服务器数据卷内。具体备份与恢复方式见 `docs/release/cloud-server-deploy-guide.md`。
- 生产入口：域名 HTTPS → Nginx → Docker 中的 FastAPI；主 H5、管理前端和 API 由同一部署镜像提供。

## 2. 客户端功能清单

### 2.1 知行公考：根目录 `src/`

主端提供 H5 和微信小程序。当前审核整改展示版将首页和练习入口定位为公考练习，入口名称使用“每日练习 / 专题练习 / 行测真题”；金句素材、知识框架、签到、错题和账号能力保留。**本轮仅调整客户端展示文案和层级；时政要点、文章、时评及金句数据/API、后台和深链均未下线。**微信小程序打开登录页会先走微信登录；昵称仍是默认且没有头像时，先完善资料。

首页、练习、个人中心的实际露出受 `src/constants/featureVisibility.ts` 控制。页面清单见 `FEATURES.md`。

### 2.2 AI 百宝箱：`baibaoxiang/`

- 工具首页、分类和搜索；个人中心提供本地收藏、最近浏览和偏好设置。
- 微信登录、个人资料及反馈使用共享后端。
- 照片换风格：选图、选择已发布风格、生成前确认；登录后上传处理、查看任务状态并保存结果。
- 可用模型、图片风格和实际生成能力由管理后台配置；服务商密钥只从服务端环境变量读取。未配置可用模型/密钥时，生成不能完成。
- 本机后台图片配置保留原有“旅行手账·清透淡彩”，另有四种已复核风格和草稿“钢笔淡彩·漫游手账”；草稿含用户提供的原图/生成图对照图，仅用于后台测试。其余探索风格已从本地配置清理；源文件和配置说明见 `docs/ai-image-styles/`。本地数据库状态不会自动同步到生产服务器。
- 其他尚未实现的工具会显示准备中，不代表已经可用。

### 2.3 知库：`zhishiku/`

- 浏览后台发布的资料目录，按关键词搜索和分类筛选。
- 微信登录后可上传、阅读和删除个人文档；支持 MD、TXT、PDF、DOCX。
- 阅读页展示提取文本、只读提示和身份水印；个人上传文档仅本人可见。
- 扫描版 PDF 目前标记为待 OCR；文档权限、付费和定向分享能力尚未接入。

### 2.4 言遇英语：`kaikoushuo/`

- 今日推荐、英语场景浏览和课程单元练习。
- 对话中英对照、核心句块、情境替换任务；支持视频/音频媒体、字幕显示控制、录音回放或删除本地录音。
- 学习完成记录、学习统计和次日复习提示；完成记录可绑定微信登录用户。
- 管理后台可维护媒体类型、URL、官方来源和授权状态；只有标记为已获托管许可的直播放地址会在小程序内播放，外链课程只显示来源复制入口。
- 当前已发布 3 个原创情景单元，尚无已配置示范音视频；美剧及第三方学习视频需完成授权核验后再入库。

### 2.5 光线练习簿：`sheying/`

- 首页、技巧课程、课程详情、摄影知识地图、拍摄练习记录和个人练习统计。
- 已发布作品案例提供画面观察、EXIF、标明依据的摄影推断和一项关联本地练习记录的拍摄任务；案例由后台人工录入与审核。课程和案例通过 API 加载，API 不可用时保留内置课程。
- 微信登录关联用户身份；练习记录当前保存在设备本地，尚未同步到云端。
- 自动 AI 拆解、用户图片上传分析、云端练习档案属于后续规划；详细设计见 `内容运营/摄影/04-优秀摄影作品解析与练习闭环优化方案.md`，发布状态以代码为准。

## 3. H5 与微信小程序

- 根目录 H5 是知行公考主 H5，生产构建由 Docker 镜像打包；本地端口默认 `10087`。
- 根目录微信包由 `npm run build:weapp` 构建，生成 `dist/`。
- 微信端学习/我的使用 `pages/index/index` 单页容器与自定义底栏切换，页面内保留两侧面板，避免主 Tab 路由切换造成空白帧；H5 仍用独立页面路由。旧的 `pages/user/index` 微信路径会转到单页容器的“我的”面板。
- `kaikoushuo/`、`zhishiku/`、`sheying/` 是各自独立的 Taro 工程，可运行 H5 调试构建；其正式发布目标仍以各自微信小程序为准。
- `baibaoxiang/` 当前提供独立微信小程序构建，并在构建前同步项目配置。
- 每个小程序必须在微信开发者工具中核对项目名称与 AppID，上传后先进入开发版本；设为体验版是微信后台的后续操作。
- 微信 `AppSecret`、模型密钥等只放服务器 `.env`；不能写入小程序源码或构建包。微信请求域名在公众平台单独配置。

| 金句管理 | 侧栏可见。先审核，通过后才能启用；列表同时显示来源文章日期与采集日期 |

### 常用内容发布流程

1. 打开 `/manage/` 并用有相应读写权限的管理员账号登录。
2. 进入对应产品菜单创建或编辑内容，补齐必填字段及素材。
3. 保存草稿后检查预览、排序和发布状态；确认后发布。
4. 在对应小程序/H5 刷新内容。若客户端有缓存，重新进入页面或执行下拉刷新。

### 学员端时政要点与金句素材

1. 在「时政要点」创建要点或小节，填写摘要并发布。套题用导入写入这一条，不选文章。学员端点这一条就刷这一套。
2. 登录后练习会保存进度。重复练习不重复计分，错题可订正并更新错题本。
3. 金句在「金句管理」审核通过并启用后，出现在学员端「金句素材」。未启用的不会展示。

### 人民日报每日金句流程（2026-10-13已部署）

1. 金句管理是历史运营库入口。2026-10-15本地新增「词汇素材」与「申论素材」页面；旧全量文章、评论工作流、客户端采集、运营包和批次入口继续重定向至金句管理，旧触发API不再注册。
2. 配置`LLM_ENABLED=true`与`LLM_API_KEY`后，词汇任务默认06:40先对当天全版文章按批次联合筛选金句、词汇和申论素材；金句任务默认07:10等待联合分析结束后复用结果，仅处理缺失项，最迟等待至10:00。申论素材候选须通过原文证据、类型闭集和8/10质量门，随后在“申论素材”独立页面人工审核。正文及完整分析在共享缓存中最长保留48小时；部署时若服务端显式设置过调度变量，须同步改成先联合采集后金句。
3. 原句须逐字出现在原文中；AI无法替代人工事实核对，库中只保存每句必要证据摘录、来源和位置，不保存全文、完整提示词或AI原始响应。结果先入“待核对”，不自动确认、精选或发布。
4. 在页面中按日期、关键词、主题、构件、核对/精选状态检索；列表显示来源文章日期和采集日期，详情查看证据、句式、落笔提醒和多个主题仿写。编辑高亮词会校验是否出现在正文中；确认须有原文证据及标题。
5. 可在页面“立即整理/重试失败项”，已成功文章跳过。词汇任务和金句任务分别按配置时间启动，失败可重试；关闭定时开关不影响手动录入或导入。
6. JSON导入支持每日汇编、精选合集及本库导出：先预览再提交，重复“来源URL＋原句指纹”跳过；缺证据可导入待核对，不能直接确认。精选仅允许已确认的金句，按日期保存。
7. 生产已上线金句管理；旧档案已备份后清理，10月13日36句/72例已导入并保持待核对。10月13日部署时生产环境尚未配置LLM凭据；10月15日已确认启用，配置服务端`LLM_ENABLED=true`及`LLM_API_KEY`后生效。生产快照目录为`data/backups/rmrb-retirement-20261013-214526/`。

### 人民日报申论素材管理（本地实现）

1. 在“人民日报 → 申论素材”维护当日筛选后的素材；来源必须是人民日报当天已刊发稿件，不外部补料，排除人事任免、公告、广告、天气预报和纯转载通稿。
2. 使用固定主题、主题要素、使用场景和物料类型编码。质量分低于8/10或命中一票否决时，系统将记录标为退回；确认前需填写完整七维评分。事实案例正文压缩至60–90字，并提供事实、结果、证明点和使用边界；语录须提供原文核对信息。
3. 每条必须保留来源日期、篇名、版面和素材用途。`example_body` 控制在80–120字，是原创写作用法示例，不是人民日报原文；涉及数据时保留报道中的时间、地域与统计对象。
4. 首批 2026-10-15 的10条筛选结果由启动初始化按指纹幂等导入，默认待审核、未评分。导入其他日期时使用 JSON，先看预览中的无效/重复状态，再执行导入；导出 JSON 可作为备份和跨环境迁移文件。确认前需完成七维评分并达到8分。
5. 页面和接口共用 `rmrb:read` / `rmrb:write` 权限。此素材库仅为后台教研管理，不会自动在学员端公开。

### 人民日报素材共用采集与大模型用量（本地实现）

1. 金句与词汇共用版面目录、文章元数据和临时正文缓存，跨版重复文章会归并。正文及联合分析最多保留48小时；目录元数据保留7天，后台每小时清理过期缓存。
2. 联合分析结果按刊期、来源URL和正文指纹缓存。词汇任务一次读入文章后，同时返回评论类别、金句、词汇和申论素材候选；三类素材分别执行来源校验、去重和人工审核。申论候选仅保存评分达标且无否决项的待审核记录；人工确认前不可用或发布。金句仿写仅在人工确认后选入当天运营内容时生成。
3. 申论素材与词汇、金句共享同一批文章正文和模型分析，不增加一次单独的全文调用；联合分析缓存缺失、过期或规则版本不匹配时才重新分析。案例事实和语录归属仍需人工复核，AI质量分不能替代人工审核。
4. “大模型用量”页面按北京时间日期、用途和模型汇总调用次数、Token、耗时与失败；配置`LLM_INPUT_PRICE_PER_MILLION`和`LLM_OUTPUT_PRICE_PER_MILLION`后可显示单价估算。日志只保存调用元数据，不含提示词、文章正文或模型输出。

迁移命令、回退和配置详见`server/README.md`的“每日金句库”。学员端时评精拆数据不在旧档案清理范围。

## 7. 部署、数据与常见操作

- 生产更新按 `docs/release/cloud-server-deploy-guide.md` 执行；当前生产服务器内存有限，优先使用本机 `bash scripts/deploy-from-local.sh` 构建镜像并传输。
- 不要在生产服务器执行 `docker compose --build`，不要运行 `docker compose down -v`，不要覆盖服务器 `.env`。
- 部署后核验 `/health`、主 H5 `/`、管理端 `/manage/` 及本次变更涉及的 API。
- 数据备份、恢复、域名与 Nginx 配置按 `DEPLOY.md` 和云服务器部署指南操作。

### 每日金句规则与流程优化（2026-10-15，本地实现，未部署）

- 先比较候选再精选最多3句，12—55字优先，70字硬上限；连续节选不改原文。模型自评记忆成本、逻辑、迁移、亮点四项至少各3/5且总分至少16/20。自评分只作筛选提示，不代表质量认证，仍须人工审核。

- 原句连续性、长度、低分及领导人引语拒绝仍严格执行；引语校验定位到引述范围，不再因证据邻文出现领导人姓名直接拒绝。自动检测不是引语归属的完整证明，审核时仍需核对。
- 高亮不在对应正文中时移除并记录警告，保持正文原样；不对错字原句作模糊匹配。单条写入用savepoint隔离，一句失败不再丢掉整篇。两种构件改为质量提醒，不通过改标签凑构件。

### 2026-10-16 · 速算训练后台与练习闭环（本地实现，未部署）

管理端「备考教学 → 资料分析 → 速算训练」分为训练方法和训练效果。首次初始化的七类方法均为草稿。方法配置包括名称、类别、适用场景、知识框架路径、基础数值范围、难度和启停；使用「预览校验」查看样题、KaTeX 公式、答案、适用场景和解析，并验证算法适用条件、唯一答案及知识节点是否存在于已发布的资料分析框架。全部通过后才可发布，学员端只获取已发布方法。后台保留不可变的已发布版本，可查看版本记录并把旧规则内容作为新版本重新发布。发布操作复用 `ziliao:write` 权限，数据查看使用 `ziliao:read`。七类现有生成器均作为受控规则，不支持任意上传代码或 JSON 生成逻辑。

小程序通过 `/api/ziliao/quick-calc/*` 获取已发布规则并创建服务端练习，需要登录账号；未登录会提示前往登录。每题答案提交后由服务端判分，完成会话后同步个人历史；错题可以创建新的练习会话重做。会话保存出题快照、方法版本、答题文本和耗时。后台效果页支持 7/30/90 天筛选，显示完成组数、答题数、各方法正确率、平均用时及错选文本。离线时不能判分或进入后台统计，恢复连接后需重新提交当前选择。

学员端依据最近 10 组内各方法至少 5 道答题的正确率生成专项建议，正确率低于 75% 的方法优先展示；历史不足时提示继续训练，不制造薄弱结论。
