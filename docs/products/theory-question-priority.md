## 强制优先级（新出题）

纲要/建议类：6–10 题深度练，或 20 题且 **前 8 题覆盖骨架**。

1. 定位 / 方位  
2. 指导思想五件套（中心 / 主题 / 动力 / 目的 / 保障）  
3. 原则完整句  
4. 目标层定性（不先抠 GDP）  
5. 篇章列举「不包括」  
6. 数字：仅易混时点或单位；每套 ≤2 题，**不得放第 1–2 题**

题型跟真题：direct 15–17 / combo 2 / count 1–2。不要为文章练强上多选+判断。

## 十五五骨架（出题必须先覆盖）

- 中心=经济建设；主题=高质量发展；动力=改革创新；目的=美好生活需要；保障=全面从严治党  
- 六项原则（党领 / 人民 / 高质量 / 改革 / 有效市场有为政府 / 发展和安全）  
- 方位：承前启后；夯实基础、全面发力  

数字题仅当有「十四五成就 vs 十五五目标」或单位偷换时才出。
