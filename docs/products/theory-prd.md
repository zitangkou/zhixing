# 政治理论垂直小程序 PRD

> 版本：1.0 · 2026-08-23
> MVP目标：把权威时政和理论文章转化为15分钟内可完成、有原文依据、能进入复习的每日训练。

## 1. 用户与价值

核心用户是接触时政但知识碎片化、记不住规范表述、容易被相近选项干扰的国考考生。产品不是新闻聚合器，核心能力是理解、辨析和长期记忆。

北极星指标：每周完成4个以上政治理论学习包且按时完成到期复习的用户数。

## 2. 核心流程

```text
2–3题读前测
→ 3–5张知识卡
→ 重点原文分节精读
→ 5题真题化测验
→ 原文依据与干扰项辨析
→ 错题/SRS
→ 周测和掌握度更新
```

首页显示今日主题、考点数、预计时间和唯一主操作“开始今日学习”。

## 3. 信息架构

- 今日：今日学习包、继续学习、到期复习。
- 专题：理论体系、重要会议、法律政策、经济社会、科技和年度时政。
- 刷题：每日题、专题题、真题、错题和易混辨析。
- 我的：掌握度、易混表述、收藏、学习记录和周报。

## 4. MVP功能

### 4.1 来源与知识单元

- 保存权威来源、发布日期、访问日期、版权状态和原文证据。
- 结构化主体、时间、行动、关键数字、规范表述、专题、重要性和有效期。
- 内容支持修订/失效；来源变化时关联题目自动进入待复核。

### 4.2 读前测与精读

- 读前测激活已有认知，答后提示阅读重点，不提前给完整解析。
- 知识卡每张只表达一个考点，包含核心表述、关键词、易错表述和相关真题。
- 分节精读提供主旨、规范表述、可能考法、知识树位置和原文定位。

### 4.3 真题化出题

- 复用“两阶段：提取要点→生成题目”，新增规则校验、真题风格评测和教研审核。
- 每题必须有关联证据、知识点、正确答案、干扰项类型、生成版本和审核记录。
- 干扰项类型包括主体偷换、时间错位、范围扩大/缩小、程度变化、因果倒置和概念混淆。
- AI题默认`pending`，无人工审核不得发布。

### 4.4 作答与反馈

- 支持单选、多选、判断和材料型题目。
- 提交后保留用户原选择，逐项解释正确/错误原因。
- 一键定位原文，突出主体、动作、目标、程度词和限定条件。
- 错题保存错误知识点、干扰项类型、依据和理解/记忆错误分类。

### 4.5 复习与专题

- SRS形式包括原题、判断、限定词补全、表述对比、变式题和主动回忆。
- 每条内容进入专题，专题展示知识结构、时间线、政策、真题、掌握度和易混点。
- 周测组合本周新知、错题、到期旧知和少量已掌握保持题。

### 4.6 2025真题基准集

- 使用结构化真题库中的20道唯一政治理论题。
- 先补充合法答案来源并双人核验，再补解析、知识点、命题方式和干扰项。
- 作为Prompt/模型变更的固定评测集；答案就绪前只做题面研究，不进入评分池。

## 5. 数据对象

- 复用：`Article`、`Question`、`Category`、`StudyRecord`、`SectionRead`、`WrongAnswer`、知识树和SRS。
- 新增：`ContentSource`、`KnowledgeFact`、`ArticleEvidence`、`QuestionEvidence`、`QuestionDistractor`、`QuestionReview`、`DailyTheoryPack`。
- 通用字段：`product_key=theory`、来源、有效期、版本和审核状态。

## 6. 管理后台

- 来源白名单、候选内容池、去重/相关性、文章分节和事实卡编辑。
- AI出题预览、规则错误、真题风格评分、逐题审核和每日包编排。
- 内容修订影响检查、发布/撤回、题目错误率和干扰项选择率。
- 从审核资产派生公众号、小红书、抖音和B站内容包。

## 7. 体验要求

- 不用新闻瀑布流；今日页只展示一个编排后的学习包。
- 知识卡短而聚焦，重要原文可展开；依据与解析原位显示。
- 正误反馈中性、清晰，错误后两步内看到答案、依据和辨析。
- 中断恢复、弱网保留、深浅模式和双端体验满足共享规范。

## 8. 验收

- 每道发布题证据覆盖率100%，未经审核AI题发布数为0。
- 2025基准集答案双人核验完成。
- 15分钟内完成每日包；错题自动进入正确复习计划。
- 上线前至少14天内容，稳定后保持7天滚动库存。
- 事实/答案事故为0；来源修订可以定位并下线全部关联内容。

## 9. 后续版本

- P1：更多年份真题、专题测评、个性化薄弱包。
- P2：省考/公基范围扩展、能力画像和更丰富的主动回忆。
- 不进入MVP：泛新闻聚合、自动发布题目、押题承诺和无来源知识卡。
