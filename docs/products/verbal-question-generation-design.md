## 1. 设计目标与边界

### 1.1 目标

言语理解引擎的核心挑战不是"生成看起来像真题的文字"，而是**保证答案唯一、干扰项可溯源、文段无歧义**。本方案先建立语义唯一性审核机制，再实现最小引擎（单空选词填空 + 主旨/意图判断），用现有真题验证校验逻辑。

### 1.2 与资料分析引擎的本质差异

| 维度 | 资料分析（Q2/Q3） | 言语理解（Q5） |
|---|---|---|
| 正确性来源 | 给定数据 + 统计公式 | 文本语义 + 语境约束 |
| 校验方式 | 双求解器精确复算 | 程序层 + LLM 盲审 + 人工抽审 |
| 干扰项生成 | 错误公式计算确定值 | 真实错误路径（近义混淆/语境不符/范围偏差等） |
| 答案唯一性 | 数值唯一，程序可判定 | 语义唯一，需多层审核 |
| 数据源 | 合成数据集（自洽可验算） | 人工编写文段（避免版权，可控约束） |

**核心结论**：言语题不能像资料分析那样纯程序校验。语义歧义、语境依赖、近义词语用差异使得"正确答案"本质上是一个**约定意义下的最优解**，必须通过多层审核机制保证唯一性。

## 2. 语义唯一性审核机制

### 2.1 为什么言语题不能纯程序校验

1. **语义歧义**：同一词语在不同语境下可能有不同含义，程序难以判定"哪个解读更合理"。
2. **语境依赖**：正确答案往往由空格前后的逻辑信号词（转折/递进/因果）决定，需要理解整段文字的语义走向。
3. **近义词语用差异**：近义词之间的区别可能在程度、范围、感情色彩、搭配对象上，这些差异需要语义理解而非字符串匹配。
4. **主旨概括的层级性**：文段可能有多个"正确概括"，只是概括层级不同，需要判定哪个是"核心"而非"局部"。

因此，言语题的审核必须是**程序可判定部分 + 模型语义判断 + 人工最终确认**的三层结构。

### 2.2 三层审核设计

```
生成题（draft）
  │
  ▼
① 程序层校验（machine_check）
  │  ├─ 选项互异检查
  │  ├─ 答案唯一性检查（正确项与干扰项不重复）
  │  ├─ 语境约束检查（题干包含足够逻辑信号词）
  │  ├─ 词性一致性检查（选词填空：四个选项词性相同）
  │  ├─ 选项长度合理性检查（主旨题：选项长度差异不过大）
  │  └─ 干扰项类型标注完整性检查（每个干扰项有 type + violated_constraint）
  │
  ▼ 通过
② 模型层盲审（llm_blind_review）
  │  ├─ 不看答案，独立作答 3 次
  │  ├─ 每次作答基于：语境约束匹配度 / 核心句语义重叠度
  │  ├─ 3 次答案一致率 ≥ 2/3 才通过
  │  └─ 不一致则标记 ambiguity，需重写
  │
  ▼ 通过
③ 人工层抽审（academic_review）
     ├─ 教研人员独立作答，验证答案唯一性
     ├─ 检查文段自然度（不能为了答案而写得过于刻意）
     ├─ 确认干扰项"只违反一项约束"，不是生僻词凑数
     └─ 审核通过 → approved
```

### 2.3 盲审流程细节

**LLM 盲审（规则模拟版）**：

由于当前环境无法调用外部 LLM API，采用**规则模拟盲审**：基于语境约束关键词与选项的语义匹配度，模拟 3 次独立作答（每次使用略有不同的权重组合），验证答案一致性。

- **选词填空盲审**：提取题干中的逻辑信号词和约束描述词，对每个选项计算"约束匹配分"（语义类别匹配度 × 权重），3 次使用不同权重组合，取最高分选项为作答结果。
- **主旨意图盲审**：提取文段核心句的关键词集合，对每个选项计算与核心句的语义重叠度（Jaccard 相似度 + 关键词命中数），3 次使用不同阈值，取最高重叠度选项为作答结果。

**答案唯一性判定标准**：

> 正确项在语境约束下唯一成立，其他选项在同一语境下不成立或明显劣于正确项。

具体判定：
- 选词填空：正确项的约束匹配分显著高于所有干扰项（差距 ≥ 阈值），且不存在第二个选项也满足全部语境约束。
- 主旨意图：正确项与核心句的语义重叠度显著高于所有干扰项，且不存在第二个选项也能概括文段核心（而非局部）。

## 3. 干扰项来自真实错误路径

### 3.1 选词填空干扰项类型

| 干扰项类型 | 说明 | 典型错误路径 | violated_constraint 示例 |
|---|---|---|---|
| 近义混淆_程度 | 近义词但程度轻重不同 | 把"遏制"（重）选成"抑制"（轻） | 语境要求"严重趋势"需重程度词 |
| 近义混淆_范围 | 近义词但适用范围不同 | 把"因地制宜"（差异化）选成"一视同仁"（同等化） | 语境强调"各地差异显著" |
| 近义混淆_感情色彩 | 近义词但褒贬不同 | 把"独树一帜"（褒）选成"标新立异"（中偏贬） | 语境为正面评价 |
| 近义混淆_搭配对象 | 近义词但搭配对象不同 | 把"遏制趋势"选成"制止趋势"（制止搭配行为） | 空格后为"趋势"，需搭配趋势的动词 |
| 语境不符_逻辑关系反了 | 选项含义与语境逻辑方向相反 | 转折语境中选了同向词 | 空格前有"然而""但"等转折词 |
| 搭配不当 | 选项与前后文无法构成合法搭配 | "文化记忆的途径"（应为载体） | "记忆"需搭配承载类名词 |
| 生僻词干扰 | 用不常见词增加迷惑性 | 用"踵事增华"干扰"锦上添花" | 生僻词本身可能也成立，但非最优 |

**硬约束**：干扰项不能只因生僻或词性不同被排除，必须违反明确的语境约束。每个干扰项标注 `distractor_type` 和 `violated_constraint`。

### 3.2 主旨意图干扰项类型

| 干扰项类型 | 说明 | 典型错误路径 | violated_constraint 示例 |
|---|---|---|---|
| 局部信息 | 表述正确但只概括了文段某一部分 | 把论据当结论 | 文段核心在末句对策，选项只提到了问题 |
| 范围扩大 | 概括范围超出文段讨论对象 | 文段谈"老旧小区改造"，选项说"城市建设" | 文段主题词为"老旧小区改造" |
| 范围缩小 | 概括范围小于文段核心 | 文段提"三方面同时发力"，选项只说"提高薪酬" | 核心对策包含三个方面 |
| 偷换主题 | 选项主体与文段主体不一致 | 文段谈"AI与教师关系"，选项说"AI改变教育" | 文段核心主体是"AI与教师的关系" |
| 原因结果混淆 | 把原因说成结果或反之 | 把背景分析当结论 | 文段结构为"背景→分析→对策"，选项选了分析层 |
| 无中生有 | 选项内容文段未提及 | 文段未提"资金总量"，选项说"需要大量资金" | 选项关键词在文段中无对应 |
| 过度引申 | 基于文段信息做了超出合理范围的推断 | 文段说"有望推动"，选项说"将全面实现" | 选项含"全面""必然"等绝对化表述 |
| 表述正确但非重点 | 选项本身正确但不是文段核心意图 | 文段背景句正确但非重点 | 文段有明确的核心观点句，选项选了背景 |

### 3.3 干扰项标注规范

每个干扰项保存为：

```json
{
  "option_key": "A",
  "option_text": "循序渐进",
  "distractor_type": "近义混淆_范围",
  "violated_constraint": "语境强调'各地资源禀赋差异显著'，需差异化策略；'循序渐进'强调步骤先后，未体现因地制宜",
  "error_path": "考生只注意到'发展策略'而忽略了'各地差异'的约束，选择了通用但不精准的词"
}
```

## 4. 避免歧义句设计原则

### 4.1 题干语境约束充分性

- **选词填空**：空格前后必须有明确的逻辑信号词（转折/递进/并列/因果/解释），且信号词与正确答案的语义方向直接相关。
- **主旨意图**：文段必须有明确的核心句或论证结构（背景→分析→核心观点→对策），不能是"都有道理"的模糊文段。

### 4.2 禁止的歧义结构

| 歧义类型 | 错误示例 | 修正方式 |
|---|---|---|
| 指代不明 | "他对他说..." | 明确指代对象，使用具体名词 |
| 修饰语范围不清 | "几个学校的领导" | 改为"几所学校的领导"或"学校的几位领导" |
| 多义词未消歧 | "他走了一个小时" | 补充语境明确是"行走"还是"离开" |
| 逻辑关系模糊 | 缺少信号词的并列句 | 添加"因此""然而""不仅...而且"等信号词 |
| 核心句不明确 | 文段各句权重相当 | 用"因此""可见""总之"等标记核心句 |

### 4.3 选项区分度要求

- 选项之间必须有明确的语义区分度，不能有两个"都算对"的选项。
- 选词填空：四个选项必须语义相近但在**至少一个维度**（程度/范围/感情色彩/搭配对象）上有明确差异。
- 主旨意图：四个选项必须对应不同的偏差类型（局部/范围/无中生有/主题偷换），不能有两个选项都是"局部信息"。

## 5. 最小引擎技术方案

### 5.1 单空选词填空引擎

**生成流程**：

```
人工编写短文（100~200字，语境约束明确）
  → 选定目标词（动词/成语/实词）
  → 标注语境约束（逻辑信号词 + 约束描述）
  → 隐去目标词形成空格
  → 从近义词干扰词库选 3 个"只违反一项约束"的干扰词
  → 程序校验（选项互异/词性一致/语境约束存在/答案唯一）
  → 规则模拟盲审 3 次（约束匹配度评分）
  → 盲审一致率 ≥ 2/3 → 保存
```

**题目规格定义**：

```python
{
    "question_id": "Q5-VB-FILL-001",
    "passage": "乡村振兴不能照搬城市发展模式。由于各地资源禀赋...因此在制定发展策略时必须______，根据本地实际情况选择...",
    "target_word": "因地制宜",
    "blank_position": "句中",
    "logic_signal": "由于...因此...",
    "context_constraints": [
        "各地资源禀赋、产业基础和文化传统差异显著",
        "根据本地实际情况选择适合的产业路径"
    ],
    "options": {"A": "循序渐进", "B": "因地制宜", "C": "一视同仁", "D": "精益求精"},
    "answer": "B",
    "distractors": {
        "A": {"distractor_type": "近义混淆_程度", "violated_constraint": "..."},
        "C": {"distractor_type": "近义混淆_范围", "violated_constraint": "..."},
        "D": {"distractor_type": "近义混淆_程度", "violated_constraint": "..."}
    }
}
```

### 5.2 主旨/意图判断引擎

**生成流程**：

```
人工编写文段（150~300字，论证结构明确）
  → 标注论证结构（背景句/分析句/核心观点句/对策句）
  → 写出核心命题（不超过 20 字）
  → 正确项 = 核心观点的等义压缩
  → 干扰项 4 类各 1 个（局部信息/范围偏差/无依据引申/主题偷换）
  → 程序校验（选项互异/答案唯一/核心句关键词存在/干扰项类型标注完整）
  → 规则模拟盲审 3 次（核心句语义重叠度评分）
  → 盲审一致率 ≥ 2/3 → 保存
```

**题目规格定义**：

```python
{
    "question_id": "Q5-VB-MAIN-001",
    "passage": "当前，我国城市老旧小区改造工作正在全面推进。然而...因此，老旧小区改造应建立以居民需求为导向的项目遴选机制...",
    "argument_structure": {
        "background": "当前，我国城市老旧小区改造工作正在全面推进。",
        "analysis": "然而，部分小区在改造过程中存在'重面子轻里子'的倾向...根本原因在于...",
        "core_viewpoint": "老旧小区改造应建立以居民需求为导向的项目遴选机制",
        "countermeasure": "将资金优先用于解决居民反映最强烈的民生问题"
    },
    "core_proposition": "老旧小区改造应以居民需求为导向",
    "question_type": "意图判断",
    "stem": "这段文字意在说明：",
    "options": {
        "A": "部分老旧小区改造存在'重面子轻里子'倾向",
        "B": "城市建设应建立透明的资金分配机制",
        "C": "老旧小区改造应以居民需求为导向分配资源",
        "D": "老旧小区改造需要大量资金投入"
    },
    "answer": "C",
    "distractors": {
        "A": {"distractor_type": "局部信息", "violated_constraint": "..."},
        "B": {"distractor_type": "范围扩大", "violated_constraint": "..."},
        "D": {"distractor_type": "无中生有", "violated_constraint": "..."}
    }
}
```

### 5.3 数据源

- **选词填空**：人工编写短文（避免版权问题），每段 100~200 字，语境约束明确。
- **主旨意图**：人工编写文段（避免版权问题），每段 150~300 字，论证结构清晰。
- **近义词干扰词库**：`xingce-structured-data/_schema/verbal_distractor_vocabulary.json`，按干扰项类型分类存储近义词组。

## 6. 质量门槛

### 6.1 选词填空质量门槛

1. 正确词必须在语义、搭配和文体上同时最优。
2. 干扰词不能只因生僻或词性不同被排除，必须违反明确的语境约束。
3. 四个选项词性一致（同为动词/名词/成语）。
4. 空格前后有明确的逻辑信号词。
5. 规则模拟盲审 3 次一致率 ≥ 2/3。
6. 多空题（本版本不涉及）组合答案唯一。

### 6.2 主旨意图质量门槛

1. 正确项是核心观点的等义压缩（不超过 20 字核心命题）。
2. 不存在两个选项都能概括文段核心（而非局部）。
3. 文段有明确的论证结构标注（背景/分析/核心观点/对策）。
4. 四个干扰项分别对应不同的偏差类型。
5. 规则模拟盲审 3 次一致率 ≥ 2/3。
6. 至少 2 名审核者独立作答一致（程序 + 规则模拟盲审）。

### 6.3 通用红线

- 禁止编造答案：每题必须通过程序校验 + 盲审才保存。
- 禁止使用新闻原文（版权问题），所有文段人工编写。
- 干扰项必须来自真实错误路径，标注 violated_constraint。
- 盲审不通过的题不保存，记录到报告中。
- JSON ensure_ascii=False, indent=2。

## 7. 真题验证方案

### 7.1 验证目标

用引擎的程序校验层对 2025 真题言语理解模块跑一遍，验证：
1. 校验逻辑能识别正确项（正确项通过所有程序检查）。
2. 干扰项能被正确分类（真题干扰项属于哪种偏差类型）。

### 7.2 验证样本

从 2025 三卷真题中选取：
- 选词填空 5 道（有答案解析的）
- 主旨/意图判断 5 道（有答案解析的）

### 7.3 验证指标

| 指标 | 说明 |
|---|---|
| 正确项通过率 | 真题正确项通过程序校验的比例 |

**引擎架构**（`scripts/xingce/gen_verbal_questions.py`）：

- **选词填空引擎**：5 道人工编写短文，每段 100~200 字，目标词覆盖成语/动词/实词，干扰词从近义词库选取，每个只违反一项约束（程度/范围/搭配/感情色彩）。
- **主旨意图引擎**：5 道人工编写文段，每段 150~300 字，论证结构标注（背景/分析/核心观点/对策），正确项为核心观点等义压缩，干扰项 4 类各 1 个（局部信息/范围偏差/无依据引申/主题偷换）。
- **程序校验层**：选项互异、答案唯一、词性一致、语境约束存在、干扰项类型标注完整。
- **规则模拟盲审**：选词填空用约束匹配度评分（3 次不同权重），主旨意图用核心句语义重叠度评分（3 次不同阈值），一致率 ≥ 2/3 才通过。
- **真题验证**：从 2025 三卷真题选 5 道选词填空 + 5 道主旨意图，跑程序校验层，记录正确项通过率和干扰项分类结果。

**近义词干扰词库**（`xingce-structured-data/_schema/verbal_distractor_vocabulary.json`）：
