# 「知行日知」×「知行策论」小程序 Logo 设计方案

> 版本：v1 · 2026-08-29 · 状态：待确认
> 确认方向：印章/书卷风 · 统一品牌红 · 文字为主与图形+文字两版并行出效果

---

## 1. 设计定位

两个小程序是「知行」产品矩阵的垂直应用，Logo 需要：

1. **成系列**：两枚 Logo 并排出现（如公众号矩阵、小程序主页互推）时是一家人；
2. **各自有身份**：一眼能区分「日知」（政治理论学习）与「策论」（申论写作）；
3. **小尺寸友好**：微信小程序头像最小 120×120px，聊天列表仅约 40px，构图必须极简、留白充足、主元素占比大。

文化母题（来自产品名本身）：

| 产品 | 名称出处 / 意象 | 视觉母题 |
|---|---|---|
| 知行日知 | 《论语》「日知其所亡，月无忘其所能」——每日求知 | 日（旭日）、书卷 |
| 知行策论 | 科举「策论」——策士之论、经世文章 | 毛笔、简策/卷轴、砚 |

## 2. 统一规范（两款共用）

| 项 | 规范 |
|---|---|
| 主色 | 品牌中国红 `#D0021B`（与品牌真值源 `src/constants/theme.ts` 一致） |
| 辅色 | 纯白 `#FFFFFF`（反白文字/图形） |
| 风格 | 印章/书卷风：中式篆刻 + 白描线条，扁平无渐变 |
| 画布 | 1:1 正方形，主元素安全区 ≥ 画布 72%，四周留白 ≥ 14% |
| 字体 | 篆书（印章版）/ 楷体或宋体（图形版），正式制作统一选用可商用开源字体（如「思源宋体」「仓耳今楷」；篆书可用「志莽朱雀」「方正篆刻」需确认授权，或以字形绘制转矢量） |
| 圆角 | 小程序头像由微信自动裁圆角，Logo 本体按方形设计、内容不顶边 |

## 3. 方向 A：文字为主 · 方章篆书（推荐）

一枚方正朱文印章，印面内竖排两个字（取产品名核心字「日知」「策论」），外围细白边框。**两个产品仅换字，其余完全同构**，天然成对。

- **知行日知**：竖排「日知」，篆书白文；
- **知行策论**：竖排「策论」，篆书白文；
- 优点：缩到 40px 仍可读（两个大字占满印面），文化感最强，两枚并排极具「系列感」；
- 风险：篆书字形需人工校对（AI 生成字形不可直接使用，正式版须以真字体/手工矢量绘制）。

> 预览图：`logo-rizhi-seal` / `logo-celun-seal`

## 4. 方向 B：图形+文字 · 白描意象

上方白描红线的核心意象图形，下方楷体红字产品名。

- **知行日知**：旭日东升于展开书卷之上，云纹点缀 —— 「日日知新」的意象；
- **知行策论**：毛笔立于砚台、旁倚展开的竹简策 —— 「下笔成策」的意象；
- 优点：叙事性强、意境好，适合作品牌展示图/启动图延展；
- 风险：40px 小尺寸下细节（云纹、竹简线条）会糊掉，需另做「小尺寸简化版」（去细节线条，只留大形）。

> 预览图：`logo-rizhi-graphic` / `logo-celun-graphic`

## 5. 推荐

**头像用方向 A（方章篆书），方向 B 作为品牌延展**（启动页、公众号头图、分享卡片）。理由：

1. 小程序头像的核心诉求是「小而清晰」，A 的两字大印完胜；
2. 两枚方章并排是 strongest 的系列识别；
3. 篆刻 + 朱红与「公考、科举策论」的文化语境高度契合。
