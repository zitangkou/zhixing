# 「知行」系列命名候选 · 低撞车版

> 背景：微信小程序名称全局唯一，「知行 + 高频双字」基本已被占（博观、格物、致知、有恒、拾贝均属热词）。
> 本文按**撞车概率**排序，并给一套可覆盖未来六科的命名体系，避免每上一个新产品都重新起名。
> 说明：以下「撞车概率」是按词语常用度的预判，**不代表实际注册状态**，需用第 5 节方法逐个核验。

---

## 1. 首推：低撞车 + 典雅（第二字生僻但不难念）

| 候选 | 出处 | 意象 / 适配 | 撞车 |
|---|---|---|---|
| **知行韦编** | 《史记》孔子读《易》韦编三绝 | 反复研读、下苦功；适合汇总或理论 | 很低 |
| **知行藏修** | 《礼记·学记》「藏焉修焉，息焉游焉」 | 学习涵养，古雅克制 | 很低 |
| **知行汲古** | 韩愈「汲古得修绠」；毛晋汲古阁 | 深挖经典原典 | 很低 |
| **知行敏求** | 《论语·述而》「我敏求之」 | 主动求解，与「日知」同出《论语》 | 很低 |
| **知行约礼** | 《论语·雍也》「博学于文，约之以礼」 | 收束归纳，适合申论 | 低 |
| **知行致广** | 《中庸》「致广大而尽精微」 | **汇总定位最准**：广大 = 多科聚合 | 低 |
| **知行一贯** | 《论语》「吾道一以贯之」 | 贯穿多科，汇总感强，字面干净 | 低 |
| **知行不辍** | 孜孜不辍 | 每日练习主线 | 低 |
| **知行寸功** | 不废寸功 / 寸进之功 | 积累，轻量亲切 | 低 |
| **知行程功** | 《礼记·缁衣》「程功积事，惟贤以终之」 | 功业积累，极冷门 | 极低（但字面偏晦） |

> 生僻度提醒：**知行矻矻**（矻穷年）、**知行程功** 撞车最低，但用户念不出、记不住，搜也搜不到。建议只用「不难读但少人用」的字，韦编、藏修、汲古、敏求、致广是这一档。

## 2. 备选：中撞车（词好，但可能被占）

知行笃志（《论语》「博学而笃志」）· 知行明辨（《中庸》明辨之）· 知行时习（「学而时习之」，与日知同源，最协调）· 知行日新（《大学》苟日新）· 知行多识（「多识于鸟兽草木之名」）· 知行有恒 · 知行格物

## 3. 换结构：当「知行 XX」四字全被占时

| 变体 | 例子 | 说明 |
|---|---|---|
| 倒序 | 韦编知行 · 汲古知行 | 保留系列词根，唯一性大幅提升 |
| 三字容器 | 知行帖 · 知行钥 · 知行梯 | 「帖」双关碑帖与策论，最雅；单字组合撞车低 |
| 加虚词 | 知行以恒 · 知行而作 | 破四字成语撞车热区，但读感略软 |
| 书斋系 | 知行斋 · 知行阁 · 知行居 | 传统但「知行阁」类多半已有 |

⚠️ **不建议**：知行公考、知行备考、知行学堂、知行书院——「公考/备考」直接触发考试培训资质对照，「学堂/书院」同样把审核引向教育培训，个人主体都吃亏。

## 4. 命名体系提案（一次定完，六科不再纠结）

现有两名其实分属两个语源：「日知」出自《论语·子张》「日知其所亡」，「策论」是科举文体。若继续沿用典出，建议统一到**《中庸》为学五阶 + 「广大精微」**这一套，天然覆盖六科：

| 产品 | 名 | 出处 |
|---|---|---|
| 政治理论（已定） | 知行日知 | 《论语》日知其所亡 |
| 申论（已定） | 知行策论 | 科举策问论对 |
| **汇总 / 母体** | **知行致广** 或 **知行一贯** | 「致广大而尽精微」/「一以贯之」 |
| 言语理解 | 知行审问 | 博学、审问、慎思、明辨、笃行 |
| 数量关系 | 知行慎思 | 同上 |
| 判断推理 | 知行明辨 | 同上（也与日知的「辨清表述」呼应，注意区分） |
| 资料分析 | 知行精微 | 「尽精微」，正合资料分析的精算气质 |

好处：任何一个被占，只换那一科，不影响整体系列感；且这些词都**不含考试/培训字样**，对个人主体友好。

## 5. 怎么快速核验是否被占

1. **搜一搜**：微信顶部搜索输入「知行韦编」，切到「小程序」标签——有同名即不可用（名称全局唯一，近似名一般可用）。
2. **MP 后台实时校验**：小程序后台 → 设置 → 基本设置 → 名称「修改」，输入候选名后**提交前就会校验重复**，未发布也能反复试，这是最准的判据。
3. 顺手查同名**公众号**：若同名公众号属他人，即使小程序名可用，后续也可能被判重或引流纠纷。
4. 一次多备 3–5 个，按上面顺序逐个试。

---

## 6. 两件值得提前做的事

**① 名称一年只能改两次**，所以别用「先随便注册占位、以后再改」的思路——两次改完就锁死了。第一次就定下最终名。

**② 商标是唯一的「重名翻盘」手段。** 若坚持用某个已被占的名字，微信支持凭商标注册证申诉名称。建议注册 **第 41 类（教育培训）** 与 **第 9 类（可下载软件/APP）** 的「知行日知 / 知行策论 / 知行公考」文字商标。注意：中国大陆以个人名义申请商标通常需要个体工商户营业执照，纯身份证申请受限——如果打算长期做矩阵，这一项的性价比高于反复换名。
