# Canva 制作规格单 · 知行日知 / 知行策论 小程序头像

> 用途：在 Canva 网页端手动挑选模板并制作正式 Logo 头像
> 制作基准：1080×1080 px 画布（导出后再缩放，保证 144px 清晰）

---

## 0. 挑模板建议

在 Canva 首页搜索以下关键词，找**中式印章/方形徽标**类模板：

- 中文：`印章 logo`、`中式 logo`、`篆刻`、`国潮 徽标`
- 英文（结果更多）：`seal stamp logo`、`chinese seal`、`red square logo`

挑模板只看**版式结构**（方框 + 竖排两字），颜色和字体全部按本单替换。找不到合适的也可以直接从空白设计开始，结构很简单。

## 1. 画布与配色

| 项 | 值 |
|---|---|
| 尺寸 | 自定义 1080 × 1080 px |
| 底色 | 品牌红 `#D0021B`，**铺满整个画布**（不要留白边、不要放圆角红块） |
| 文字/框线 | 纯白 `#FFFFFF` |
| 效果 | 关闭所有阴影、发光、渐变、纹理 |

## 2. 版式参数（1080 画布下的像素值）

| 元素 | 参数 | 说明 |
|---|---|---|
| 白色方框 | 距四边 **172px**，线宽 **13px**，圆角 **38px** | 关键：框的四个角必须完整落在内切圆内，圆形裁切才不切框 |
| 文字 | 竖排两字，总高约占画布 **58%**（约 626px） | 水平垂直居中 |
| 字间距 | 两字之间留约 **8% 画布高**（86px） | 太挤在小尺寸下会糊成一团 |
| 安全区 | 文字左右边缘距画布边 ≥ **25%** | 圆形裁切后仍完整 |

> 原理：圆形头像展示时按内切圆裁切，边长 1080 的圆裁掉四角。方框半边长 368px，对角线 520px < 半径 540px，所以框完整可见。

## 3. 字体

优先级从高到低：

1. **Canva 字体面板搜索「篆」**，选一款笔画粗细均匀的小篆（如可用）；
2. Canva Pro 可**上传自定义字体**——推荐免费商用篆书「汉鼎篆体」（文悦字体，上传前请自行确认授权条款）；
3. 实在没有篆书，退而用**宋体/明朝体 Heavy**（如思源宋体 Heavy），做成「现代宋体方章」，同样成立。

两枚 Logo **必须用同一字体、同一字号、同一版式**，只换文字，保证系列感。

## 4. 两枚内容

| 文件 | 文字 | 备注 |
|---|---|---|
| 知行日知 | 竖排「日知」 | 政治理论小程序 |
| 知行策论 | 竖排「策论」 | 申论小程序 |

⚠️ 用**简体字**（日知 / 策论），不要用繁体「策論」——小程序名是简体，头像与名称需一致，且简体在小尺寸下更易读。

## 5. 自检清单（导出前）

- [ ] 缩小到 40×40 px 看一遍，两个字仍清晰可辨
- [ ] 在 Canva 里临时叠一个正圆蒙版（或用「形状」画一个透明圆 + 黑底）确认框和字都不被裁掉
- [ ] 无 Canva 水印（免费模板带水印元素需替换为免费元素，或用 Pro 导出）
- [ ] 底色为 `#D0021B`，与 App 品牌色一致
- [ ] 两枚版式完全同构，仅文字不同

## 6. 导出与交付

| 用途 | 规格 |
|---|---|
| 小程序头像（上传用） | PNG **144 × 144**，≤2M |
| 高分辨率母档 | PNG **1024 × 1024** |
| 应用内/分享图 | PNG **512 × 512** |

Canva 导出时如不能直接指定 144px，先导出最大尺寸，把设计链接或文件给我，我用插件 `resize-design` / 本地脚本批量生成三档尺寸并做圆形裁切预览验证。

## 7. 做好之后

告诉我 Canva 设计名称（或分享链接），我会：

1. 用 `get-design-thumbnail` 拉缩略图检查版式与圆形适配；
2. 用 `export-design` 导出 PNG 全规格；
3. 把成品同步到 `apps/theory-app`、`apps/shenlun-app` 的品牌资源目录。
