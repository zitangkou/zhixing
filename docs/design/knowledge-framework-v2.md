# 知识框架通用展示与维护方案（第一版实现）

## 产品入口

学习首页「知识框架」和「我的」入口进入同一个通用页面。先选择科目，再逐层浏览；「结构总览」展示前两层，点击继续深入。支持当前科目搜索、面包屑返回、末级内容弹层、图片放大。游客可以浏览公开知识框架。

新增科目不需要增加页面或修改前端代码。科目名称、简介、分组、节点标题、顺序和内容由后台维护。只有已上线且设为「学员可见」的科目进入列表。

## 内容模型

- 根：schemaVersion=2、title、description、groups、children。
- 节点：稳定 id、title、blocks、children；路径、深度由服务端派生。
- 内容块：文字 text；公式 formula（latex + plain）；图片 image（url + alt）；例题 example（question + answer）。分支节点同样可以维护内容。
- 公式：H5 用共享 LatexBlock 排版；微信小程序使用必填可读式，避免依赖浏览器 HTML/CSS。复杂几何图、复杂公式可上传 PNG/JPEG 图片补充，图片支持点击放大。
- 文字保留换行，第一版不接受任意 HTML。图片可上传（最多 3MB）或填写 HTTPS 地址；公式可读式可以用 ×、÷、括号、上标字符。

## 后台操作

主界面仅保留科目选择、新增科目、保存状态、发布、更多操作及可见性开关。

左侧搜索/选择知识树：新增一级、下级、同级，调整顺序，拖动调整层级，删除。右侧编辑内容或手机预览。默认自动保存草稿；切换科目、离开路由先完成保存，失败时保留当前编辑。一级分类可填写展示分组；不填则直接按顺序展示。

发布前校验完整性并显示新增/保留/归档数量。发布固化版本后激活；无需生成整张思维导图图片。首次发布后需要开启「学员可见」。高级工具保留 Markdown 导入、旧图片资产、版本与回滚；Markdown 保存/导入会替换结构化草稿，应先保留版本。

## 同步与兼容

KnowledgeTree 新增 draft_tree_json，启动兼容迁移自动补列。旧 Markdown 草稿首次打开转换为通用树，沿用已发布节点的 ID，保存后使用结构化草稿。版本 tree_json 保存结构、内容块、简介与分组。

草稿保存不修改线上快照；包括科目名称，学员接口只读取 liveVersion。发布后下次进入、切换科目或下拉刷新读取新版本，未实现实时推送。节点改名、移动保留 ID；删除后归档，不删除个人关联状态。用草稿 revision 防止并发覆盖，用 expectedLive 防止覆盖别人刚激活的版本。
