- 全报非广告版面先发现目录：明确评论栏目直接纳入，补齐和音、金台锐评、四海听音、环球走笔等；未知栏目以20条一批分类，不确定文章通读正文后再判断。目录分类响应不合法时停止并报安全错误码，不伪报完成。

- 先比较候选再精选最多3句，12—55字优先，70字硬上限；连续节选不改原文。模型自评记忆成本、逻辑、迁移、亮点四项至少各3/5且总分至少16/20。自评分只作筛选提示，不代表质量认证，仍须人工审核。

- 原句连续性、长度、低分及领导人引语拒绝仍严格执行；引语校验定位到引述范围，不再因证据邻文出现领导人姓名直接拒绝。自动检测不是引语归属的完整证明，审核时仍需核对。
- 高亮不在对应正文中时移除并记录警告，保持正文原样；不对错字原句作模糊匹配。单条写入用savepoint隔离，一句失败不再丢掉整篇。两种构件改为质量提醒，不通过改标签凑构件。
- 有失败的文章保留partial供重试，合格句已入待审；按来源与原句指纹去重，已有人工审核和启用结果不覆盖。已完成文章仍跳过，本次规则升级不会重写既有采集记录。

### 人民日报申论题型每日练习生成（本地实现）

1. 每日北京时间09:00—11:00等待人民日报共享采集池及词汇联合分析任务完成，再从当天缓存与分析结果中筛选申论候选；复用已有48小时正文，不恢复已退役的全量档案采集/评估任务。
2. 生成规则基于`server/app/knowledge/shenlun_exam_standards.json`：整理历年国考题型设问、教材方法和范例、给定资料DNA、四题型评价维度。候选除达到质量门槛、能回查原文外，还必须至少包含公共议题、治理或政策执行类证据锚点；人物故事、旅行见闻和生活方式文章不能仅凭高分进入出题池。正文哈希去重后每批最多处理3篇、每篇最多2题。摘录须为完整连续原文，不接受省略标记；每题至少3条题型匹配的评分维度，解析不少于160字；答案长度按结构化字数上限或题干明确要求由程序硬校验。参考要点常规优先4—6项，最多8项；超过常规数量须说明各点不可合并的理由并通过颗粒度复核。
3. 通过硬规则初筛后，结构化语义复核须检查题型、答案逐点覆盖、材料证据、答案和解析的材料忠实度、答案字数及要点颗粒度。材料外事实/地名/组织/案例、答案漏点、证据过度推断等实质性问题不论模型给出何种严重度均退回；逐点引文无法在答案或材料中定位、问题字段缺失或复核结论矛盾也退回。纯措辞建议可以显示为一般提示，但质量分不能抵消任何硬问题。生成和复核会参考`server/app/knowledge/shenlun_benchmark_cases.json`中的8个教材真题任务结构样例，按题型校准设问；每题质量报告记录基准集版本。复核还须逐点解释材料证据如何支持要点、答案如何保留要点的对象与动作；解释缺失或空泛即退回，后台展示理由供教研核验。复核与生成当前使用同一服务端LLM，不能替代独立教研审核。旧规则草稿会显示为需复核。审核结论、问题维度、审核意见和是否修改内容会写入质量报告并保留历史，作为后续质量校准样本；后台反馈面板按题型汇总审核结论、修改量和高频问题维度；练习必须经人工审核后发布，系统不会自动公开或给学员答案打分。
4. 后台“人民日报 → 申论练习”可按刊期手动补跑并查看候选总数、本批上限、逐篇进度、质量退回、运行失败和材料跳过明细；同刊期再次运行会跳过此前成功处理的候选，续跑后续候选，运行失败的文章可重试。若上游联合分析失败，可从此页进入“词汇素材”并带入刊期后手动重跑。定时任务使用`RMRB_SHENLUN_AUTO_ENABLED`（默认`true`）控制；每日上游任务达到重试上限后不会自动恢复。小程序学员先提交作答，再对照材料证据、参考要点、示例答案和解析，并可订正及记录复盘。

### 2026-10-16 · 速算训练后台与练习闭环（后端已部署；小程序包已构建，待手动上传）

资料分析公式、题型和技巧的默认种子位于 `server/app/seed_data/ziliao/`，随应用镜像发布，与生产持久化数据卷分开。FastAPI 启动时会幂等补齐缺少的默认编码；后台「同步种子」也可执行补齐，不覆盖已有人工维护内容。「强制覆盖种子」才会用仓库版本覆盖同编码内容。生产旧版本曾将这些 JSON 放在被 Docker 排除的 `server/data/`，并且该目录由持久化卷遮住镜像，因此本机有数据、生产没有；修复后部署新镜像会自动补齐，重启旧镜像或只上传小程序不会初始化。

小程序通过 `/api/ziliao/quick-calc/*` 获取已发布规则并创建服务端练习，需要登录账号；未登录会提示前往登录。每题答案提交后由服务端判分，完成会话后同步个人历史；错题可以创建新的练习会话重做。会话保存出题快照、方法版本、答题文本和耗时。后台效果页支持 7/30/90 天筛选，显示完成组数、答题数、各方法正确率、平均用时及错选文本。离线时不能判分或进入后台统计，恢复连接后需重新提交当前选择。
