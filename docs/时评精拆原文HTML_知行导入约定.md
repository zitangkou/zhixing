# 时评精拆原文 HTML（知行导入约定）

> 物料脚本在 iCloud `申论学习/工作流/原文HTML生成.py`。本文只记**知行「时评文章 → 新建时评 → 预览」依赖的字段**，供物料生成智能体与本仓库对齐。解剖页 HTML 走「导入解析」，不走本约定。

## 预览抽取（2026-09-11）

粘贴 `文章目录/原文/<标题>_原文.html`。解析函数 `parse_rmrb_source_html`（不是理论文的 `parse_article_html`）。

须能抽出：

| 后台字段 | HTML 约定 |
|----------|-----------|
| 标题 | 居中 `h1`（可带《》）；不要把报头 28px「时评精拆」当标题 |
| 原文链接 | `查看人民日报原文` 的 `paper.people.com.cn` 链接 |
| 来源 / 日期 | `—— 人民日报 YYYY-MM-DD …` 或底部「原文出处：」 |
| 主题 | 标题下明文 **`主题：作风建设`**（顿号/逗号可多个）。优先命中后台预设：政绩观、社会治理、乡村振兴、县域经济、高质量发展、民生保障、作风建设、基层减负、科技创新、文化建设、生态文明、依法治国；扫不到则用解剖「主题归类」里 `·` 与 `｜` 之间的短名（如 `干部成长`） |
| 摘要 | **`中心论点：` + 灰底斜体块** = 原文中**中心论点文段**（含「关键在于」等），不是首段钩子 |

- 全部正文段落都在正文区（钩子也保留）。
- 无 `主题：` 时预览警告，主题可手选后保存。
- 旧 HTML（灰块=首段、无主题行）需重跑 `原文HTML生成.py`。

## 生成脚本要点

- 选中心论点：优先含 `关键在于|核心在于|根本上|归根结底|必须坚持` 的段落；否则跳过「近日/某县」类钩子后再取较长议论。
- 主题：同文章目录已有 `解剖/*_三刀解剖.md` 时读 `主题归类:`；解剖未写完可空。
- 导入解析弹窗只挂精拆 HTML，不回填原文主题/摘要。
