# 判断推理

## 逻辑判断

### 必然性推理

- 直言命题
  - 矛盾关系
    - 两个命题一真一假，前面加“并非”转化
  - 推出关系
    - 两个命题既可同真，又可同假
    - 有的p是q
      - 可以换成
        - 有的q是p
  - 下反对关系
    - 两个命题必有一真，可以同真，不能同假
  - 上反对关系
    - 两命题必有一假，可以同假，不能同真
- 复言命题
  - 联言命题
    - 多个肢命题同时为真
    - p且q
      - 非p或非q
  - 选言命题
    - 不相容选言命题
      - 有且只有一种情况为真
      - 要么p，要么q
        - 要么p且q，要么非p且非q
    - 相容选言命题
      - 允许多种情况同时为真
      - p或q
        - 非p且非q
- 假言命题
  - 充分条件假言命题
    - p=>q，可以推出，非p<=非q
    - p=>q，矛盾命题为，p且非q
    - 常见表述
      - 只要p就q
  - 必要条件假言命题
    - p<=q，转换为充分假言命题，q=>p，可以推出，非q<=非p
    - p<=q，转换为充分假言命题，q=>p，矛盾命题为，q且非p
    - 天p是q的必要条件
    - 常见表述
      - p是q的必要条件
      - 除非p否则非q
  - 连锁推理
    - p1=>p2，p2=>p3，p4<=p3，p4=>p5
      - p1=>p2=>p3=>p4=>p5
  - 题型
    - 给出判断q，补充前提p
      - 则选项必须是p=>q，或者非q=>非p
- 朴素逻辑
  - 代入排除法
  - 假设法
  - 图表法
    - 列表法
    - 画图法
  - 找突破口法
  - 选项反向证明
    - 没有明显突破口、信息太多无法判断，则否定选项，判断是否满足题意，不满足则表示正确选项
  - 解题方法
    - 找出矛盾关系或者其它对当关系命题
    - 基于推理规则，列出推理关系，无法确定，结合假设法进一步推理

### 可能性推理

- 论证结构
  - 论点
  - 论证方式
  - 论据
- 前提型
  - 搭桥法、反向代入法
  - 题干中论据与论点之间一般存在明显的跳跃，由于题干论据不足不足以推出论点，需要增加隐含假设才能使论证成立
- 削弱型、加强型
  - 求异论证
    - 切断因果、因果倒置、另有他因
    - 解释因果、无因无果、排除他因
  - 原因分析
    - 因不致果、另有他因
    - 建立因果联系、排除他因
  - 枚举归纳
    - 样本特殊、存在反例
    - 样本具有代表性
  - 类比论证
    - 本质不同/相同
  - 提出方法
    - 达不到目的/达到目的、方法不可操作/方法可操作
- 解释型
  - 题干给出某一事实或论证的描述，要求从选项中找出最能够合理解释题干所述的一项，题干描述大多是一个结论、现象、矛盾或差异
- 结论型
  - 错误选项，无中生有、过度推测、偷换概念、违背规则、信息矛盾
  - 题干给出一段论述或推理，要求选出能够根据题干信息进行归纳或者推出的选项
- 评价型
  - 对题干论证的结构、方式、有效性等做出评价

## 定义判断

### 定义特征分析

- 主体
- 客体（对象）
- 目的
- 条件
  - 排除选项
- 原因
- 结果
- 方式（或手段）
- 本质

### 定义特征归纳

- 筛选信息，提取主要信息，筛掉次要信息
- 一般考察哲学、语言学、社会学、心理学、管理学等领域的定义
- 根据条件、目的、结果、方式排除选项

## 图形推理

### 题型

- 顺推
  - 题干包含一组图形和一个空缺项，需要根据已知图形的排列规律填补空缺
  - 共同特征、连续变化规律、奇偶项规律
  - 对称、数量关系、移动转动
- 类比
  - 题干有两组图形，每组三个，第二组空缺一个，需要根据第一组图形规律填补
  - 第一组规律、两组对应图形规律
- 九宫格型
  - 题干为3x3的方格，给出八个图形，要求按照八个图形的排列规律填补第九个空格的图形
  - 行、列、连续变化、整体
- 分类分组型
  - 找两个图形突破口再验证、寻找共同特征
  - 题干给出六个图形，要求将六个图形分成两组，每组三个图形，使得每一组图形都有各自的共同特征
- 条件型
  - 题干给出明确条件和相应图形，根据条件进行推理，选择选项
  - 空间折叠、立体拼接与切割、截面图、三视图

### 考察方式

- 移动转动
  - 移动
    - 图形由多个相同部分组成，但相对位置不同，考虑移动方向（顺逆时针、某一特定方向）和距离（格数）
  - 题干图形的整体相似程度较高或者有多个小图形相同时，优先考虑移动、转动
  - 转动
    - 旋转
      - 图形构成相同，角度不同，整体绕其中心旋转，考虑旋转的方向（顺逆时针）和角度/格数
    - 翻转
      - 相邻图形对称相似，考虑上下翻转或左右翻转
- 对称性
  - 轴对称
    - 是否轴对称图形、对称轴数量、对称轴方向
    - 对称轴彼此间关系（垂直）
    - 对称轴与图形某一部分位置关系、穿过图形数量
  - 中心对称
    - 把一图形绕着某一点旋转180度，与另一图形重合，两个图形关于这个点对称，呈中心对称
  - 轴对称与中心对称
    - 综合考察
- 叠加
  - 直接叠加
    - 两个图形直接叠加形成新的图形，保留两个图形所有形状
    - 结合图形旋转、翻转，再叠加综合考查
  - 自定义叠加
    - 两个图形按照特性规则叠加，得到第三个图形
    - 根据图形变化确定叠加规则，阴影类图形推理
  - 去同存异、去异存同
    - 两个图形叠加后去掉/保留相同部分，保留/去掉不同部分，得到第三个图形
- 数量关系
  - 封闭区域数
    - 图形中每一个封闭的、空白的区域称为图形的封闭区域
  - 部分数
    - 包含相同部分
    - 图形中不相连的部分就是图形中不同的部分，对应部分数
  - 线条数
    - 直线数、曲线数、线条总数
    - 结合交点数、角的数量考察
  - 笔画数
    - 通过几笔将图形不间断、不重复地画出，由图形中的奇点个数决定（汉字和字母按笔画数）
    - 图形中所有的交点及端点中，连线数量为奇数的点
    - 笔画数 = 奇点数/2（奇点数成对存在，偶数），0、1均一笔
  - 交点数
    - 十字交叉点、直线与曲线的交点、接触点
  - 角的数量
    - 角的数量，直角、钝角、锐角数量
  - 面积周长
    - 面积占比，阴影部分占整体的比例，周长关系
  - 图群数
    - 小图形种类、个数、数量换算（如一个小三角=两个小圆圈）
    - 小图形组合、大图形分割的小图形
- 相对位置
  - 结构位置
    - 上下、左右、内外
  - 排列位置
    - 相邻、相交、相离、相切
  - 平行、垂直、小图形特殊位置
- 立体图形
  - 空间折叠
    - 小图形特征判定法
    - 区分相邻面与相对面
    - 马走日法
      - 根据平面图点走两次“马走日”寻找公共点，再根据小图形特征判断
    - 移面法
      - 有夹角的两个面可以绕公共点滚动
      - 222、33格式，最左可以直接移动到最右下面，反之也行
      - 141格式，最左可以直接移动到最右，反之也行
      - 231格式转换成其他格式
    - 还原法
      - 图形新趋势，边没有完全相接，只有交点相接，需要还原为正常形状，再解答
  - 立体拼接与切割
    - 旋转、移动或翻转
  - 截面图
    - 正方体
      - 可截出正方形、长方形、平行四边形、菱形、梯形，至少一组平行边
      - 可截出锐角，不能截出直角和钝角
  - 三视图
    - 外部轮廓与细节特征（内部线条，实虚线）
    - 主视图、俯视图、左视图

## 类比推理

### 逻辑关系

- 集合关系
  - 全同
  - 包含
    - 组成
    - 种属
  - 全异
  - 交叉
  - 并列
    - 矛盾
    - 反对
- 条件关系
- 充分必要条件关系
- 因果关系
  - 区分必然与可能区别，有些事件之间的联系是必然的，有些只是可能的

### 言语关系

- 语法关系
  - 主谓结构
  - 动宾结构
  - 并列结构
  - 偏正结构
    - 一个词语修饰另一个词语
  - 主宾结构
- 语义关系
  - 近义关系
  - 反义关系
    - 区分绝对反义和相对反义，绝对反义词指两个词之间是非此即彼的关系，不存在中间项，如生：死，动：静
  - 象征关系
    - 一个词语是另一个词语的象征，如鸽子：和平，蓝色：忧郁
  - 语义程度轻重
  - 词语适用对象，人、事物，抽象、具体
  - 词语感情色彩，褒贬
  - 词语词性，名词、动词

### 常识关系

- 经验常识
  - 目的关系
  - 加工关系
  - 顺承关系
  - 职业关系
  - 功能关系
  - 特征关系
    - 区分必然属性和或然属性
    - 指事物与其主要特征、性质等的关系
- 理论常识
  - 考查学科知识繁杂、范围较广，涉及语文、数学、物理、化学、地理等等
