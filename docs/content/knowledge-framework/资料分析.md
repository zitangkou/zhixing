# 资料分析

## 翻番

### a翻n番 = a x 2的n次方

## 增长

### 增长量（X）

- 现期值 - 基期值
  - B - A
- 现期值 x 增长率 / (1 + 增长率)
  - BR/(1 + R)
    - n＋1的原则，11.4% ≈ 1/9，n＝9增长量 = 现期值 / (n+1)
- 基期值 x 增长率
  - AR
- 增长量比较
  - 大大则大，一大一小看乘积

### 增长率（R）

- 增长量 / 基期值
  - X/A
- 增长量 / (现期值 - 增长量)
  - X/(B - X)
- 现期值 / 基期值 - 1
  - B/A - 1

### 基期值（A）

- 现期值 - 增长量
  - B - X
- 增长量 / 增长率
  - X/R
- 现期值 / (1 + 增长率)
  - B/(1 + R)

### 现期值（B）

- 基期值 + 增长量
  - A + X
- 基期值 x (1 + 增长率)
  - A(1 + R)

## 比重/倍数/平均数

### 现期

- 现期部分值 / 现期整体值
  - A / B

### 基期

- (现期部分值 - 部分增长量) / (现期整体值 - 整体增长量)
  - (A1 - a) / (A - b)
- (现期部分值 / 现期整体值) x (1 + 整体增长率) / (1 + 部分增长率)
  - ((A / B)(1 + Rb)/(1 + Ra)

### 增长量

- (现期部分值/现期整体值) x (部分增长率 - 整体增长率) / (1 + 部分增长率)
  - (A / B)(Ra - Rb) / (1 + Ra)

### 增长率

- (部分增长率 - 整体增长率) / (1 + 整体增长率)
  - (Ra - Rb) / (1 + Rb)

## 混合问题

### 线段法（快速判断）

- 标轴上标出部分增长率，混合增长率介于之间，偏向且偏向于权重（基期部分）较大的一方
- (混合增长率 - 部分增长率1) / (部分增长率2 - 混合增长率) = 基期2 / 基期1 约等于 现期2 / 现期1
  - (r - r1) / (r2 - r) = A2 / A1 约等于 B2 / B1

### 快速判断法

- 以增长率为例，整体增长率介于多个部分增长率之间
- 整体增长率介于部分增长率之间
  - 求解当期增长率与累计（整体）增长率大小
  - 只要累计（整体）增长率是增长的，那么当期增长率就大于累计增长率
  - 分解为当期增长率N（部分增长率）、N-1期累计增长率（部分增长率）、N期累计增长率（整体增长率）

### 十字交叉法

- 根据混合增长率及部分增长率求基期比（十字交叉法）
- 先求解出混合增长率，再根据混合增长率与部分增长率，结合 a - c / c - b 十字交叉法求解出基期比重之比
- 基期2 / 基期1 = (混合增长率 - 部分增长率1) / (部分增长率2 - 混合增长率)
  - A2 / A1 = (r - r1) / (r2 - r)
  - 约等于现期比 B2 / B1

## 隔年增长

### 隔年增长率

- (1 + 增长率1)(1 + 增长率2) - 1
  - R1 + R2 + R1 x R2
- 增长率2 = (1 + 隔年增长率)/(1 + 增长率1) - 1
  - R2 = (1 + R) / (1 + R1) - 1
- 当每年增长率都不大时（1.x%类似），直接约等于每年的增长率之和，选择最接近的值，R > R1 + R2 + R3...

### 隔年基期值

- 现期值 / ((1 + 同比增长率)(1 + 上年同比增长率))
  - 现期值 / (隔年增长率 + 1)
    - B / ((1 + R1)(1 + R2))

## 年均增长

### 年均增长量

- (末期值 - 初期值) / 增长次数（年份则期末年份 - 期初年份）
  - (B - A) / n

### 年均增长率

- (末期值 / 初期值) ，再开增长次数根号 - 1，年均增长率大小比较，则直接比较（末期值 / 初期值）的大小
- 快速计算
  - (A/B - B/A) / 2n
  - (B - A)/ n x A（偏大）
    - 优先考
- (末期值- 初期值) / 增长次数 * 初期值
  - (B - A)/ n x A（偏大）
- (末期值 / 初期值 - 初期值 / 末期值) / 2n
  - (B/A - A/B) / 2n

## 贡献率

### (部分增长量 / 整体增长量) x 100%

- (PX / TX) x 100%

## 拉动......增长

### 拉动...增长...个百分点

- (部分增长量 / 整体基期值) x 100
  - (PX / TA) x 100

### 拉动...增长的百分点数

- 贡献率 x 整体增长率 x 100
  - G x (TX / TA) X 100

## 快速计算

### 加减速算

- 根据选项前几位数不同，确定取几位有效数字计算

### 除法速算

- 分子、分母取前两位有效数字计算，一般遵循同舍同进原则

### 乘法速算

- 小数四舍五入大数反向取舍
  - 通过前三位有效数字确定大小数字，第三位有效数字都为8、9，则都进位，都为0、1、2则都舍去
- 特征数字法、乘数拆分法
  - 小数、百分数转化为特征数字的分数、拆分为特征数字
    - 11.1% = 1/9
    - 14.3% = 1/7
    - 12.5% = 1/8
    - 16.7% = 1/6
    - 33.3% = 1/3
  - 小数、百分数
    - 83.3% x 33421 = (50% + 33.3%) x 33421
    - 87.5% = 7 x 12.5% = 7/8
    - 88.8% = 8 x 11.1% = 8/9
    - 85.8% = 6 x 14.3% = 6/7
    - 11 = (10 + 1)
- 乘数拆分法
- 两位数 x 两位数
  - 前前后后，里里外外，对齐相加
    - 87 x 91
      - 7x9 = 63, 8x1 = 8，63 + 8 = 71
      - 8x9 = 72, 7x1 = 7，7200 + 0007 = 7207
      - 7207 + 0710 = 7917
  - 前前后后从右至左对齐相加，里里外外在对齐右进一位相加
- 错位加减法
  - 分母和分子同时加减相同倍数等于原值，模拟出可直接约掉分母的表达式
  - 根据现期和增长率求基期、求增长量
    - 不管百分数，直接保留三位有效数字计算，跟选项对比，分母接近100，则后面减去一个100倍数的值，放大倍数修正
- 除乘转化法（求基期和增长量）
  - 将某种列式中的除法转化为乘法
  - a / (1 + x%)，若x < 5，则a / (1 + x%) ≈ a(1 - x%)，实际值略大于估计值，直接根据选项判断大小
- 假设估算判断法、尾数计算排除法
  - 已知现期、增长率，求基期，假设一个特征数字的基期，比较假设基期的增长量及现期，快速判断
  - 现期可以快速估算场景

### 尾数判断

- 取每个数据的末尾数字进行计算，通过确定尾数来判断正确答案的方法，可以是最后一位，或最后几位
- 倍数 = 增长率 - 1
- 中位数不等于平均数

## 快速比较

### 大小比较

- 差分比较
  - 若A>C，B>D，则判断A-C)/(B-D)的大小
    - 若(=C/D，则=
    - 若(A-C)/(B-D)>C/D，则>
    - 若(A-C)/(B-D)<C/D，则<
- 同位比较
  - 判断A/C、a（中间值）、B/D的大小，即分子倍数关系大，分数大，分母倍数关系大，分数小
    - 则A/B > C/D
  - 若A/C < a < B/D
    - 则A/B < C/D
- 分母拆分（分子分母接近）
  - 判断分子除以分母减去分子的差值的大小，A/(B-A) > C/(D-C)
- 比较AxB与CxD
  - 转化为A/C与D/B比较
  - 比较Axa/(1 + a)与Bxb/(1 + b)，看作AxB与CxD比较
