# 数量关系

## 解题方法

### 方程法

- 普通方程
  - 设未知数
    - 涉及等量关系最多的中间量
    - 比例、百分数，A:B=m:n，设mx、nx，m和n互质
  - 等量关系列方程
  - 解方程
    - 代入消元法
    - 加减消元法
    - 换元还元法
    - 不定方程，结合整除特性、奇偶性、尾数、特值判断

### 整除法

- 尾数判断
  - 2、5（末位）
  - 4、25（末两位）
  - 8、125（末三位）
- 和判断
  - 3、9
- 差判断
  - 7、11、13（末三位与剩下位数之差）
- 相关定义
  - 质数
    - 互质
    - 合数判断，分解成互质的因数
  - 公因数
  - 可传递性
  - 可加减性

### 特值法

- 设特殊值为1
  - 为避免出现过大的数字
- 设特殊值为100
  - 题干给出百分数
- 设特殊值为公倍数
  - 多个比例关系互质，设未知的总量为已知分量的公倍数
- 设特殊值为最简比
  - 出现比例关系，将比例的份数设为特殊值

### 比例法

- 不设未知数而设份数，利用份数代替实际量进行计算

### 十字交叉法

- 方程的简便形式，用于解决事物之间的混合比值问题
  - aA + bB = c(A + B)
  - a、b代表两个分量比值，c代表混合后的比值，A、B代表a、b对应分母量的比值
- 浓度问题
  - 浓度 = 溶质 / 溶液，已知不同浓度（a、b）和混合后浓度（c），求去混合前两种溶液量比（A/B）
- 增长率问题
  - 增长率 = 增长量 / 基期值，已知今年上下半年（a、b）和今年的增长率（c），求去年上下半年量比（A/B）

### 代入排除法

- 不易列方程、方程不易求解或无需求解
- 多位数问题，个位、十位、百位求具体数
- 多个数量之间和差倍比关系明确

### 逆推法

- 正面求解困难
- 涉及步骤数量关系，已知最后一步结果，列表格逆推

## 常考题型

### 等差数列

- 常用公式
  - m + n = p + q ， am + an = ap + aq
  - an = a1 + (n - 1)d
  - m + n = p + q，am + an = ap + aq
  - Sn = n x a1 + n(n - 1)d / 2
  - Sn = 中项 x n
- 等比数列
  - an = a1 x q^(n-1)，
  - Sn = a1(1-qn) /( 1-q)(q ≠ 1)，Sn = na1(q = 1)，等比数列求和
  - 绳子对折n次中间剪断问题
    - 每次剪断新增2x2n个端点，加上起始两个，共2(2n+1)个端点 ，则有2n+1条线段

### 和差倍比

- 已知两个数和、差，则小数 = (和 - 差) / 2，大数 = (和 + 差) / 2
- 已知两个数和、倍数关系，则小数 = 和 / ( 倍数 + 1)
- 已知两个数和、倍数关系，则小数 = 和 / (倍数 + 1)
- 已知两个数差、倍数关系，则小数 = 差 / (倍数 - 1)

### 利润问题

- 利润 = 售价(收入) - 成本(支出)
- 利润率 = (利润 / 成本) x 100% = (售价 / 成本 - 1) x 100%
- 打 N 折 = (售价 / 原价) x 10

### 工程问题

- 核心公式
  - 工作总量 = 工作效率(每人每天) x 工作时间，S = VT
  - 基于核心公式结合比例法、方程法、特值法求解
  - 普通工程问题，基于核心公式，结合比例法、方程法、特值法求解
- 多者合作问题
  - 效率和 = 效率1 + 效率2 + ...
  - 工作总量 = 第一者工作量 + 第二者工作量 + ...
  - 先求解每个合作团队完成整个工作量需要的工作时间，在基于每个合作团队完成整个工作量的工作时间最小公倍数，设整个工作量特值，再分别算出每个合作团队的工作效率，从中得出每个合作团队或者单个成员的效率，再求其他
- 交替完工问题
  - 根据已知条件将工作量或者工作效率表示为特值
  - 找出合作周期并计算每个周期完成的工作量
  - 根据循环顺序，确定剩余工作量的完成方式及完成时间
  - 计算完成该项工作需要的完整周期数以及剩余工作量
- 多劳力合作问题
  - 如果V1 / V2 > V3 / V4，则甲相对擅长A产品，乙相对擅长B产品
  - 甲生产A、B产品效率之比为V1 / V2，乙生产A、B产品效率之比为V3 / V4

### 排列组合

- 加法原理
  - 完成一件事情需要划分几个类别，各类别中的方法可以独立完成这件事情
- 乘法原理
  - 完成一件事情需要分几个步骤，每个步骤内的方法刚好完成该步骤，所有步骤实施完毕刚好完成这件事
- 排列
  - 从n个不同元素中任取m个按照一定的顺序排成一列
  - 公式：A(n,m) = n x (n - 1) x ... x (n - m + 1)
  - 全排列：A(n,n) = n x (n - 1) x ... x 1 = n!
- 组合
  - 从n个不同元素中取出m个元素作为一组，不考虑取出的顺序
  - C(n,m) = A(n,m) / A(m,m) = n x (n-1) x ... x (n - m +1) / m x (m - 1) x ... x 1
    - 简化计算：C(n,m) = C(n,n-m)
  - 快速计算
    - A(3,2) = A(3,3) = C(4,2) = 6
    - A(4,2) = 12
    - A(4,3) = A(4,4) = 24
    - A(5,5) = 120、A(6,6) = 720
    - C(3,2) = 3、C(5,2) = 10、C(6,2) = 15、C(6,3) = 20
  - 快速解法
    - 优解法
      - 题干中有些元素有条件限制，优先排有条件限制元素
    - 捆绑法
      - 有些元素必须相邻，分两步排，第一步将相邻元素作为整体排，第二步考虑捆绑元素之间的相对顺序
      - 需要考虑捆绑元素内部的排列顺序对事件是否有影响
    - 插空法
      - 题干要求指定元素不相邻，分两步完成，第一步先排其他元素，将不相邻元素插入这些元素所形成的空位中
      - 空位数量要数清楚

### 行程问题

- 核心公式
  - 路程 = 速度 x 时间，s = vt
  - 平均速率
    - v = s / (t1 + t2 + ...) = s / (s1 / v1 + s2 / v2 + ...)
    - s1 = s2 = ...时，v = n / (1 / v1 + 1 / v2 + ...)，且n = 2时，v = 2v1v2 / (v1 + v2)
    - t1 = t2 = ...时，v = (v1t1 + v2t2 + ...) / (t1 + t2 + ...)，且n =2时v = (v1 + v2) / 2
    - 一般用来求解变速运动问题，特别时匀变速运动时，平均速度 = (初速度 + 末速度) / 2
  - 相遇追及问题
    - 直线相遇追及
      - 相遇路程 = 速度和 x 相遇时间
      - 追及路程 = 速度差 x 追及时间
    - 多次相遇
      - 相向而行，且做往返运动，涉及多次相遇问题
      - 第n次相遇，两人所走的路程和sn = (2n - 1)s
      - 第n次相遇，所用时间为tn = (2n - 1)t
    - 环线相遇追及
      - 第n次相遇，两人所走的路程和sn = ns
      - 第n次追及，一个比另一个多跑ns

### 概率问题

- 古典概率
  - 等可能概率事件，有限个等可能事件发生的概率
  - 事件A发生的概率 = 事件A包含的等可能样本数 / 总的等可能样本数
- 独立概率事件
  - 事件A是否发生对事件B发生的概率没有影响，两个独立概率同时发生的概率等于两个独立事件分别发生的概率之积
- 独立重复试验概率
  - 记一次试验中目标事件发生的概率为p，则在n次试验中出现k次目标事件的概率：C(n,k) x p^k x (1-p)^(n-k)
  - 相同条件下重复的、各次之间相互独立的进行的一种试验，其中每次试验某事件只有发生或不发生两种结果
- 对立面求解
  - 当所求事件包含的情况比较复杂、分类较多时，可以通过分析该事件的对立事件，利用公式求解：1 - 对立面事件概率

### 容斥问题

- 基本格式
  - A∪B = A + B - A∩B
- 文氏图
  - 各集合使用大写A、B、C表示，一般考察3个集合容斥问题，判断题意是否涉及有不属于任意集合的元素（非A∪B∪C ）
  - 全集（总数）表示为L，不属于任意集合表示为L0，仅属于一个集合表示为L1，仅属于两个集合表示为L2，属于三个集合表示为L3（即A∩B∩C）
- 三集合容斥
  - A∪B∪C = A + B + C - A∩B - B∩C - C∩A + A∩B∩C
  - A + B + C = L1 + 2L2 + 3L3
  - L = L0 + A∪B∪C
  - L = L0 + L1 + L2 + L3
  - L = L0 + A + B + C - L2 - 2L3
- 多集合容斥
  - A∩B∩C数量的最小值 = A + B + C - 2L
  - A∩B∩C∩D数量的最小值 = A + B + C + D - 3L
