# 言语理解与表达

## 选词填空

### 语境分析

- 解释说明关系
  - 含有指代义的词语，如：这、那、此、这样、这些
  - 表同义互换的词语，如：也就是说、或者说、无异于、即
  - 表解释说明的标点符号，如：冒号、破折号
  - 表归纳概括的词语，如：可见、总之、可谓
  - 表举例论证的词语，如：也是如此、譬如、如
  - 表假设、条件的词语，如：如果……就/那么……、只有……才…...
- 相反相对关系
  - 转折词
  - 对照词
  - 变化词
  - 否定词
- 并举关系
  - 平行并列的句式
- 递进关系
  - 表递进关系的关联词

### 词语辨析

- 词语搭配
- 词义侧重
- 词义轻重
- 词语感情色彩
  - 褒义
  - 贬义
  - 中性
- 词语语体色彩
  - 书面语体
  - 口头语体
- 语法语用角度
  - 语义重复的词语不能连用，如”大约“与“左右”
  - 词性误用
  - 乱接宾语，如“截止”后不能接时间词

## 片段阅读

### 概括归纳

- 列举不同事物
  - 提炼共性
- 剖析同一事物
  - 加和要点

### 判断意图

- 梳理行文结构
  - 总分
  - 分总
  - 总分总
  - 因果式，侧重结果
  - 转折式，侧重转折后内容
  - 隐形主旨
    - 基于问题给出对策、原因、危害
    - 归纳概括影响意义
    - 并列归纳
- 把握关键词语
  - 高频词，排除可疑选项
  - 强调词，语气比较重的词语

### 查找细节

- 无中生有
- 概念变化
  - 不是同一个概念，或者修饰词改变、缺失
- 颠倒黑白
- 绝对表述
- 混淆逻辑
  - 强加因果
  - 因果倒置，如充分必要条件

### 标题添加

- 紧扣主旨
  - 提出问题，解决问题，对策
- 简洁凝练
- 吸人眼球

### 推断下文

- 关注尾句
  - 提出一个概念，下一步解释概念
  - 指出一种现象，下一步介绍现象表现或原因
  - 得出一个结论，下一步陈述观点、看法，或者呼吁、倡导
- 排除信息
  - 本文信息
  - 前文信息
  - 无关信息

### 语句理解

- 就近原则
- 文段层次
