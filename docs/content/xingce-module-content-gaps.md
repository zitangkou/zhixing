## 对照核实（相对 `~/真题文档` + 入库 JSON + 学员端代码）

核对方式：扫了本机 PDF **文件名页码段** 和体积；对照 JSON 题干长度/`……`/材料/`media`；对照刷题页实现。扫描件是整页图像，本机没有可用的 PDF 文本层，**没有逐页 OCR 和卷面一字对读**。下面三条用户现象都能在数据里坐实。

### A. 「题目太长，中间用省略号」——属实，且主要是 2025 言语被摘要了

国考片段阅读原文一般 **200–400 字**。入库后：

| 年·卷 | 言语题均长 | 题干含 `……` | 判断 |
|--------|------------|-------------|------|
| 2023 省 | 143 字 | 0 题 | 多数像完整段；文章阅读题干极短（13–30 字）是因为正文在材料 `m_haishi` 等里，题干只留问句，这算正常拆分 |
| 2024 省 | 156 字 | 1 题 | 接近完整段 |
| 2025 省/市/执法（三卷同文） | **109 字** | **14 / 30 题** | **中间用省略号砍原文** |

2025 已确认被摘要的题号（三卷同一套言语）：**Q52–Q65**（含两条语句排序 Q54–Q55 把 ①–⑥ 收成一句提纲）。样例：

- Q52：冻胀丘段只留首尾，中间 `……`，`len=89`
- Q54：`将以下6个句子重新排列……①……⑥……`，**没有完整六句**
- Q56：氦-3 段 `len=75`

解析里还在写「由某某句可知」，说明解析册按全文写，题干 JSON 却是缩写——**不能拿 2025 言语当完整真题练**。

另：领导人讲话、法条选项里的 `……` 是原文引用省略，不要和上述「砍阅读文段」混为一谈。

### B. 判断推理有图但不展示、题干不全——属实，两层原因

**数据层**

- 2025 图形题题干是套话（「从所给四个选项中选最合适的填入问号处」），**规律在图里**；`media` 已指向 `media/figures/shengji_q081.png` 等，**文件在、体积正常**。
- 2023 / 2020–2022：**连 media 引用都没有**，只有套话题干。
- 2024：JSON 写了 `q076.jpg`… 但 `2024/xingce/media/` **目录不存在**。

**产品层（即使用户练到 2025）**

- [`QuestionItem.vue`](../../src/components/QuestionItem.vue) **不渲染 `media`**。
- 材料只塞进 `sourceSentence`，且 **答完才在「原文」里出现**，作答过程看不见图、也看不见资料。

所以：2025 不是「没扫出图」，是 **刷题页没挂图**；2023–2024 才是「库里就没图」。

### C. 资料分析缺具体资料——属实，年与年不同

1. **2025 判断末 5 题模块错配**（省 106–110，市地/执法 97–101），内容是言语/数量，不是判断。

命名规则：`{年}{起始页}{结束页}.pdf`，一套卷大约 70–77 页。

- 裁几何图：2024 `q070.jpg` `q071.jpg`；2023 对应几何题（JSON 尚未写 path）；2026 省 Q71–72。  
- 2023 省 Q73 补答案。

### 判断推理

三类缺口，不要混：

1. **图形**：从试卷裁「题干图 + 选项图」，写入 `media`，文件放到 `media/figures/`。2023 / 2020–2022 连引用都没有，要新建 path。2024 path 已写好，只缺文件。2025 文件已齐。  
2. **定义/类比/逻辑**：一般不缺图；2024 市地/执法要换成本卷题干。  
3. **分析推理材料**：确认 `material_ids` 指向的短文是否完整（2025 `m106_110` 已有）。  
4. **错配题**：2025 三卷判断末 5 题，回源换成真判断，不要当言语/数量练。

每则材料通常要齐这三样（缺哪补哪）：

1. **可读文字/表格**（`content` 或 `table_data`）

3. **题的 `material_ids` 挂上**
