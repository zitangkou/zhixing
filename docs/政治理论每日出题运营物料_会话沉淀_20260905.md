# 政治理论每日出题与运营物料（知行对接约定）

> 物料生成脚本在 iCloud `政治理论/工作流/`。本文只记录**知行后台导入依赖的字段**，供物料生成智能体与本仓库开发对齐。完整生成步骤见云盘 `工作流/README.md`。

## 结构化 HTML 引导卡字段（2026-09-10）

知行「文章管理 → 导入文章 → HTML → 预览」按**整行标签**抽取，不猜节末「关键词」。

引导卡须含（日期之后、原文链接之前或紧邻）：

```
来源：人民日报2026-09-10 09版理论
日期：2026-09-10
标签：思想建设 · 理论武装 · 凝心铸魂
分类：思想理论
```

- `标签：` 文章级 3–6 个，`·` 或逗号分隔。不要把每节【关键词】全部写入。
- `分类：` 必须是知行「分类管理」里已有的中文名。人民日报理论版用 `思想理论`；头版时政用 `时政要闻`。
- 结构化 MD 文首同步：`> 标签：…`、`> 分类：…`。`gen_structure_html.py` 写入 HTML；`--tags` / `--category` 可覆盖。缺省标签 `政治理论`、分类 `思想理论`。
- 无这两行时预览对应表单为空并警告，仍可手填后导入。

时评精拆原文 HTML 的知行预览约定见 [时评精拆原文HTML_知行导入约定.md](./时评精拆原文HTML_知行导入约定.md)（另一套物料脚本，不要和理论 infobox 混用）。
