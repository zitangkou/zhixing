# 言遇英语

知行仓库内的独立 Taro 4 + Vue 3 微信小程序项目。英语内容服务和管理菜单复用仓库 `server/` 与 `server/admin-web/`，学员端代码、微信配置和构建产物独立在本目录。

## 开发

```bash
npm install
npm run dev:weapp
```

微信开发者工具导入本目录下生成的 `dist/`。H5 调试可运行 `npm run dev:h5`。小程序 AppID 从服务端本地 `server/.env` 的 `YANYU_ENGLISH_MINIPROGRAM_APP_ID` 同步到 `project.config.json`；AppSecret 只保存在服务端本地环境变量 `YANYU_ENGLISH_MINIPROGRAM_APP_SECRET`。

API 地址在 `src/config.ts`，当前指向 `https://zhixinggk.ltd/api`。在微信公众平台「开发管理 → 开发设置 → 服务器域名」中，将 `https://zhixinggk.ltd` 配置为 request 合法域名。微信登录由小程序 `wx.login` 获取临时 code，再由后端使用服务端 AppID/AppSecret 换取会话；登录 token 缓存在本机，学习完成记录绑定微信登录用户。未能连接 API 时，学员端会回退到内置样例内容。

## 当前功能

- 今日推荐、场景浏览和课程练习。
- 支持课程关联视频/音频、官方来源链接、台词/字幕和核心句块；视频/音频直播放地址仅在后台标记为已获托管许可后才会在小程序播放。外链课提供来源链接复制入口。
- 学习页支持英文+中文、仅英文和隐藏字幕切换；课程提供逐句音频地址或时间戳时，可点击台词定位播放；并支持视频/示范音频播放、录音回放和情境输出。录音仍只保存在当前设备。
- 微信录音、当前设备回放与删除；录音不上传服务器。
- 本地完成进度、待同步提交队列和账号进度恢复；完成提交带幂等编号，重复网络重试不会重复记次。
- 首页优先显示到期复习；学习者自评“独立说出 / 看提示后说出 / 还没说出”，服务端按结果安排复习。初始间隔为 1、3、7、14 天，是产品规则，后续需根据试点调整。
- 公开课程不要求先登录即可读取；学习记录在登录后绑定账号，无网时保留本机并等待重试。
- 服务端公开课程只返回播放器与学习页面所需的课程字段，后台备注不随公开课程接口返回。
- 管理后台“英语学习”菜单：场景、课程单元、发布状态和基础数据概览。
- 管理后台课程编辑提供逐句台词、中译、句子音频/起止时间、核心表达和自主任务表单，高级 JSON 用于扩展字段；支持上传 MP3/M4A/WAV/AAC/MP4/MOV（单文件 80MB 内）和导入 SRT/VTT 字幕草稿。发布校验课程练习内容、完整时间轴、HTTPS 媒体地址和授权状态；上传与导入不会自动发布。
- 目前线上仅有 3 个原创文本情景单元，未配置示范视听素材；逐句播放功能需要课程后台配置音频地址或句子时间轴才会出现。美剧/学习视频素材库尚待授权核验和录入。
